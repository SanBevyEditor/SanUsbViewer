USB Explorer بومی نوشته شده در **Rust**، با رابط تاریک، توپولوژی بصری و تشخیص قابل خواندن. اولین نسخه در نظر گرفته شده برای ویندوز 10/11.

## منشا پروژه

ویدئو در مبدا پروژه: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus).

این پروژه از استفاده از **WhatCable** در اپل و **USB Device Tree Viewer** در ویندوز الهام گرفته شده است: درک تجهیزات جانبی، هاب ها و سرعت اتصالات USB آنها. این یک پیاده سازی مستقل است.

## ویژگی ها

- تشخیص واقعی دستگاه ها و کنترلرهای USB از طریق `nusb`.
- ساختار درختی توسط اتوبوس و مسیر بندر، با عمق هاب.
- جستجو بر اساس نام، شماره سریال یا VID:PID. فیلترها و هاب USB 3+.
- سرعت پیوند توافقی: 1.5 / 12 / 480 مگابیت بر ثانیه، 5 گیگابیت بر ثانیه،
یا دسته SuperSpeedPlus (10 گیگابیت بر ثانیه یا بیشتر).
- نمودار سفر: کامپیوتر، هاب های میانی، پیوند و دستگاه.
- تحت ویندوز، بازجویی اضافی از هاب توسط IOCTL برای پیدا کردن
قابلیت های SuperSpeed اعلام شده توسط دستگاه. یک دستگاه سازگار با SuperSpeed که از طریق USB 2.0 متصل شده است، یک تشخیص محدودیت مسیر تولید می کند.   هاب USB 2 همراه هاب USB 3 به طور جداگانه درمان می شوند تا از انتساب انشعاب 480 مگابیت بر ثانیه به خطای کابل جلوگیری شود.
- شناسه‌های VID/PID، توصیفگر USB، ویرایش، درایور، سریال و رابط‌ها،
زمانی که سیستم این اطلاعات را افشا می کند.
- به روز رسانی خودکار هر سه ثانیه یا دستی با F5.
- گزارش جلسه از 200 تغییر مشاهده شده گذشته.
- عبارت کامل را در JSON (Ctrl+E) صادر کنید و جزئیات انتخاب شده را کپی کنید.
- راهنمای یکپارچه و حالت نمایش صریح، هرگز به عنوان پشتیبان استفاده نشده است
بی صدا در صورت عدم تشخیص

## پرتاب کنید

با Rust **1.95+**، زنجیره ابزار MSVC و ابزارهای Visual Studio C++ در ویندوز. نمونه ها از RTK برای فیلتر کردن خروجی دستورات استفاده می کنند. بدون RTK، فقط پیشوند `rtk` را حذف کنید. اسکریپت توزیع هر دو مورد را می پذیرد.

```powershell
rtk cargo run --release
```

باینری مستقل در `target/release/san-usb-viewer.exe` تولید شده است. اسکریپت `build.ps1` همچنین یک توزیع در `dist/` ایجاد می کند. هیچ تغییر درایور یا نصب WinUSB برای موجودی لازم نیست: برنامه به رابط های دستگاه نیاز ندارد.

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

پوشه مقصد برای عکسبرداری باید وجود داشته باشد. نسخه انتشار یک برنامه ویندوز بدون کنسول است. `cargo run` را در توسعه برای موجودی خط فرمان ترجیح دهید.

## نتایج را تفسیر کنید

**سرعت مذاکره** سرعت اتصال است و معیاری برای سرعت کپی نیست. سرعت های مفید به ویژه به پروتکل، دستگاه جانبی و سایر دستگاه هایی که گذرگاه را به اشتراک می گذارند بستگی دارد. سرعت های چند دستگاه برای محاسبه پهنای باند موجود جمع نمی شود.

کابل USB غیرفعال معمولاً یک دستگاه قابل شمارش نیست. این نسخه نه نشانگر الکترونیکی خود را می‌خواند، نه قدرت USB Power Delivery و نه نوع اتصال آن را. بنابراین ادعای تایید حداکثر سرعت خود را ندارد. تشخیص بر اساس پیوند مشاهده شده و در صورت وجود، بر اساس شاخص های ویندوز است. یک پیوند کند ممکن است توسط کابل، پورت، هاب یا دستگاه محدود شود. شماره نسخه توصیفگر USB هرگز به عنوان حداکثر سرعت استفاده نمی شود.

دسته SuperSpeedPlus در اینجا بین حالت های 10 و 20 گیگابیت بر ثانیه تمایز قائل نمی شود. USB4/Thunderbolt و تونل های آنها بازرسی نمی شود. پورت های بدون دستگاه متصل موجودی نیستند. کابل شارژ بدون داده دستگاه قابل مشاهده ای ایجاد نمی کند. دستگاه های داخلی (بلوتوث، دوربین داخلی و غیره) ممکن است در درخت USB ظاهر شوند.

اطلاعات غیرقابل دسترس به عنوان در دسترس نمایش داده می شود. سازنده و رابط ها همیشه توسط ویندوز افشا نمی شوند. رویدادهایی که کاملاً بین اسکن ها رخ می دهند ممکن است مورد توجه قرار نگیرند. گزارش در حافظه است و پس از اولین موجودی موفق شروع می شود.

شناسه های گذرگاه و مسیرهای پورت توپولوژی سیستم را توصیف می کنند. یک کانکتور فیزیکی می تواند دو مسیر مجزا برای USB 2 و SuperSpeed داشته باشد.

## معماری و اعتبار سنجی

`scanner.rs` موجودی را انجام می دهد. `windows_probe.rs` درخواست های خواندن بومی از هاب ها را در بر می گیرد. `model.rs` شامل داده ها و تشخیص است. `app.rs` وظایف پس زمینه و انتخاب را انجام می دهد. `views.rs`، `inspector.rs`، `connection.rs` و `theme.rs` رابط را با egui/eframe ترسیم می کنند. رابط در طول اسکن تعاملی باقی می ماند و در صورت شکست اسکن بعدی، آخرین خوانده موفق را حفظ می کند.

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

کتابخانه ها کراس پلتفرم هستند و کد ویندوز مشروط است. نسخه‌های macOS/Linux در این اولین تحویل تأیید نشده‌اند.

## محرمانه بودن

موجودی به صورت محلی، فقط خواندنی، بدون تله متری یا خدمات شبکه کار می کند. لینک های راهنما فقط با کلیک باز می شوند. گزارش‌های JSON می‌توانند شامل شماره سریال و شناسه‌های سیستم باشند: اشتراک‌گذاری آنها به عهده شماست.

## زبان ها - نسخه 0.2.0

این برنامه شامل **50 زبان رابط ** است. روی کد زبان (`FR`، `EN`، و غیره) در بالا سمت راست کلیک کنید تا سوئیچر باز شود. می توانید یک زبان را با نام اصلی، نام انگلیسی یا کد آن جستجو کنید. تغییر فوری است و انتخاب در `%APPDATA%/SanUsbViewer/preferences.json` تحت ویندوز ذخیره می شود. بدون اولویت، از زبان سیستم استفاده می شود. یک زبان پشتیبانی نشده به انگلیسی باز می گردد.

این انتخاب به نفع پرتکلم‌ترین زبان‌ها در کل (زبان مادری و زبان دوم) است و انواع منطقه‌ای را با هم گروه‌بندی می‌کند. این یک طبقه بندی عددی نیست: نتایج بسته به گروه بندی گویش ها متفاوت است. انواع انتخاب شده شامل چینی ساده شده، عربی استاندارد و خط لاتین فولانی و ازبکی است. پنجابی از گورموکی استفاده می کند.

انگلیسی، چینی، هندی، اسپانیایی، فرانسوی، عربی، بنگالی، پرتغالی، روسی، اردو، اندونزیایی، آلمانی، ژاپنی، مراتی، ویتنامی، تلوگو، هائوسا، ترکی، پنجابی، سواحیلی، فیلیپینی، تامیلی، فارسی، کره ای، آمهری، تایلندی، جاوه ای، ایتالیایی، گجراتی، کانادایی، بوجپوری، برمه ای، لهستانی، یوروبایی اوکراینی، سندی، ازبکی، پشتو، سوندانی، مالایی، ایگبو، نپالی، آذری، میتیلی و سومالیایی.

منوهای کپی شده، عیب‌یابی، متن‌های راهنما، پیام‌های فعالیت و جزئیات بومی‌سازی شده‌اند. نام ها و شناسه های ارائه شده توسط سخت افزار و سیستم حفظ می شوند. صادرکننده JSON، طرح و داده‌های موجودی خود را بدون توجه به زبان نمایش نگه می‌دارد. واحدهای فنی در **bit/s** (Mbit/s و Gbit/s) باقی می مانند تا از اشتباه گرفتن با بایت ها جلوگیری شود.

کاتالوگ های فرانسوی و انگلیسی به عنوان مرجع عمل می کنند. زبان‌های دیگر **ترجمه‌های خودکار ** هستند که ممکن است به اصلاحات زبانی نیاز داشته باشند. فایل‌های `locales/*.json` در کامپایل گنجانده شده‌اند و قابل اصلاح و سپس کامپایل مجدد هستند. هیچ ترجمه شبکه ای توسط برنامه انجام نمی شود: 50 زبان و فونت Noto تحت مجوز SIL Open Font جاسازی شده اند. متن عربی از بخش های یونیکد دو طرفه و خطوط جدید محاسبه شده قبل از قالب بندی استفاده می کند.

```powershell
# Forcer une langue pour ce lancement, sans remplacer le choix enregistré
rtk cargo run -- --lang ja

# Vérifier les catalogues, les paramètres et les unités de vitesse
rtk python tools/validate_locales.py

# Capture du guide en arabe
rtk cargo run -- --demo --lang ar --page guide --screenshot artifacts/guide-ar.png
```

`SAN_USB_VIEWER_CONFIG` ممکن است برای آزمایش یا نصب قابل حمل به فایل ترجیحی دیگری مراجعه کند. فقط کد زبان در آنجا ذخیره می شود.
