## सुविधाहरू

- `nusb` मार्फत USB यन्त्रहरू र नियन्त्रकहरूको वास्तविक पहिचान।
- बस र पोर्ट मार्ग, हब गहिराई संग रूख संरचना।
- नाम, क्रम संख्या वा VID: PID द्वारा खोज्नुहोस्; USB 3+ फिल्टर र हबहरू।
- वार्तालाप गरिएको लिङ्क गति: 1.5 / 12 / 480 Mb/s, 5 Gb/s,
वा श्रेणी SuperSpeedPlus (10 Gb/s वा बढी)।
- यात्रा रेखाचित्र: कम्प्युटर, मध्यवर्ती हब, लिङ्क र उपकरण।
- विन्डोज अन्तर्गत, IOCTL द्वारा हबको थप सोधपुछ पत्ता लगाउन
SuperSpeed क्षमताहरू उपकरणद्वारा घोषणा गरियो। USB 2.0 मार्फत जडान भएको SuperSpeed मिल्दो यन्त्रले पथ सीमितता निदान उत्पादन गर्छ।   USB 3 हबका USB 2 हब साथीहरूलाई तिनीहरूको 480 Mb/s शाखालाई केबल गल्तीको श्रेय दिनबाट बच्न छुट्टै व्यवहार गरिन्छ।
- VID/PID पहिचानकर्ताहरू, USB डिस्क्रिप्टर, संशोधन, ड्राइभर, सिरियल र इन्टरफेसहरू,
जब प्रणालीले यो जानकारी उजागर गर्छ।
- प्रत्येक तीन सेकेन्डमा स्वचालित अपडेट, वा F5 को साथ म्यानुअल।
- पछिल्लो २०० अवलोकन गरिएका परिवर्तनहरूको सत्र लग।
- JSON (Ctrl+E) मा पूरा कथन निर्यात गर्नुहोस् र चयन गरिएका विवरणहरू प्रतिलिपि गर्नुहोस्।
- एकीकृत गाइड र स्पष्ट प्रदर्शन मोड, ब्याकअपको रूपमा कहिल्यै प्रयोग नगरिएको
पत्ता लगाउन असफल भएको अवस्थामा मौन।

## फाल्ने

Rust **1.95+** सँग, MSVC टूलचेन र विन्डोजमा भिजुअल स्टुडियो C++ उपकरणहरू। उदाहरणहरूले आदेशहरूको आउटपुट फिल्टर गर्न RTK प्रयोग गर्दछ; RTK बिना, `rtk` उपसर्ग मात्र हटाउनुहोस्। वितरण लिपिले दुवै अवस्थामा स्वीकार गर्दछ।

```powershell
rtk cargo run --release
```

स्ट्यान्डअलोन बाइनरी `target/release/san-usb-viewer.exe` मा उत्पादन गरिएको छ। `build.ps1` स्क्रिप्टले `dist/` मा वितरण पनि सिर्जना गर्दछ। सूचीको लागि WinUSB को कुनै चालक परिमार्जन वा स्थापना आवश्यक छैन: अनुप्रयोगलाई उपकरण इन्टरफेसहरू आवश्यक पर्दैन।

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

क्याप्चरको लागि गन्तव्य फोल्डर अवस्थित हुनुपर्छ। रिलीज संस्करण कन्सोल-रहित विन्डोज अनुप्रयोग हो; कमाण्ड लाइन सूचीको लागि विकासमा `cargo run` लाई प्राथमिकता दिनुहोस्।

## परिणामहरू व्याख्या गर्नुहोस्

**वार्ता गरिएको गति** जडानको हो, र प्रतिलिपि गतिको बेन्चमार्क होइन। उपयोगी गति विशेष गरी प्रोटोकल, परिधीय र बस साझा गर्ने अन्य उपकरणहरूमा निर्भर गर्दछ। उपलब्ध ब्यान्डविथ गणना गर्न धेरै यन्त्रहरूबाट गतिहरू थपिँदैन।

एक निष्क्रिय USB केबल सामान्यतया गन्ने यन्त्र होइन। यो संस्करणले यसको ई-मार्कर पढ्दैन, न USB पावर डेलिभरी पावर, न त यसको कनेक्टर प्रकार। त्यसैले यसले यसको अधिकतम गति प्रमाणित गर्ने दाबी गर्दैन। निदान अवलोकन गरिएको लिङ्कमा आधारित छ र, यदि उपलब्ध छ भने, Windows संकेतकहरूमा। एक ढिलो लिङ्क केबल, पोर्ट, हब, वा उपकरण द्वारा सीमित हुन सक्छ। USB डिस्क्रिप्टर संस्करण नम्बरलाई अधिकतम गतिको रूपमा कहिल्यै प्रयोग गरिँदैन।

SuperSpeedPlus कोटिले यहाँ 10 र 20 Gb/s मोडहरू बीच भेद गर्दैन। USB4/थन्डरबोल्ट र तिनीहरूको सुरुङहरू निरीक्षण गरिएको छैन। संलग्न उपकरण बिना पोर्टहरू आविष्कारित छैनन्। डाटा बिना चार्जिङ केबल देखिने उपकरण सिर्जना गर्दैन। आन्तरिक यन्त्रहरू (ब्लुटुथ, बिल्ट-इन क्यामेरा, आदि) USB रूखमा देखा पर्न सक्छन्।

पहुँचयोग्य जानकारी अनुपलब्धको रूपमा प्रदर्शित हुन्छ। निर्माता र इन्टरफेसहरू सधैं विन्डोजद्वारा खुलासा हुँदैनन्। स्क्यानहरू बीच पूर्ण रूपमा हुने घटनाहरू ध्यान नदिने हुन सक्छन्। लग मेमोरीमा छ र पहिलो सफल सूची पछि सुरु हुन्छ।

बस पहिचानकर्ता र पोर्ट मार्गहरूले प्रणाली टोपोलोजी वर्णन गर्दछ। भौतिक कनेक्टरसँग USB 2 र SuperSpeed को लागि दुईवटा अलग-अलग मार्गहरू हुन सक्छन्।

## वास्तुकला र प्रमाणीकरण

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

पुस्तकालयहरू क्रस-प्लेटफर्म हुन् र विन्डोज कोड सशर्त छ। macOS/Linux संस्करणहरू यो पहिलो डेलिभरीमा मान्य छैनन्।
