مقامی USB ایکسپلورر **Rust** میں لکھا گیا ہے، ایک تاریک انٹرفیس، بصری ٹوپولاجی اور پڑھنے کے قابل تشخیص کے ساتھ۔ پہلا ورژن ونڈوز 10/11 کے لیے ہے۔

## منصوبے کی اصل

پروجیکٹ کی اصل میں ویڈیو: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus)۔

یہ پروجیکٹ ایپل پر **WhatCable** اور ونڈوز پر **USB Device Tree Viewer** کے استعمال سے متاثر ہے: پیری فیرلز، حبس اور ان کے USB کنکشن کی رفتار کو سمجھنا۔ یہ ایک آزاد نفاذ ہے۔

## خصوصیات

- `nusb` کے ذریعے USB آلات اور کنٹرولرز کا اصل پتہ لگانا۔
- حب کی گہرائی کے ساتھ، بس اور بندرگاہ کے راستے سے درخت کا ڈھانچہ۔
- نام، سیریل نمبر یا VID:PID سے تلاش کریں۔ USB 3+ فلٹرز اور حب۔
- بات چیت شدہ لنک کی رفتار: 1.5/12/480 Mb/s، 5 Gb/s،
یا زمرہ SuperSpeedPlus (10 Gb/s یا اس سے زیادہ)۔
- سفر کا خاکہ: کمپیوٹر، انٹرمیڈیٹ حبس، لنک اور ڈیوائس۔
- ونڈوز کے تحت، IOCTL کی طرف سے حب کی اضافی تفتیش کا پتہ لگانے کے لیے
SuperSpeed صلاحیتوں کا اعلان ڈیوائس کے ذریعے کیا گیا۔ USB 2.0 کے ذریعے جڑا ہوا SuperSpeed ہم آہنگ آلہ راستے کی حد بندی کی تشخیص کرتا ہے۔   USB 3 حبس کے USB 2 حب کے ساتھیوں کے ساتھ الگ سے سلوک کیا جاتا ہے تاکہ ان کی 480 Mb/s برانچ کو کیبل کی خرابی سے منسوب نہ کیا جائے۔
- VID/PID شناخت کنندہ، USB ڈسکرپٹر، نظرثانی، ڈرائیور، سیریل اور انٹرفیس،
جب سسٹم اس معلومات کو ظاہر کرتا ہے۔
- ہر تین سیکنڈ میں خودکار اپ ڈیٹ، یا F5 کے ساتھ دستی۔
- آخری 200 مشاہدہ شدہ تبدیلیوں کا سیشن لاگ۔
- JSON (Ctrl+E) میں مکمل بیان برآمد کریں اور منتخب کردہ تفصیلات کاپی کریں۔
- انٹیگریٹڈ گائیڈ اور واضح مظاہرہ موڈ، بیک اپ کے طور پر کبھی استعمال نہیں ہوتا ہے۔
پتہ لگانے میں ناکامی کی صورت میں خاموش۔

## پھینکنا

Rust **1.95+** کے ساتھ، ونڈوز پر MSVC ٹول چین اور ویژول اسٹوڈیو C++ ٹولز۔ مثالیں کمانڈز کے آؤٹ پٹ کو فلٹر کرنے کے لیے RTK کا استعمال کرتی ہیں۔ RTK کے بغیر، صرف `rtk` سابقہ ​​کو ہٹا دیں۔ تقسیم کا اسکرپٹ دونوں صورتوں کو قبول کرتا ہے۔

```powershell
rtk cargo run --release
```

اسٹینڈ اسٹون بائنری `target/release/san-usb-viewer.exe` میں تیار کی گئی ہے۔ `build.ps1` اسکرپٹ `dist/SanUsbViewer/` میں ایک تقسیم بھی تخلیق کرتا ہے۔ انوینٹری کے لیے کسی ڈرائیور میں ترمیم یا WinUSB کی انسٹالیشن ضروری نہیں ہے: ایپلیکیشن کو ڈیوائس انٹرفیس کی ضرورت نہیں ہے۔

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

کیپچر کے لیے منزل کا فولڈر موجود ہونا چاہیے۔ ریلیز ورژن ایک کنسول لیس ونڈوز ایپلی کیشن ہے۔ کمانڈ لائن انوینٹری کے لیے ترقی میں `cargo run` کو ترجیح دیں۔

## نتائج کی تشریح کریں۔

**گفتگو کی رفتار** کنکشن کی ہے، نہ کہ کاپی کی رفتار کا معیار۔ کارآمد رفتار خاص طور پر پروٹوکول، پیریفرل اور بس کو شیئر کرنے والے دیگر آلات پر منحصر ہے۔ دستیاب بینڈوتھ کا حساب لگانے کے لیے متعدد آلات کی رفتار میں اضافہ نہیں ہوتا ہے۔

ایک غیر فعال USB کیبل عام طور پر قابل شمار آلہ نہیں ہے۔ یہ ورژن نہ اپنے ای مارکر کو پڑھتا ہے، نہ ہی USB پاور ڈلیوری پاور، اور نہ ہی اس کے کنیکٹر کی قسم۔ لہذا یہ اپنی زیادہ سے زیادہ رفتار کی تصدیق کرنے کا دعوی نہیں کرتا ہے۔ تشخیص مشاہدہ شدہ لنک پر مبنی ہے اور، اگر دستیاب ہو تو، ونڈوز کے اشارے پر۔ ایک سست لنک کیبل، پورٹ، ہب، یا ڈیوائس کے ذریعہ محدود ہوسکتا ہے۔ USB ڈسکرپٹر ورژن نمبر کبھی بھی زیادہ سے زیادہ رفتار کے طور پر استعمال نہیں ہوتا ہے۔

SuperSpeedPlus زمرہ یہاں 10 اور 20 Gb/s موڈز کے درمیان فرق نہیں کرتا ہے۔ USB4/تھنڈربولٹ اور ان کی سرنگوں کا معائنہ نہیں کیا جاتا ہے۔ بغیر کسی ڈیوائس کے منسلک بندرگاہوں کو انوینٹری نہیں کیا جاتا ہے۔ ڈیٹا کے بغیر چارجنگ کیبل نظر آنے والا آلہ نہیں بناتی ہے۔ اندرونی آلات (بلوٹوتھ، بلٹ ان کیمرہ وغیرہ) USB ٹری میں ظاہر ہو سکتے ہیں۔

ناقابل رسائی معلومات کو غیر دستیاب کے طور پر دکھایا جاتا ہے۔ مینوفیکچرر اور انٹرفیس ہمیشہ ونڈوز کے ذریعہ سامنے نہیں آتے ہیں۔ وہ واقعات جو مکمل طور پر اسکینز کے درمیان رونما ہوتے ہیں کسی کا دھیان نہیں جاتا۔ لاگ میموری میں ہے اور پہلی کامیاب انوینٹری کے بعد شروع ہوتا ہے۔

بس شناخت کنندہ اور پورٹ پاتھ سسٹم ٹوپولوجی کی وضاحت کرتے ہیں۔ فزیکل کنیکٹر کے پاس USB 2 اور SuperSpeed کے لیے دو الگ الگ راستے ہو سکتے ہیں۔

## فن تعمیر اور توثیق

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

لائبریریاں کراس پلیٹ فارم ہیں اور ونڈوز کوڈ مشروط ہے۔ اس پہلی ترسیل میں macOS/Linux ورژن کی توثیق نہیں کی گئی ہے۔
