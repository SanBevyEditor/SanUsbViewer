## የፕሮጀክቱ አመጣጥ

ቪዲዮ በፕሮጀክቱ መነሻ: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus).

ፕሮጀክቱ በ **WhatCable** አፕል እና **USB Device Tree Viewer** በዊንዶው ላይ በመጠቀማቸው ተመስጧዊ ነው፡ መገኛ አካባቢን፣ መገናኛዎችን እና የዩኤስቢ ግንኙነቶቻቸውን ፍጥነት መረዳት። ይህ ራሱን የቻለ ትግበራ ነው።

## ባህሪያት

- የዩኤስቢ መሳሪያዎችን እና ተቆጣጣሪዎችን በ`nusb` በኩል በትክክል ማግኘት።
- የዛፍ መዋቅር በአውቶቡስ እና በወደብ መንገድ፣ ከመሃል ጥልቀት ጋር።
- በስም, ተከታታይ ቁጥር ወይም VID: PID; የዩኤስቢ 3+ ማጣሪያዎች እና መገናኛዎች።
- በድርድር የተደረገ የአገናኝ ፍጥነት፡ 1.5/12/480 ሜባ/ሰ፣ 5Gb/s፣
ወይም ምድብ SuperSpeedPlus (10 Gb/s ወይም ከዚያ በላይ)።
- የጉዞ ሥዕላዊ መግለጫ፡ ኮምፕዩተር፣ መካከለኛ ማዕከሎች፣ ማገናኛ እና መሣሪያ።
- በዊንዶውስ ስር፣ የማዕከሉ ተጨማሪ ምርመራ በ IOCTL
በመሳሪያው የታወቁ የ SuperSpeed ችሎታዎች። በUSB 2.0 የተገናኘ የSuperSpeed ተኳሃኝ መሳሪያ የመንገድ ውስንነት ምርመራን ይፈጥራል።   የዩኤስቢ 2 መገናኛዎች የዩኤስቢ 3 መገናኛዎች 480 ሜባ/ሰ ቅርንጫፎቻቸውን በኬብል ስህተት ምክንያት ላለማድረግ በተናጠል ይታከማሉ።
- VID/PID ለዪዎች፣ የዩኤስቢ ገላጭ፣ ክለሳ፣ ሾፌር፣ ተከታታይ እና በይነገጾች፣
ስርዓቱ ይህንን መረጃ ሲያጋልጥ.
- በየሶስት ሴኮንዱ በራስ ሰር አዘምን፣ ወይም በእጅ በF5።
- ያለፉት 200 የተስተዋሉ ለውጦች የክፍለ-ጊዜ ምዝግብ ማስታወሻ።
- ሙሉውን መግለጫ በJSON (Ctrl+E) ወደ ውጭ ይላኩ እና የተመረጡትን ዝርዝሮች ይቅዱ።
- የተዋሃደ መመሪያ እና ግልጽ የማሳያ ሁነታ፣ እንደ ምትኬ በጭራሽ ጥቅም ላይ አይውልም።
ማወቂያው ካልተሳካ ጸጥ.

## መወርወር

ከ Rust **1.95+** ጋር፣ የ MSVC የመሳሪያ ሰንሰለት እና ቪዥዋል ስቱዲዮ ሲ++ መሳሪያዎች በዊንዶው። ምሳሌዎቹ የትእዛዞችን ውጤት ለማጣራት RTK ይጠቀማሉ; ያለ RTK፣ የ`rtk` ቅድመ ቅጥያውን ብቻ ያስወግዱ። የስርጭት ስክሪፕቱ ሁለቱንም ጉዳዮች ይቀበላል.

```powershell
rtk cargo run --release
```

ራሱን የቻለ ሁለትዮሽ የሚመረተው በ`target/release/san-usb-viewer.exe` ነው። የ`build.ps1` ስክሪፕትም በ`dist/SanUsbViewer/` ውስጥ ስርጭትን ይፈጥራል። ለክምችቱ ምንም የአሽከርካሪ ማሻሻያ ወይም የ WinUSB መጫን አያስፈልግም፡ አፕሊኬሽኑ የመሳሪያ በይነገጾች አያስፈልግም።

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

ቀረጻ የመድረሻ ማህደር መኖር አለበት። የሚለቀቀው ስሪት ኮንሶል-ያነሰ የዊንዶውስ መተግበሪያ ነው; ለትዕዛዝ መስመር ክምችት `cargo run`ን እመርጣለሁ።

## ውጤቱን መተርጎም

**የድርድር ፍጥነት** የግንኙነቱ ነው እንጂ የቅጂ ፍጥነት መለኪያ አይደለም። ጠቃሚው ፍጥነቶች በተለይ በፕሮቶኮል፣ በተጓዳኝ እና አውቶቡሱን በሚጋሩት ሌሎች መሳሪያዎች ላይ ይመረኮዛሉ። ከበርካታ መሳሪያዎች የሚመጡ ፍጥነቶች የሚገኙትን የመተላለፊያ ይዘት ለማስላት አይጨምሩም.

ተገብሮ የዩኤስቢ ገመድ በአጠቃላይ ሊቆጠር የሚችል መሳሪያ አይደለም። ይህ እትም የኢ-ማርከርን ፣ የዩኤስቢ ሃይል ማቅረቢያ ሃይልን ፣ ወይም የግንኙነት አይነትን አያነብም። ስለዚህ ከፍተኛውን ፍጥነት አረጋግጣለሁ አይልም. የምርመራው ውጤት በሚታየው አገናኝ ላይ እና ካለ, በዊንዶውስ አመላካቾች ላይ የተመሰረተ ነው. ዘገምተኛ ማገናኛ በኬብሉ፣ ወደብ፣ መገናኛ ወይም መሳሪያ ሊገደብ ይችላል። የዩኤስቢ ገላጭ ሥሪት ቁጥሩ እንደ ከፍተኛው ፍጥነት በጭራሽ ጥቅም ላይ አይውልም።

የSuperSpeedPlus ምድብ እዚህ በ10 እና 20 Gb/s ሁነታዎች መካከል ያለውን ልዩነት አይለይም። USB4/ Thunderbolt እና ዋሻዎቻቸው አልተፈተሹም። መሳሪያ የሌላቸው ወደቦች አልተመረመሩም። ያለ ውሂብ የሚሞላ ገመድ የሚታይ መሳሪያ አይፈጥርም። የውስጥ መሳሪያዎች (ብሉቱዝ፣ አብሮ የተሰራ ካሜራ፣ ወዘተ) በዩኤስቢ ዛፉ ላይ ሊታዩ ይችላሉ።

የማይደረስበት መረጃ የማይገኝ ሆኖ ይታያል። አምራቹ እና መገናኛዎች ሁልጊዜ በዊንዶው አይጋለጡም. በፍተሻዎች መካከል ሙሉ በሙሉ የሚከሰቱ ክስተቶች ሳይስተዋል ሊቀሩ ይችላሉ። ምዝግብ ማስታወሻው በማስታወስ ውስጥ ነው እና የሚጀምረው ከመጀመሪያው የተሳካ ክምችት በኋላ ነው.

የአውቶቡስ መለያዎች እና የወደብ መንገዶች የስርዓት ቶፖሎጂን ይገልጻሉ። አካላዊ አያያዥ ለUSB 2 እና SuperSpeed ሁለት የተለያዩ መንገዶች ሊኖሩት ይችላል።

## አርክቴክቸር እና ማረጋገጫ

`scanner.rs` ቆጠራ ያከናውናል; `windows_probe.rs` ከማዕከሎች የመጡ ቤተኛ የንባብ ጥያቄዎችን ያጠቃልላል። `model.rs` ውሂብ እና ምርመራዎችን ይዟል። `app.rs` የጀርባ ተግባራትን እና ምርጫን ይቆጣጠራል; `views.rs`፣ `inspector.rs`፣ `connection.rs` እና `theme.rs` በይነገጹን በ egui/eframe ይሳሉ። በይነገጹ በፍተሻ ጊዜ መስተጋብራዊ ሆኖ ይቆያል እና የሚቀጥለው ቅኝት ካልተሳካ የመጨረሻውን የተሳካ ንባብ ይይዛል።

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

ቤተ መፃህፍቶቹ መድረክ አቋራጭ ሲሆኑ የዊንዶውስ ኮድ ሁኔታዊ ነው። የማክኦኤስ/ሊኑክስ ስሪቶች በዚህ የመጀመሪያ ማድረስ አልተረጋገጡም።

## ሚስጥራዊነት

ኢንቬንቶሪ ያለ ቴሌሜትሪ ወይም የኔትወርክ አገልግሎት በአገር ውስጥ፣ ተነባቢ-ብቻ ይሰራል። የመመሪያው ማገናኛዎች በጠቅታ ብቻ ይከፈታሉ. የJSON ሪፖርቶች ተከታታይ ቁጥሮችን እና የስርዓት መለያዎችን ሊይዙ ይችላሉ፡ እነሱን ማጋራት የእርስዎ ነው።

## ቋንቋዎች - ስሪት 0.2.0

አፕሊኬሽኑ **50 የበይነገጽ ቋንቋዎችን ያካትታል። መቀየሪያውን ለመክፈት ከላይ በቀኝ በኩል ያለውን የቋንቋ ኮድ (`FR`፣ `EN`፣ ወዘተ) ጠቅ ያድርጉ። ቋንቋን በአፍ መፍቻ ስሙ፣ በእንግሊዝኛ ስሙ ወይም በኮዱ መፈለግ ይችላሉ። ለውጡ ወዲያውኑ ነው እና ምርጫው በዊንዶውስ ስር በ `%APPDATA%/SanUsbViewer/preferences.json` ውስጥ ተከማችቷል. ያለ ምርጫ, የስርዓት ቋንቋ ጥቅም ላይ ይውላል; የማይደገፍ ቋንቋ ወደ እንግሊዝኛ ይመለሳል።

ምርጫው በአጠቃላይ በጣም የሚነገሩ ቋንቋዎችን ይደግፋል (የአፍ መፍቻ ቋንቋ እና ሁለተኛ ቋንቋ) ፣ የክልል ልዩነቶችን በአንድ ላይ በማሰባሰብ። ይህ የቁጥር ምደባ አይደለም፡ ውጤቶቹ እንደ ዘዬዎች ስብስብ ይለያያል። የተመረጡት ልዩነቶች ቀለል ያሉ ቻይንኛ፣ መደበኛ አረብኛ እና የፉላኒ እና የኡዝቤክ የላቲን ፅሁፎችን ያካትታሉ። ፑንጃቢ ጉርሙኪን ይጠቀማል።

እንግሊዘኛ፣ ቻይንኛ፣ ሂንዲ፣ ስፓኒሽ፣ ፈረንሳይኛ፣ አረብኛ፣ ቤንጋሊኛ፣ ፖርቱጋልኛ፣ ራሽያኛ፣ ኡርዱ፣ ኢንዶኔዥያ፣ ጀርመንኛ፣ ጃፓንኛ፣ ማራቲኛ፣ ቬትናምኛ፣ ቴሉጉኛ፣ ሃውሳ፣ ቱርክኛ፣ ፑንጃቢ፣ ስዋሂሊ፣ ፊሊፒኖ፣ ታሚልኛ፣ ፋርስኛ፣ ኮሪያኛ፣ አማረኛ፣ ታይኛ፣ ጃቫኔዝ፣ ጣሊያንኛ፣ ጉጃራቲ፣ ካናዳ፣ ቦሆጁፑሪ፣ በርማዝ፣ ፖላንድኛ፣ ዮሩባ፣ ሊንጋላምኛ፣ ኦሮሞኛ፣ ፉላኒኛ ኡዝቤክ፣ ፓሽቶ፣ ሱዳኒዝ፣ ማላይኛ፣ ኢግቦ፣ ኔፓሊ፣ አዜሪ፣ ማይቲሊ እና ሶማሊኛ።

የተገለበጡ ምናሌዎች፣ ምርመራዎች፣ የእርዳታ ጽሑፎች፣ የእንቅስቃሴ መልዕክቶች እና ዝርዝሮች የተተረጎሙ ናቸው። በሃርድዌር እና ስርዓቱ የቀረቡ ስሞች እና መለያዎች እንደተጠበቁ ናቸው። የJSON ኤክስፖርት የማሳያ ቋንቋው ምንም ይሁን ምን የእቅዱን እና የእቃ ዝርዝር ውሂቡን ይጠብቃል። ከባይት ጋር ግራ መጋባትን ለማስወገድ የቴክኒክ አሃዶች በ **bit/s** (Mbit/s እና Gbit/s) ይቀራሉ።

የፈረንሳይ እና የእንግሊዝኛ ካታሎጎች እንደ ማጣቀሻ ያገለግላሉ. ሌሎች ቋንቋዎች **አውቶማቲክ ትርጉሞች** ናቸው፣ የቋንቋ እርማቶችን ሊፈልጉ ይችላሉ። የ `locales/*.json` ፋይሎች በቅንብሩ ውስጥ ተካትተዋል እና ሊስተካከሉ እና ከዚያ እንደገና ሊጠናከሩ ይችላሉ። በመተግበሪያው ምንም የአውታረ መረብ ትርጉም አይከናወንም-50 ቋንቋዎች እና የኖቶ ቅርጸ-ቁምፊዎች በ SIL ክፍት ቅርጸ-ቁምፊ ፈቃድ ውስጥ ተካትተዋል። የአረብኛ ጽሁፍ ከመቅረፅ በፊት የተሰሉ ባለሁለት አቅጣጫዊ የዩኒኮድ ክፍሎችን እና አዲስ መስመሮችን ይጠቀማል።
