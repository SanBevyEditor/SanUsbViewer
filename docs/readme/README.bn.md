## প্রকল্পের উত্স

প্রকল্পের মূলে ভিডিও: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus)।

প্রজেক্টটি অ্যাপল-এ **WhatCable** এবং Windows-এ **USB Device Tree Viewer** ব্যবহার দ্বারা অনুপ্রাণিত: পেরিফেরাল, হাব এবং তাদের USB সংযোগের গতি বোঝা। এটি একটি স্বাধীন বাস্তবায়ন।

## বৈশিষ্ট্য

- `nusb` এর মাধ্যমে USB ডিভাইস এবং কন্ট্রোলারের প্রকৃত সনাক্তকরণ।
- হাবের গভীরতা সহ বাস এবং বন্দরের পথ দ্বারা গাছের গঠন।
- নাম, সিরিয়াল নম্বর বা ভিআইডি:পিআইডি দ্বারা অনুসন্ধান করুন; USB 3+ ফিল্টার এবং হাব।
- আলোচিত লিঙ্কের গতি: 1.5 / 12 / 480 Mb/s, 5 Gb/s,
অথবা SuperSpeedPlus (10 Gb/s বা তার বেশি) বিভাগ।
- জার্নি ডায়াগ্রাম: কম্পিউটার, ইন্টারমিডিয়েট হাব, লিঙ্ক এবং ডিভাইস।
- উইন্ডোজের অধীনে, আইওসিটিএল দ্বারা হাবের অতিরিক্ত জিজ্ঞাসাবাদটি খুঁজে বের করতে
SuperSpeed ক্ষমতা ডিভাইস দ্বারা ঘোষিত. USB 2.0 এর মাধ্যমে সংযুক্ত একটি SuperSpeed সামঞ্জস্যপূর্ণ ডিভাইস একটি পাথ সীমাবদ্ধতা ডায়াগনস্টিক তৈরি করে।   USB 3 হাবের ইউএসবি 2 হাব সঙ্গীদের আলাদাভাবে চিকিত্সা করা হয় যাতে তাদের 480 Mb/s শাখাকে তারের ত্রুটির জন্য দায়ী করা না হয়।
- ভিআইডি/পিআইডি শনাক্তকারী, ইউএসবি বর্ণনাকারী, সংশোধন, ড্রাইভার, সিরিয়াল এবং ইন্টারফেস,
যখন সিস্টেম এই তথ্য প্রকাশ করে।
- প্রতি তিন সেকেন্ডে স্বয়ংক্রিয় আপডেট, অথবা F5 সহ ম্যানুয়াল।
- শেষ 200টি পর্যবেক্ষিত পরিবর্তনের সেশন লগ।
- JSON (Ctrl+E) এ সম্পূর্ণ বিবৃতি রপ্তানি করুন এবং নির্বাচিত বিবরণ অনুলিপি করুন।
- ইন্টিগ্রেটেড গাইড এবং স্পষ্ট প্রদর্শন মোড, ব্যাকআপ হিসাবে ব্যবহার করা হয় না
সনাক্তকরণ ব্যর্থতার ক্ষেত্রে নীরব।

## নিক্ষেপ

Rust **1.95+** সহ, MSVC টুলচেন এবং Windows এ ভিজ্যুয়াল স্টুডিও C++ টুল। উদাহরণগুলি কমান্ডের আউটপুট ফিল্টার করতে RTK ব্যবহার করে; RTK ছাড়া, শুধু `rtk` উপসর্গটি সরিয়ে দিন। বিতরণ স্ক্রিপ্ট উভয় ক্ষেত্রেই গ্রহণ করে।

```powershell
rtk cargo run --release
```

স্বতন্ত্র বাইনারি `target/release/san-usb-viewer.exe` এ উত্পাদিত হয়। `build.ps1` স্ক্রিপ্ট `dist/`-এ একটি বিতরণও তৈরি করে। ইনভেন্টরির জন্য WinUSB-এর কোনো ড্রাইভার পরিবর্তন বা ইনস্টলেশনের প্রয়োজন নেই: অ্যাপ্লিকেশনটির ডিভাইস ইন্টারফেসের প্রয়োজন নেই।

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

একটি ক্যাপচারের জন্য গন্তব্য ফোল্ডার বিদ্যমান থাকা আবশ্যক. রিলিজ সংস্করণ একটি কনসোল-হীন উইন্ডোজ অ্যাপ্লিকেশন; কমান্ড লাইন ইনভেন্টরির জন্য বিকাশে `cargo run` পছন্দ করুন।

## ফলাফল ব্যাখ্যা

**আলোচনার গতি** হল সংযোগের গতি, এবং অনুলিপি গতির মানদণ্ড নয়। দরকারী গতি বিশেষভাবে প্রোটোকল, পেরিফেরাল এবং বাস ভাগ করে নেওয়া অন্যান্য ডিভাইসের উপর নির্ভর করে। উপলব্ধ ব্যান্ডউইথ গণনা করতে একাধিক ডিভাইসের গতি যোগ হয় না।

একটি প্যাসিভ USB তারের সাধারণত একটি গণনাযোগ্য ডিভাইস নয়। এই সংস্করণটি এর ই-মার্কার, USB পাওয়ার ডেলিভারি পাওয়ার বা এর সংযোগকারীর ধরনটি পড়ে না। তাই এটি তার সর্বোচ্চ গতি প্রত্যয়িত করার দাবি করে না। নির্ণয়টি পর্যবেক্ষণ করা লিঙ্কের উপর ভিত্তি করে এবং, যদি উপলব্ধ থাকে, তাহলে Windows সূচকের উপর। একটি ধীর লিঙ্ক কেবল, পোর্ট, হাব বা ডিভাইস দ্বারা সীমিত হতে পারে। USB বর্ণনাকারী সংস্করণ নম্বর সর্বোচ্চ গতি হিসাবে ব্যবহার করা হয় না.

SuperSpeedPlus বিভাগটি এখানে 10 এবং 20 Gb/s মোডের মধ্যে পার্থক্য করে না। USB4/থান্ডারবোল্ট এবং তাদের টানেল পরিদর্শন করা হয় না। সংযুক্ত একটি ডিভাইস ছাড়া পোর্ট ইনভেন্টরি হয় না. ডেটা ছাড়া একটি চার্জিং তার দৃশ্যমান ডিভাইস তৈরি করে না। অভ্যন্তরীণ ডিভাইস (ব্লুটুথ, অন্তর্নির্মিত ক্যামেরা, ইত্যাদি) USB ট্রিতে উপস্থিত হতে পারে৷

অ্যাক্সেসযোগ্য তথ্য অনুপলব্ধ হিসাবে প্রদর্শিত হয়. নির্মাতা এবং ইন্টারফেস সবসময় উইন্ডোজ দ্বারা উন্মুক্ত করা হয় না. স্ক্যানগুলির মধ্যে সম্পূর্ণরূপে ঘটে যাওয়া ঘটনাগুলি অলক্ষিত হতে পারে৷ লগটি মেমরিতে রয়েছে এবং প্রথম সফল ইনভেন্টরির পরে শুরু হয়।

বাস শনাক্তকারী এবং পোর্ট পাথ সিস্টেম টপোলজি বর্ণনা করে। একটি শারীরিক সংযোগকারীর USB 2 এবং SuperSpeed এর জন্য দুটি পৃথক পাথ থাকতে পারে।

## স্থাপত্য এবং বৈধতা

`scanner.rs` জায় সম্পাদন করে; `windows_probe.rs` হাব থেকে নেটিভ রিড রিকোয়েস্ট এনক্যাপসুলেট করে; `model.rs` ডেটা এবং ডায়াগনস্টিক ধারণ করে। `app.rs` ব্যাকগ্রাউন্ড কাজ এবং নির্বাচন পরিচালনা করে; `views.rs`, `inspector.rs`, `connection.rs` এবং `theme.rs` egui/eframe দিয়ে ইন্টারফেস আঁকে। স্ক্যানের সময় ইন্টারফেসটি ইন্টারেক্টিভ থাকে এবং পরবর্তী স্ক্যান ব্যর্থ হলে শেষ সফল পড়া ধরে রাখে।

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

লাইব্রেরিগুলো ক্রস-প্ল্যাটফর্ম এবং উইন্ডোজ কোড শর্তসাপেক্ষ। এই প্রথম ডেলিভারিতে macOS/Linux সংস্করণগুলি যাচাই করা হয় না।

ইনভেন্টরি স্থানীয়ভাবে কাজ করে, শুধুমাত্র পঠনযোগ্য, টেলিমেট্রি বা নেটওয়ার্ক পরিষেবা ছাড়াই। গাইড লিঙ্কগুলি শুধুমাত্র ক্লিকে খোলে। JSON রিপোর্টে সিরিয়াল নম্বর এবং সিস্টেম শনাক্তকারী থাকতে পারে: সেগুলি ভাগ করা আপনার ব্যাপার।

## ভাষা - সংস্করণ 0.2.0

অ্যাপ্লিকেশনটিতে রয়েছে **50টি ইন্টারফেস ভাষা**। সুইচার খুলতে উপরের ডানদিকে ভাষার কোডে (`FR`, `EN`, ইত্যাদি) ক্লিক করুন। আপনি একটি ভাষা এর স্থানীয় নাম, এর ইংরেজি নাম বা এর কোড দ্বারা অনুসন্ধান করতে পারেন। পরিবর্তনটি অবিলম্বে এবং পছন্দটি উইন্ডোজের অধীনে `%APPDATA%/SanUsbViewer/preferences.json` এ সংরক্ষণ করা হয়েছে। পছন্দ ছাড়া, সিস্টেম ভাষা ব্যবহার করা হয়; একটি অসমর্থিত ভাষা ইংরেজিতে ফিরে আসে।

নির্বাচনটি আঞ্চলিক রূপগুলিকে একত্রিত করে মোট সর্বাধিক কথ্য ভাষার (মাতৃভাষা এবং দ্বিতীয় ভাষা) সমর্থন করে। এটি একটি সংখ্যাগত শ্রেণীবিভাগ নয়: উপভাষার গোষ্ঠীকরণের উপর নির্ভর করে ফলাফলগুলি পরিবর্তিত হয়। নির্বাচিত রূপের মধ্যে রয়েছে সরলীকৃত চাইনিজ, স্ট্যান্ডার্ড আরবি এবং ফুলানি ও উজবেক ভাষার ল্যাটিন লিপি; পাঞ্জাবি গুরুমুখী ব্যবহার করে।

কপি করা মেনু, ডায়াগনস্টিকস, হেল্প টেক্সট, অ্যাক্টিভিটি মেসেজ এবং বিশদ স্থানীয়করণ করা হয়েছে। হার্ডওয়্যার এবং সিস্টেম দ্বারা প্রদত্ত নাম এবং শনাক্তকারী রাখা হয়। JSON এক্সপোর্ট তার স্কিমা এবং ইনভেন্টরি ডেটা রাখে, প্রদর্শনের ভাষা নির্বিশেষে। বাইটের সাথে বিভ্রান্তি এড়াতে প্রযুক্তিগত ইউনিটগুলি **বিট/সেকেন্ড** (Mbit/s এবং Gbit/s) এ থাকে।

ফরাসি এবং ইংরেজি ক্যাটালগ একটি রেফারেন্স হিসাবে কাজ করে। অন্যান্য ভাষা হল **স্বয়ংক্রিয় অনুবাদ**, যার জন্য ভাষাগত সংশোধনের প্রয়োজন হতে পারে। `locales/*.json` ফাইলগুলি সংকলনে অন্তর্ভুক্ত করা হয়েছে এবং সংশোধন করা যেতে পারে এবং তারপরে পুনরায় সংকলন করা যেতে পারে। অ্যাপ্লিকেশন দ্বারা কোন নেটওয়ার্ক অনুবাদ করা হয় না: SIL ওপেন ফন্ট লাইসেন্সের অধীনে 50টি ভাষা এবং নোটো ফন্ট এমবেড করা হয়েছে। আরবি পাঠ্য দ্বিমুখী ইউনিকোড সেগমেন্ট এবং বিন্যাস করার আগে গণনা করা নতুন লাইন ব্যবহার করে।
