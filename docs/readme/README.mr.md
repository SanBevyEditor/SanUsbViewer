## वैशिष्ट्ये

- `nusb` द्वारे USB उपकरणे आणि नियंत्रकांची वास्तविक ओळख.
- बस आणि बंदर मार्गाने झाडाची रचना, हबच्या खोलीसह.
- नाव, अनुक्रमांक किंवा VID:PID द्वारे शोधा; USB 3+ फिल्टर आणि हब.
- निगोशिएट लिंक स्पीड: 1.5 / 12 / 480 Mb/s, 5 Gb/s,
किंवा श्रेणी SuperSpeedPlus (10 Gb/s किंवा अधिक).
- प्रवास आकृती: संगणक, इंटरमीडिएट हब, लिंक आणि डिव्हाइस.
- विंडोज अंतर्गत, हे शोधण्यासाठी IOCTL द्वारे हबची अतिरिक्त चौकशी
डिव्हाइसद्वारे घोषित SuperSpeed क्षमता. USB 2.0 द्वारे कनेक्ट केलेले SuperSpeed सुसंगत डिव्हाइस पथ मर्यादा निदान तयार करते.   USB 3 हबचे USB 2 हब सहचर त्यांच्या 480 Mb/s शाखेला केबल फॉल्टचे श्रेय देऊ नये म्हणून त्यांना स्वतंत्रपणे हाताळले जाते.
- व्हीआयडी/पीआयडी आयडेंटिफायर, यूएसबी डिस्क्रिप्टर, रिव्हिजन, ड्रायव्हर, सीरियल आणि इंटरफेस,
जेव्हा सिस्टम ही माहिती उघड करते.
- दर तीन सेकंदांनी स्वयंचलित अपडेट किंवा F5 सह मॅन्युअल.
- शेवटच्या 200 निरीक्षण केलेल्या बदलांचा सत्र लॉग.
- JSON (Ctrl+E) मध्ये संपूर्ण विधान निर्यात करा आणि निवडलेले तपशील कॉपी करा.
- एकात्मिक मार्गदर्शक आणि स्पष्ट प्रात्यक्षिक मोड, कधीही बॅकअप म्हणून वापरला जात नाही
शोध अयशस्वी झाल्यास शांत.

## फेकणे

Rust **1.95+** सह, MSVC टूलचेन आणि Windows वर Visual Studio C++ टूल्स. कमांडचे आउटपुट फिल्टर करण्यासाठी उदाहरणे RTK वापरतात; RTK शिवाय, फक्त `rtk` उपसर्ग काढून टाका. वितरण स्क्रिप्ट दोन्ही प्रकरणे स्वीकारते.

```powershell
rtk cargo run --release
```

स्टँडअलोन बायनरी `target/release/san-usb-viewer.exe` मध्ये तयार केली जाते. `build.ps1` स्क्रिप्ट `dist/SanUsbViewer/` मध्ये वितरण देखील तयार करते. इन्व्हेंटरीसाठी कोणतेही ड्रायव्हर बदल किंवा WinUSB ची स्थापना आवश्यक नाही: अनुप्रयोगास डिव्हाइस इंटरफेसची आवश्यकता नाही.

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

कॅप्चरसाठी गंतव्य फोल्डर अस्तित्वात असणे आवश्यक आहे. रिलीझ आवृत्ती कन्सोल-लेस विंडोज ऍप्लिकेशन आहे; कमांड लाइन इन्व्हेंटरीसाठी विकासामध्ये `cargo run` ला प्राधान्य द्या.

## परिणामांचा अर्थ लावा

**निगोशिएट स्पीड** हा कनेक्शनचा आहे, कॉपी स्पीडचा बेंचमार्क नाही. उपयुक्त वेग विशेषतः प्रोटोकॉल, परिधीय आणि बस सामायिक करणार्या इतर उपकरणांवर अवलंबून असतात. उपलब्ध बँडविड्थची गणना करण्यासाठी एकाधिक डिव्हाइसेसवरील वेग जोडत नाहीत.

निष्क्रीय USB केबल साधारणपणे मोजता येण्याजोगे उपकरण नसते. ही आवृत्ती तिचा ई-मार्कर, किंवा USB पॉवर डिलिव्हरी पॉवर किंवा त्याचा कनेक्टर प्रकार वाचत नाही. त्यामुळे त्याची कमाल गती प्रमाणित करण्याचा दावा करत नाही. निदान निरीक्षण केलेल्या दुव्यावर आणि उपलब्ध असल्यास, Windows संकेतकांवर आधारित आहे. केबल, पोर्ट, हब किंवा डिव्हाइसद्वारे स्लो लिंक मर्यादित असू शकते. USB डिस्क्रिप्टर आवृत्ती क्रमांक कधीही कमाल गती म्हणून वापरला जात नाही.

SuperSpeedPlus श्रेणी येथे 10 आणि 20 Gb/s मोडमध्ये फरक करत नाही. USB4/थंडरबोल्ट आणि त्यांच्या बोगद्यांची तपासणी केली जात नाही. जोडलेले उपकरण नसलेले पोर्ट इन्व्हेंटरी केलेले नाहीत. डेटाशिवाय चार्जिंग केबल दृश्यमान उपकरण तयार करत नाही. अंतर्गत उपकरणे (ब्लूटूथ, अंगभूत कॅमेरा इ.) USB ट्रीमध्ये दिसू शकतात.

अगम्य माहिती अनुपलब्ध म्हणून प्रदर्शित केली जाते. निर्माता आणि इंटरफेस नेहमी Windows द्वारे उघड होत नाहीत. संपूर्णपणे स्कॅन दरम्यान घडणाऱ्या घटनांकडे लक्ष दिले जात नाही. लॉग मेमरीमध्ये आहे आणि पहिल्या यशस्वी इन्व्हेंटरीनंतर सुरू होतो.

बस अभिज्ञापक आणि पोर्ट पथ सिस्टम टोपोलॉजीचे वर्णन करतात. भौतिक कनेक्टरमध्ये USB 2 आणि SuperSpeed साठी दोन वेगळे मार्ग असू शकतात.

## आर्किटेक्चर आणि प्रमाणीकरण

`scanner.rs` यादी करते; `windows_probe.rs` हबमधून मूळ वाचलेल्या विनंत्या अंतर्भूत करते; `model.rs` मध्ये डेटा आणि डायग्नोस्टिक्स आहेत. `app.rs` पार्श्वभूमी कार्ये आणि निवड हाताळते; `views.rs`, `inspector.rs`, `connection.rs` आणि `theme.rs` egui/eframe सह इंटरफेस काढतात. स्कॅन दरम्यान इंटरफेस परस्परसंवादी राहते आणि पुढील स्कॅन अयशस्वी झाल्यास शेवटचे यशस्वी वाचन राखून ठेवते.

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

लायब्ररी क्रॉस-प्लॅटफॉर्म आहेत आणि विंडोज कोड सशर्त आहे. या पहिल्या वितरणामध्ये macOS/Linux आवृत्त्या प्रमाणित नाहीत.

## गुप्तता

इन्व्हेंटरी टेलीमेट्री किंवा नेटवर्क सेवांशिवाय स्थानिक पातळीवर, केवळ-वाचनीय कार्य करते. मार्गदर्शक लिंक फक्त क्लिकवर उघडतात. JSON अहवालांमध्ये अनुक्रमांक आणि सिस्टम अभिज्ञापक असू शकतात: ते सामायिक करणे आपल्यावर अवलंबून आहे.
