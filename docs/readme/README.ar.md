مستكشف USB الأصلي مكتوب باللغة **Rust**، مع واجهة داكنة وهيكل مرئي وتشخيصات قابلة للقراءة. الإصدار الأول مخصص لنظام التشغيل Windows 10/11.

## أصل المشروع

الفيديو في أصل المشروع: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus).

المشروع مستوحى من استخدامات **WhatCable** على Apple و**USB Device Tree Viewer** على Windows: فهم الأجهزة الطرفية والمحاور وسرعات اتصالات USB الخاصة بها. هذا تنفيذ مستقل.

## سمات

- الكشف الفعلي عن أجهزة USB ووحدات التحكم عبر `nusb`.
- هيكل الشجرة حسب مسار الحافلات والميناء، مع عمق المحور.
- البحث حسب الاسم أو الرقم التسلسلي أو VID:PID؛ USB 3+ المرشحات والمحاور.
- سرعة الارتباط القابلة للتفاوض: 1.5 / 12 / 480 ميجا بايت / ثانية، 5 جيجا بايت / ثانية،
أو الفئة SuperSpeedPlus (10 جيجابت/ثانية أو أكثر).
- مخطط الرحلة: الكمبيوتر، المحاور المتوسطة، الرابط والجهاز.
- ضمن Windows، يتم إجراء استجواب إضافي للمركز بواسطة IOCTL لمعرفة
إمكانيات SuperSpeed التي أعلن عنها الجهاز. ينتج جهاز متوافق مع SuperSpeed متصل عبر USB 2.0 تشخيصًا لقيود المسار.   تتم معالجة لوحات وصل USB 2 المصاحبة لمحاور USB 3 بشكل منفصل لتجنب إسناد فرع 480 ميجا بايت/ثانية إلى خطأ في الكابل.
- معرفات VID/PID، واصف USB، والمراجعة، وبرنامج التشغيل، والمسلسل والواجهات،
عندما يكشف النظام عن هذه المعلومات.
- يتم التحديث تلقائيًا كل ثلاث ثوانٍ، أو يدويًا باستخدام F5.
- سجل الجلسة لآخر 200 تغيير تمت ملاحظته.
- قم بتصدير البيان الكامل بتنسيق JSON (Ctrl+E) وانسخ التفاصيل المحددة.
- دليل متكامل ووضع عرض توضيحي واضح، لا يستخدم أبدًا كنسخة احتياطية
صامت في حالة فشل الكشف.

## يرمي

باستخدام Rust **1.95+** وسلسلة أدوات MSVC وأدوات Visual Studio C++ على Windows. تستخدم الأمثلة RTK لتصفية مخرجات الأوامر؛ بدون RTK، ما عليك سوى إزالة البادئة `rtk`. يقبل البرنامج النصي للتوزيع كلتا الحالتين.

```powershell
rtk cargo run --release
```

يتم إنتاج الثنائي المستقل في `target/release/san-usb-viewer.exe`. يقوم البرنامج النصي `build.ps1` أيضًا بإنشاء توزيع في `dist/`. لا يلزم تعديل برنامج التشغيل أو تثبيت WinUSB للمخزون: لا يتطلب التطبيق واجهات الجهاز.

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

يجب أن يكون المجلد الوجهة للالتقاط موجودًا. إصدار الإصدار عبارة عن تطبيق Windows بدون وحدة تحكم؛ تفضل `cargo run` في تطوير مخزون سطر الأوامر.

## تفسير النتائج

**السرعة المتفاوض عليها** هي سرعة الاتصال، وليست معيارًا لسرعة النسخ. تعتمد السرعات المفيدة بشكل خاص على البروتوكول والأجهزة الطرفية والأجهزة الأخرى التي تشارك الناقل. لا يتم جمع السرعات من أجهزة متعددة لحساب النطاق الترددي المتوفر.

لا يعد كبل USB السلبي جهازًا قابلاً للتعداد بشكل عام. لا يقرأ هذا الإصدار العلامة الإلكترونية الخاصة به ولا طاقة توصيل الطاقة عبر USB ولا نوع الموصل الخاص به. ولذلك فهي لا تدعي أنها تؤكد سرعتها القصوى. يعتمد التشخيص على الارتباط الذي تمت ملاحظته وعلى مؤشرات Windows، إذا كانت متوفرة. قد يكون الارتباط البطيء مقيدًا بالكابل أو المنفذ أو لوحة الوصل أو الجهاز. لا يتم استخدام رقم إصدار واصف USB مطلقًا باعتباره السرعة القصوى.

فئة SuperSpeedPlus لا تميز بين أوضاع 10 و20 جيجابت/ثانية هنا. لم يتم فحص USB4/Thunderbolt وأنفاقهم. لا يتم جرد المنافذ التي لا تحتوي على جهاز متصل. لا يؤدي كابل الشحن الذي لا يحتوي على بيانات إلى إنشاء جهاز مرئي. قد تظهر الأجهزة الداخلية (البلوتوث، الكاميرا المدمجة، إلخ) في شجرة USB.

يتم عرض المعلومات التي يتعذر الوصول إليها على أنها غير متوفرة. لا يتم دائمًا كشف الشركة المصنعة والواجهات بواسطة Windows. قد تمر الأحداث التي تحدث بالكامل بين عمليات الفحص دون أن يلاحظها أحد. السجل موجود في الذاكرة ويبدأ بعد أول عملية جرد ناجحة.

تصف معرفات الناقل ومسارات المنافذ طوبولوجيا النظام. يمكن أن يحتوي الموصل الفعلي على مسارين منفصلين لـ USB 2 وSuperSpeed.

## الهندسة المعمارية والتحقق من الصحة

يقوم `scanner.rs` بإجراء الجرد؛ يقوم `windows_probe.rs` بتغليف طلبات القراءة الأصلية من لوحات الوصل؛ يحتوي `model.rs` على البيانات والتشخيصات. يعالج `app.rs` مهام الخلفية والاختيار؛ تقوم `views.rs` و`inspector.rs` و`connection.rs` و`theme.rs` برسم الواجهة باستخدام egui/eframe. تظل الواجهة تفاعلية أثناء الفحص وتحتفظ بآخر قراءة ناجحة في حالة فشل الفحص التالي.

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

المكتبات مشتركة بين الأنظمة الأساسية ورمز Windows مشروط. لم يتم التحقق من صحة إصدارات macOS/Linux في عملية التسليم الأولى هذه.

## السرية

يعمل المخزون محليًا، للقراءة فقط، بدون القياس عن بعد أو خدمات الشبكة. روابط الدليل تفتح فقط عند النقر. يمكن أن تحتوي تقارير JSON على أرقام تسلسلية ومعرفات النظام: ومشاركتها أمر متروك لك.

## المراجع الفنية

- [مايكروسوفت: IOCTL_USB_GET_NODE_CONNECTION_INFORMATION_EX_V2](https://learn.microsoft.com/en-us/windows-hardware/drivers/ddi/usbioctl/ni-usbioctl-ioctl_usb_get_node_connection_information_ex_v2)
- [egui/eframe](https://github.com/emilk/egui)

رخصة معهد ماساتشوستس للتكنولوجيا. تظل المباني الملحقة خاضعة للتراخيص الخاصة بها.

يحتوي المستودع العام فقط على المصادر والترجمات والخطوط المجانية اللازمة للتجميع. يتم استبعاد قراءات USB والتقاطات التشخيص والصادرات والتفضيلات المحلية وذاكرة التخزين المؤقت وثنائيات التطوير بواسطة `.gitignore`. للإبلاغ عن مشكلة، استخدم الوضع `--demo` أو قم بإزالة الأرقام التسلسلية ومعرفات النظام من تقاريرك قبل مشاركتها.

## اللغات — الإصدار 0.2.0

يتضمن التطبيق **50 لغة واجهة**. انقر فوق رمز اللغة (`FR`، `EN`، وما إلى ذلك) في الجزء العلوي الأيمن لفتح المحول. يمكنك البحث عن لغة باسمها الأصلي أو اسمها باللغة الإنجليزية أو رمزها. يكون التغيير فوريًا ويتم تخزين الاختيار في `%APPDATA%/SanUsbViewer/preferences.json` ضمن Windows. يتم استخدام لغة النظام دون تفضيل؛ تعود اللغة غير المدعومة إلى اللغة الإنجليزية.

ويفضل الاختيار اللغات الأكثر استخدامًا إجمالاً (اللغة الأم واللغة الثانية)، مع تجميع المتغيرات الإقليمية معًا. هذا ليس تصنيفًا رقميًا: تختلف النتائج اعتمادًا على مجموعة اللهجات. وتشمل المتغيرات المختارة الصينية المبسطة، والعربية الفصحى، والنصوص اللاتينية للفولانية والأوزبكية؛ البنجابية تستخدم الغورموخي.

الإنجليزية، الصينية، الهندية، الإسبانية، الفرنسية، العربية، البنغالية، البرتغالية، الروسية، الأردية، الإندونيسية، الألمانية، اليابانية، الماراثية، الفيتنامية، التيلجو، الهوسا، التركية، البنجابية، السواحلية، الفلبينية، التاميلية، الفارسية، الكورية، الأمهرية، التايلاندية، الجاوية، الإيطالية، الغوجاراتية، الكانادية، البهوجبرية، البورمية، البولندية، اليوروبا، اللينجالا، الأورومو، الفولاني، المالايالامية، أوديا، الأوكرانية، السندية، الأوزبكية، الباشتو، السوندانيز، الملايو، الإيغبو، النيبالية، الأذرية، الميثيلي والصومالية.

تتم ترجمة القوائم المنسوخة والتشخيصات ونصوص المساعدة ورسائل النشاط والتفاصيل. يتم الاحتفاظ بالأسماء والمعرفات المقدمة من الأجهزة والنظام. يحتفظ تصدير JSON بمخططه وبيانات المخزون الخاصة به، بغض النظر عن لغة العرض. تظل الوحدات الفنية في **bit/s** (Mbit/s وGbit/s) لتجنب الخلط مع البايتات.

تعتبر الكتالوجات الفرنسية والإنجليزية بمثابة مرجع. اللغات الأخرى هي **الترجمات الآلية**، والتي قد تتطلب تصحيحات لغوية. يتم تضمين ملفات `locales/*.json` في التجميع ويمكن تصحيحها ثم إعادة ترجمتها. لا يتم تنفيذ أي ترجمة عبر الشبكة بواسطة التطبيق: تم تضمين اللغات الخمسين وخطوط Noto بموجب ترخيص SIL Open Font. يستخدم النص العربي مقاطع Unicode ثنائية الاتجاه وأسطر جديدة يتم حسابها قبل التنسيق.

```powershell
# Forcer une langue pour ce lancement, sans remplacer le choix enregistré
rtk cargo run -- --lang ja

# Vérifier les catalogues, les paramètres et les unités de vitesse
rtk python tools/validate_locales.py

# Capture du guide en arabe
rtk cargo run -- --demo --lang ar --page guide --screenshot artifacts/guide-ar.png
```

قد يشير `SAN_USB_VIEWER_CONFIG` إلى ملف تفضيلات آخر للاختبار أو التثبيت المحمول. يتم حفظ رمز اللغة فقط هناك.
