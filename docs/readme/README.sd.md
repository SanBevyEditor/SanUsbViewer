اصلي USB ايڪسپلورر **Rust** ۾ لکيل آهي، هڪ اونداهي انٽرفيس، بصري ٽوپولوجي ۽ پڙهڻ جي قابل تشخيص سان. پهريون نسخو ونڊوز 10/11 لاءِ ارادو ڪيو ويو.

## منصوبي جي اصليت

پروجيڪٽ جي اصل ۾ وڊيو: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus).

پروجيڪٽ ايپل تي **WhatCable** ۽ ونڊوز تي **USB Device Tree Viewer** جي استعمال کان متاثر آهي: پردي کي سمجهڻ، مرڪز ۽ انهن جي USB ڪنيڪشن جي رفتار. هي هڪ آزاد عمل آهي.

## خاصيتون

- `nusb` ذريعي USB ڊوائيسز ۽ ڪنٽرولرز جي حقيقي ڳولا.
- وڻ جي جوڙجڪ بس ۽ بندرگاهن رستي، حب جي کوٽائي سان.
- نالو، سيريل نمبر يا VID ذريعي ڳولھيو: PID؛ USB 3+ فلٽر ۽ حب.
- ڳالھ ٻولھ جي رفتار: 1.5/12/480 Mb/s، 5 Gb/s،
يا زمرو SuperSpeedPlus (10 Gb/s يا وڌيڪ).
- سفر جو نقشو: ڪمپيوٽر، وچولي مرڪز، لنڪ ۽ ڊوائيس.
- ونڊوز جي تحت، IOCTL پاران حب جي اضافي پڇا ڳاڇا ڪرڻ لاء
SuperSpeed صلاحيتون ڊوائيس پاران اعلان ڪيون ويون آهن. هڪ SuperSpeed مطابقت رکندڙ ڊوائيس USB 2.0 ذريعي ڳنڍيل آهي هڪ رستي جي حد جي تشخيص پيدا ڪري ٿي.   USB 2 حب جا ساٿي USB 3 حب سان الڳ الڳ علاج ڪيا وڃن ٿا ته جيئن انهن جي 480 Mb/s برانچ کي ڪيبل فالٽ ڏانهن منسوب ڪرڻ کان پاسو ڪجي.
- VID/PID سڃاڻپ ڪندڙ، USB بيان ڪندڙ، نظرثاني، ڊرائيور، سيريل ۽ انٽرفيس،
جڏهن سسٽم هن معلومات کي ظاهر ڪري ٿو.
- خودڪار تازه ڪاري هر ٽن سيڪنڊن، يا F5 سان دستياب.
- آخري 200 مشاهدو ڪيل تبديلين جو سيشن لاگ.
- JSON (Ctrl+E) ۾ مڪمل بيان برآمد ڪريو ۽ چونڊيل تفصيلن کي نقل ڪريو.
- انٽيگريڊ گائيڊ ۽ واضح مظاهري موڊ، ڪڏهن به بيڪ اپ طور استعمال نه ڪيو ويو
ڳولڻ جي ناڪامي جي صورت ۾ خاموش.

## اڇلائڻ

Rust **1.95+** سان، ونڊوز تي MSVC ٽول چين ۽ Visual Studio C++ اوزار. مثال استعمال ڪن ٿا RTK حڪمن جي پيداوار کي فلٽر ڪرڻ لاءِ؛ RTK کان سواء، صرف `rtk` پريفڪس کي هٽايو. تقسيم اسڪرپٽ ٻنهي صورتن کي قبول ڪري ٿو.

```powershell
rtk cargo run --release
```

اسٽينڊل بائنري `target/release/san-usb-viewer.exe` ۾ پيدا ڪئي وئي آهي. `build.ps1` اسڪرپٽ پڻ `dist/SanUsbViewer/` ۾ تقسيم ٺاهي ٿي. انوینٽري لاءِ WinUSB جي ڪا به ڊرائيور ترميم يا انسٽاليشن ضروري ناهي: ايپليڪيشن کي ڊوائيس انٽرفيس جي ضرورت ناهي.

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

هڪ پڪڙڻ لاء منزل فولڊر موجود هجڻ ضروري آهي. رليز ورشن هڪ ڪنسول کان گهٽ ونڊوز ايپليڪيشن آهي؛ ترجيح ڏيو `cargo run` ترقي ۾ ڪمانڊ لائن انوینٽري لاءِ.

## نتيجن جي تشريح ڪريو

** ڳالهين جي رفتار ** ڪنيڪشن جو آهي، ۽ نقل جي رفتار جو معيار نه آهي. مفيد رفتار خاص طور تي پروٽوڪول تي منحصر آهي، پردي ۽ ٻين ڊوائيسز تي بس شيئرنگ. دستياب بينڊوڊٿ کي ڳڻڻ لاءِ گھڻن ڊوائيسن مان اسپيڊ شامل نه ٿيون ٿين.

هڪ غير فعال USB ڪيبل عام طور تي هڪ ڳڻپيوڪر ڊوائيس نه آهي. هي نسخو نه پڙهي ٿو ان جو اي-مارڪر، نه ئي USB پاور ڊليوري پاور، ۽ نه ئي ان جي ڪنيڪٽر جو قسم. تنهن ڪري اهو دعوي نٿو ڪري ته ان جي وڌ ۾ وڌ رفتار جي تصديق ڪرڻ لاء. تشخيص مشاهدي واري لنڪ تي ٻڌل آهي ۽، جيڪڏهن دستياب هجي، ونڊوز اشارن تي. هڪ سست لنڪ شايد محدود ٿي سگھي ٿي ڪيبل، بندرگاهه، حب، يا ڊوائيس. USB بيان ڪندڙ ورزن نمبر ڪڏهن به وڌ ۾ وڌ رفتار جي طور تي استعمال نه ڪيو ويو آهي.

SuperSpeedPlus زمرو هتي 10 ۽ 20 Gb/s طريقن جي وچ ۾ فرق نٿو ڪري. USB4 / Thunderbolt ۽ انهن جي سرنگن جو معائنو نه ڪيو ويو آهي. بندرگاهن بغير ڪنهن ڊوائيس سان ڳنڍيل آهن ايجاد نه آهن. ڊيٽا کان سواء هڪ چارج ڪيبل هڪ نظر ڊوڙندو پيدا نه ڪندو آھي. اندروني ڊوائيسز (بلوٽوٿ، بلٽ ان ڪئميرا، وغيره) شايد USB وڻ ۾ ظاهر ٿي سگهن ٿيون.

ناقابل رسائي معلومات غير دستياب طور ڏيکاري ٿي. ٺاهيندڙ ۽ انٽرفيس هميشه ونڊوز طرفان ظاهر نه ٿيندا آهن. واقعا جيڪي مڪمل طور تي اسڪين جي وچ ۾ واقع ٿين ٿا، شايد اڻڄاتل ٿي وڃن. لاگ ميموري ۾ آهي ۽ پهرين ڪامياب فهرست کان پوء شروع ٿئي ٿو.

بس جي سڃاڻپ ڪندڙ ۽ بندرگاهن جا رستا سسٽم ٽوپولوجي بيان ڪن ٿا. هڪ جسماني ڪنيڪٽر وٽ USB 2 ۽ SuperSpeed لاءِ ٻه الڳ رستا هوندا.

## فن تعمير ۽ تصديق

`scanner.rs` انوینٽري انجام ڏئي ٿو؛ `windows_probe.rs` حب کان مقامي پڙهڻ جي درخواستن کي شامل ڪري ٿو. `model.rs` ڊيٽا ۽ تشخيص تي مشتمل آهي. `app.rs` پس منظر جي ڪمن ۽ چونڊ کي سنڀاليندو آهي؛ `views.rs`، `inspector.rs`، `connection.rs` ۽ `theme.rs` egui/eframe سان انٽرفيس ٺاھيو. انٽرفيس هڪ اسڪين دوران انٽرفيس رهي ٿو ۽ آخري ڪامياب پڙهڻ کي برقرار رکي ٿو جيڪڏهن ايندڙ اسڪين ناڪام ٿئي.

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

لائبريريون ڪراس پليٽ فارم آهن ۽ ونڊوز ڪوڊ مشروط آهي. macOS/Linux ورجن هن پهرين ترسيل ۾ تصديق ٿيل نه آهن.

## رازداري

انوینٽري مقامي طور تي ڪم ڪري ٿي، صرف پڙهڻ لاءِ، ٽيلي ميٽري يا نيٽ ورڪ سروسز کان سواءِ. گائيڊ لنڪ صرف ڪلڪ ڪرڻ تي کليل آهن. JSON رپورٽون سيريل نمبرن ۽ سسٽم جي سڃاڻپ ڪندڙ تي مشتمل ٿي سگهن ٿيون: انهن کي حصيداري ڪرڻ توهان تي منحصر آهي.

## ٻوليون - ورجن 0.2.0

ايپليڪيشن ۾ شامل آهي **50 انٽرفيس ٻوليون**. ڪلڪ ڪريو ٻولي ڪوڊ (`FR`, `EN`, وغيره) مٿي ساڄي پاسي سوئچر کولڻ لاءِ. توھان ڪنھن ٻولي کي ان جي اصلي نالو، ان جي انگريزي نالو يا ان جي ڪوڊ ذريعي ڳولي سگھو ٿا. تبديلي فوري آهي ۽ چونڊ `%APPDATA%/SanUsbViewer/preferences.json` ۾ محفوظ ٿيل آهي Windows جي تحت. ترجيح کان سواء، سسٽم ٻولي استعمال ڪئي وئي آهي؛ هڪ اڻ سڌريل ٻولي انگريزي ڏانهن موٽائي ٿي.

چونڊ مجموعي طور تي سڀ کان وڌيڪ ڳالهائيندڙ ٻولين کي پسند ڪري ٿو (مادري ٻولي ۽ ٻي ٻولي)، علائقائي مختلف قسمن کي گڏ ڪري. هي هڪ عددي درجه بندي نه آهي: نتيجن جي لحاظ کان مختلف ٻولين جي گروهه جي بنياد تي. منتخب ٿيل مختلف قسمن ۾ شامل آهن آسان چيني، معياري عربي ۽ لاطيني اسڪرپٽ فولاني ۽ ازبڪ؛ پنجابي گرومڪي استعمال ڪري ٿو.

انگريزي، چيني، هندي، هسپانوي، فرينچ، عربي، بنگالي، پرتگالي، روسي، اردو، انڊونيشيائي، جرمن، جاپاني، مراٺي، ويٽنامي، تيلگو، هوسا، ترڪي، پنجابي، سواحلي، فلپائني، تامل، فارسي، ڪورين، امارڪ، ٿائي، جاوي، اطالوي، گجراتي، کناڊا، يوسي، بروزپوري، بروزپوري، پوليشي، پوليشي، گجراتي. فلاني، مليالم، اوڊيا، يوڪريني، سنڌي، ازبڪ، پشتو، سنڊاني، ملئي، اگبو، نيپالي، آذري، ميٿلي ۽ صومالي.

نقل ٿيل مينيو، تشخيص، مدد متن، سرگرمي پيغام ۽ تفصيل مقامي آهن. هارڊويئر ۽ سسٽم پاران مهيا ڪيل نالا ۽ سڃاڻپ برقرار رکيا ويا آهن. JSON ايڪسپورٽ پنهنجي اسڪيما ۽ انوینٽري ڊيٽا کي رکي ٿو، ڊسپلي ٻولي کان سواء. بائيٽ سان مونجهاري کان بچڻ لاءِ ٽيڪنيڪل يونٽ **bit/s** (Mbit/s ۽ Gbit/s) ۾ رهن ٿا.

فرانسيسي ۽ انگريزي ڪيٽلاگ هڪ حوالي طور ڪم ڪن ٿا. ٻيون ٻوليون **خودڪار ترجما** آهن، جن کي لساني سڌارن جي ضرورت ٿي سگھي ٿي. `locales/*.json` فائلون تاليف ۾ شامل آھن ۽ درست ڪري سگھجن ٿيون ۽ پوءِ ٻيهر ٺاھيون وڃن. ايپليڪيشن پاران ڪوبه نيٽ ورڪ ترجمو نه ڪيو ويو آهي: 50 ٻوليون ۽ نوٽو فونٽ شامل آهن، SIL اوپن فونٽ لائسنس جي تحت. عربي متن ٻه طرفي يونيڪوڊ حصا استعمال ڪري ٿو ۽ فارميٽ ڪرڻ کان اڳ ڳڻپ ڪيل نيون لائينون.

```powershell
# Forcer une langue pour ce lancement, sans remplacer le choix enregistré
```
