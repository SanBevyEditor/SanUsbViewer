اصلي USB اکسپلورر په **Rust** کې لیکل شوی، د تیاره انٹرفیس، لید ټوپولوژي او د لوستلو وړ تشخیص سره. لومړۍ نسخه د وینډوز 10/11 لپاره ټاکل شوې.

## د پروژې اصل

د پروژې په اصل کې ویډیو: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus).

پروژه په ایپل کې د **WhatCable** او په وینډوز کې **USB Device Tree Viewer** کارولو څخه الهام اخیستې: د پردیو ، مرکزونو او د دوی د USB اتصال سرعت درک کول. دا یو خپلواک تطبیق دی.

## ځانګړتیاوې

- د `nusb` له لارې د USB وسیلو او کنټرولرونو اصلي کشف.
- د ونې جوړښت د بس او بندر لارې په واسطه، د مرکز ژوروالی سره.
- د نوم، سریال نمبر یا VID په واسطه لټون وکړئ: PID؛ د USB 3+ فلټرونه او مرکزونه.
- د خبرو اترو سرعت: 1.5/12/480 Mb/s، 5 Gb/s،
یا کټګورۍ SuperSpeedPlus (10 Gb/s یا ډیر).
- د سفر ډیاګرام: کمپیوټر، منځمهاله مرکزونه، لینک او وسیله.
- د وینډوز لاندې، د IOCTL لخوا د مرکز اضافي پوښتنې د موندلو لپاره
SuperSpeed وړتیاوې د وسیلې لخوا اعلان شوي. د SuperSpeed مطابقت لرونکی وسیله د USB 2.0 له لارې وصل شوی د لارې محدودیت تشخیص تولیدوي.   د USB 3 هبونو د USB 2 هب ملګري په جلا توګه درملنه کیږي ترڅو د دوی 480 Mb/s شاخ د کیبل غلطی ته منسوب نه شي.
- VID/PID پیژندونکي، د USB تشریح کونکی، بیاکتنه، ډرایور، سریال او انٹرفیسونه،
کله چې سیسټم دا معلومات افشا کوي.
- په هرو دریو ثانیو کې اتوماتیک تازه کول، یا د F5 سره لارښود.
- د وروستي 200 لیدل شوي بدلونونو سیشن لاګ.
- بشپړ بیان په JSON (Ctrl+E) کې صادر کړئ او ټاکل شوي توضیحات کاپي کړئ.
- مدغم لارښود او د څرګندې مظاهرې حالت، هیڅکله د بیک اپ په توګه نه کارول کیږي
د کشف ناکامۍ په صورت کې خاموش.

## وهل

د زنګ سره **1.95+**، په وینډوز کې د MSVC اوزار چین او د لید سټوډیو C++ وسیلې. مثالونه د حکمونو محصول فلټر کولو لپاره RTK کاروي؛ د RTK پرته، یوازې د `rtk` مختګ لرې کړئ. د ویش سکریپټ دواړه قضیې مني.

```powershell
rtk cargo run --release
```

سټنډول بائنری په `target/release/san-usb-viewer.exe` کې تولید شوی. د `build.ps1` سکریپټ هم په `dist/SanUsbViewer/` کې توزیع جوړوي. د موجوداتو لپاره د WinUSB هیڅ ډرایور ترمیم یا نصب کول اړین ندي: غوښتنلیک د وسیلې انٹرفیس ته اړتیا نلري.

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

د نیول کیدو لپاره د منزل فولډر باید شتون ولري. د خوشې کولو نسخه د کنسول پرته وینډوز غوښتنلیک دی؛ د کمانډ لاین لیست لپاره په پراختیا کې `cargo run` غوره کړئ.

## پایلې تشریح کړئ

**د خبرو اترو سرعت** د پیوستون دی، او د کاپي سرعت معیار نه دی. ګټور سرعت په ځانګړي ډول په پروتوکول، پرفیریل او نورو وسایلو پورې اړه لري چې بس شریکوي. د ډیری وسیلو سرعت د موجود بینډ ویت محاسبه کولو لپاره نه اضافه کیږي.

یو غیر فعال USB کیبل عموما د شمیرلو وړ وسیله نه ده. دا نسخه نه خپل ای مارکر لولي، نه د USB بریښنا رسولو ځواک، او نه د دې نښلونکي ډول. له همدې امله دا ادعا نه کوي چې د دې اعظمي سرعت تصدیق کړي. تشخیص د لیدل شوي لینک پراساس دی او که شتون ولري، د وینډوز شاخصونو کې. یو ورو لینک ممکن د کیبل، بندر، مرکز، یا وسیله لخوا محدود وي. د USB توضیحي نسخه شمیره هیڅکله د اعظمي سرعت په توګه نه کارول کیږي.

د SuperSpeedPlus کټګورۍ دلته د 10 او 20 Gb/s حالتونو ترمنځ توپیر نه کوي. USB4 / تندربولټ او د دوی تونلونه ندي معاینه شوي. پرته له وسیلې سره تړل شوي بندرونه اختراع شوي ندي. د ډیټا پرته د چارج کیبل د لید وړ وسیله نه رامینځته کوي. داخلي وسایل (بلوتوت، جوړ شوی کیمره، او نور) کیدای شي په USB ونې کې ښکاره شي.

د لاس رسی وړ معلومات د شتون نه په توګه ښودل کیږي. جوړونکی او انٹرفیس تل د وینډوز لخوا نه افشا کیږي. هغه پیښې چې په بشپړه توګه د سکینونو ترمنځ واقع کیږي ممکن د پام وړ نه وي. لاګ په حافظه کې دی او د لومړي بریالي لیست څخه وروسته پیل کیږي.

د بس پیژندونکي او د بندر لارې د سیسټم ټوپولوژي تشریح کوي. یو فزیکي نښلونکی کولی شي د USB 2 او SuperSpeed لپاره دوه جلا لارې ولري.

## معماري او اعتبار

`scanner.rs` لیست ترسره کوي؛ `windows_probe.rs` د مرکز څخه د اصلي لوستلو غوښتنې پوښي؛ `model.rs` ډیټا او تشخیص لري. `app.rs` د شالید دندې او انتخاب اداره کوي؛ `views.rs`، `inspector.rs`، `connection.rs` او `theme.rs` د egui/eframe سره انٹرفیس رسموي. انٹرفیس د سکین پرمهال متقابل پاتې کیږي او وروستی بریالي لوستل ساتي که چیرې راتلونکی سکین ناکام شي.

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

کتابتونونه کراس پلیټ فارم دي او د وینډوز کوډ مشروط دی. د macOS/Linux نسخې پدې لومړي تحویل کې نه تایید شوي.

## ژبې — نسخه 0.2.0

په غوښتنلیک کې **50 انٹرفیس ژبې** شامل دي. د سویچر د خلاصولو لپاره په پورتنۍ ښۍ خوا کې د ژبې کوډ (`FR`, `EN`, etc.) کلیک وکړئ. تاسو کولی شئ یوه ژبه د هغې اصلي نوم، د انګلیسي نوم یا د هغې کوډ په واسطه وپلټئ. بدلون سمدستي دی او انتخاب په `%APPDATA%/SanUsbViewer/preferences.json` کې د وینډوز لاندې زیرمه شوی. د غوره توب پرته، د سیسټم ژبه کارول کیږي؛ یوه بې ملاتړه ژبه انګلیسي ته راګرځي.

انتخاب په ټولیزه توګه د ډیرو ویلو ژبو (مورنۍ ژبه او دویمه ژبه) خوښوي، سیمه ایز ډولونه سره یوځای کوي. دا عددي طبقه بندي نه ده: پایلې د ژبو د ګروپ کولو پورې اړه لري. په ټاکل شوي ډولونو کې ساده چینایي، معیاري عربي او د فلاني او ازبکي لاتیني رسم الخط شامل دي؛ پنجابي ګورمکي کاروي.

انګلیسي، چینایي، هندي، هسپانوي، فرانسوي، عربي، بنګالي، پرتګالي، روسی، اردو، اندونیزیا، الماني، جاپاني، مراټي، ویتنامی، تیلوګو، هوسا، ترکي، پنجابي، سواحلي، فلیپیني، تامل، فارسي، کوریايي، اماریک، تای، جاویاني، ایټالوی، ګجراتي، کناډا، یووژپوری، بوجپوری، بوجپوری، پولیشی، بوجپوری، ګجراتی فولاني، ملیالم، اوډیا، اوکرایني، سنداني، ازبکي، پښتو، سنډانیز، مالای، ایګبو، نیپالي، آذري، میتیلي او سومالي.

کاپي شوي مینو، تشخیص، د مرستې متنونه، د فعالیت پیغامونه او توضیحات ځایی شوي دي. د هارډویر او سیسټم لخوا چمتو شوي نومونه او پیژندونکي ساتل کیږي. د JSON صادرات خپل سکیما او د لیست ډاټا ساتي، پرته له دې چې د ښودلو ژبې په پام کې نیولو سره. تخنیکي واحدونه په **bit/s** (Mbit/s او Gbit/s) کې پاتې کیږي ترڅو د بایټس سره د ګډوډۍ مخه ونیسي.

فرانسوي او انګلیسي کتلاګ د یوې مرجع په توګه کار کوي. نورې ژبې **اوتوماتیک ژباړې** دي، چې کیدای شي ژبني سمون ته اړتیا ولري. د `locales/*.json` فایلونه په تالیف کې شامل شوي او سم کیدی شي او بیا بیا تنظیم شي. د غوښتنلیک لخوا د شبکې هیڅ ژباړه نه ترسره کیږي: 50 ژبې او نوټو فونټونه د SIL خلاص فونټ لایسنس لاندې ځای په ځای شوي دي. عربي متن دوه طرفه یونیکوډ برخې کاروي او د فارمیټ کولو دمخه حساب شوي نوي لیکې.

```powershell
# Forcer une langue pour ce lancement, sans remplacer le choix enregistré

# Vérifier les catalogues, les paramètres et les unités de vitesse
```
