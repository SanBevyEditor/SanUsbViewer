** ಪ್ರಸ್ತುತ ಆವೃತ್ತಿ: `0.2.0`** — MIT ಪರವಾನಗಿ.

![San USB Viewer](../../assets/screenshots/SanUsbViewer.jpg)

ಸ್ಥಳೀಯ USB ಎಕ್ಸ್‌ಪ್ಲೋರರ್ ಅನ್ನು ಡಾರ್ಕ್ ಇಂಟರ್‌ಫೇಸ್, ದೃಶ್ಯ ಟೋಪೋಲಜಿ ಮತ್ತು ಓದಬಲ್ಲ ಡಯಾಗ್ನೋಸ್ಟಿಕ್‌ಗಳೊಂದಿಗೆ **ರಸ್ಟ್** ನಲ್ಲಿ ಬರೆಯಲಾಗಿದೆ. ವಿಂಡೋಸ್ 10/11 ಗಾಗಿ ಉದ್ದೇಶಿಸಲಾದ ಮೊದಲ ಆವೃತ್ತಿ.

## ಯೋಜನೆಯ ಮೂಲ

ಯೋಜನೆಯ ಮೂಲದಲ್ಲಿ ವೀಡಿಯೊ: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus).

ಯೋಜನೆಯು Apple ನಲ್ಲಿ **WhatCable** ಮತ್ತು Windows ನಲ್ಲಿ **USB Device Tree Viewer** ಬಳಕೆಗಳಿಂದ ಪ್ರೇರಿತವಾಗಿದೆ: ಪೆರಿಫೆರಲ್‌ಗಳು, ಹಬ್‌ಗಳು ಮತ್ತು ಅವುಗಳ USB ಸಂಪರ್ಕಗಳ ವೇಗವನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವುದು. ಇದು ಸ್ವತಂತ್ರ ಅನುಷ್ಠಾನವಾಗಿದೆ.

## ವೈಶಿಷ್ಟ್ಯಗಳು

- `nusb` ಮೂಲಕ USB ಸಾಧನಗಳು ಮತ್ತು ನಿಯಂತ್ರಕಗಳ ನಿಜವಾದ ಪತ್ತೆ.
- ಹಬ್ ಆಳದೊಂದಿಗೆ ಬಸ್ ಮತ್ತು ಬಂದರು ಮಾರ್ಗದ ಮೂಲಕ ಮರದ ರಚನೆ.
- ಹೆಸರು, ಸರಣಿ ಸಂಖ್ಯೆ ಅಥವಾ VID:PID ಮೂಲಕ ಹುಡುಕಿ; USB 3+ ಫಿಲ್ಟರ್‌ಗಳು ಮತ್ತು ಹಬ್‌ಗಳು.
- ಮಾತುಕತೆಯ ಲಿಂಕ್ ವೇಗ: 1.5 / 12 / 480 Mb/s, 5 Gb/s,
ಅಥವಾ ವರ್ಗ SuperSpeedPlus (10 Gb/s ಅಥವಾ ಹೆಚ್ಚು).
- ಜರ್ನಿ ರೇಖಾಚಿತ್ರ: ಕಂಪ್ಯೂಟರ್, ಮಧ್ಯಂತರ ಕೇಂದ್ರಗಳು, ಲಿಂಕ್ ಮತ್ತು ಸಾಧನ.
- ವಿಂಡೋಸ್ ಅಡಿಯಲ್ಲಿ, IOCTL ನಿಂದ ಹಬ್‌ನ ಹೆಚ್ಚುವರಿ ವಿಚಾರಣೆಯನ್ನು ಕಂಡುಹಿಡಿಯಲು
SuperSpeed ಸಾಮರ್ಥ್ಯಗಳನ್ನು ಸಾಧನವು ಘೋಷಿಸಿದೆ. USB 2.0 ಮೂಲಕ ಸಂಪರ್ಕಗೊಂಡಿರುವ SuperSpeed ಹೊಂದಾಣಿಕೆಯ ಸಾಧನವು ಮಾರ್ಗದ ಮಿತಿಯ ರೋಗನಿರ್ಣಯವನ್ನು ಉತ್ಪಾದಿಸುತ್ತದೆ.   USB 3 ಹಬ್‌ಗಳ USB 2 ಹಬ್‌ಗಳ ಸಹಚರರು ತಮ್ಮ 480 Mb/s ಶಾಖೆಯನ್ನು ಕೇಬಲ್ ದೋಷಕ್ಕೆ ಆರೋಪಿಸುವುದನ್ನು ತಪ್ಪಿಸಲು ಪ್ರತ್ಯೇಕವಾಗಿ ಪರಿಗಣಿಸಲಾಗುತ್ತದೆ.
- VID/PID ಗುರುತಿಸುವಿಕೆಗಳು, USB ಡಿಸ್ಕ್ರಿಪ್ಟರ್, ಪರಿಷ್ಕರಣೆ, ಚಾಲಕ, ಸರಣಿ ಮತ್ತು ಇಂಟರ್ಫೇಸ್‌ಗಳು,
ಸಿಸ್ಟಮ್ ಈ ಮಾಹಿತಿಯನ್ನು ಬಹಿರಂಗಪಡಿಸಿದಾಗ.
- ಪ್ರತಿ ಮೂರು ಸೆಕೆಂಡಿಗೆ ಸ್ವಯಂಚಾಲಿತ ಅಪ್‌ಡೇಟ್, ಅಥವಾ F5 ನೊಂದಿಗೆ ಕೈಪಿಡಿ.
- ಕಳೆದ 200 ಗಮನಿಸಿದ ಬದಲಾವಣೆಗಳ ಸೆಷನ್ ಲಾಗ್.
- JSON (Ctrl+E) ನಲ್ಲಿ ಸಂಪೂರ್ಣ ಹೇಳಿಕೆಯನ್ನು ರಫ್ತು ಮಾಡಿ ಮತ್ತು ಆಯ್ಕೆಮಾಡಿದ ವಿವರಗಳನ್ನು ನಕಲಿಸಿ.
- ಸಂಯೋಜಿತ ಮಾರ್ಗದರ್ಶಿ ಮತ್ತು ಸ್ಪಷ್ಟವಾದ ಪ್ರದರ್ಶನ ಮೋಡ್, ಎಂದಿಗೂ ಬ್ಯಾಕಪ್ ಆಗಿ ಬಳಸಲಾಗುವುದಿಲ್ಲ
ಪತ್ತೆ ವೈಫಲ್ಯದ ಸಂದರ್ಭದಲ್ಲಿ ಮೌನ.

## ಎಸೆಯಿರಿ

ರಸ್ಟ್ ಜೊತೆಗೆ **1.95+**, ವಿಂಡೋಸ್‌ನಲ್ಲಿ MSVC ಟೂಲ್‌ಚೈನ್ ಮತ್ತು ವಿಷುಯಲ್ ಸ್ಟುಡಿಯೋ C++ ಉಪಕರಣಗಳು. ಆಜ್ಞೆಗಳ ಔಟ್‌ಪುಟ್ ಅನ್ನು ಫಿಲ್ಟರ್ ಮಾಡಲು ಉದಾಹರಣೆಗಳು RTK ಅನ್ನು ಬಳಸುತ್ತವೆ; RTK ಇಲ್ಲದೆ, ಕೇವಲ `rtk` ಪೂರ್ವಪ್ರತ್ಯಯವನ್ನು ತೆಗೆದುಹಾಕಿ. ವಿತರಣಾ ಸ್ಕ್ರಿಪ್ಟ್ ಎರಡೂ ಪ್ರಕರಣಗಳನ್ನು ಸ್ವೀಕರಿಸುತ್ತದೆ.

```powershell
rtk cargo run --release
```

ಸ್ವತಂತ್ರ ಬೈನರಿಯನ್ನು `target/release/san-usb-viewer.exe` ನಲ್ಲಿ ಉತ್ಪಾದಿಸಲಾಗುತ್ತದೆ. `build.ps1` ಸ್ಕ್ರಿಪ್ಟ್ ಸಹ `dist/SanUsbViewer/` ನಲ್ಲಿ ವಿತರಣೆಯನ್ನು ರಚಿಸುತ್ತದೆ. ದಾಸ್ತಾನುಗಳಿಗೆ ಯಾವುದೇ ಚಾಲಕ ಮಾರ್ಪಾಡು ಅಥವಾ WinUSB ಸ್ಥಾಪನೆ ಅಗತ್ಯವಿಲ್ಲ: ಅಪ್ಲಿಕೇಶನ್‌ಗೆ ಸಾಧನ ಇಂಟರ್ಫೇಸ್‌ಗಳ ಅಗತ್ಯವಿಲ್ಲ.

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

ಕ್ಯಾಪ್ಚರ್‌ಗಾಗಿ ಗಮ್ಯಸ್ಥಾನ ಫೋಲ್ಡರ್ ಅಸ್ತಿತ್ವದಲ್ಲಿರಬೇಕು. ಬಿಡುಗಡೆಯ ಆವೃತ್ತಿಯು ಕನ್ಸೋಲ್-ಕಡಿಮೆ ವಿಂಡೋಸ್ ಅಪ್ಲಿಕೇಶನ್ ಆಗಿದೆ; ಕಮಾಂಡ್ ಲೈನ್ ಇನ್ವೆಂಟರಿಗಾಗಿ ಅಭಿವೃದ್ಧಿಯಲ್ಲಿ `cargo run` ಗೆ ಆದ್ಯತೆ ನೀಡಿ.

## ಫಲಿತಾಂಶಗಳನ್ನು ಅರ್ಥೈಸಿಕೊಳ್ಳಿ

** ಮಾತುಕತೆಯ ವೇಗ** ಸಂಪರ್ಕದ ವೇಗವಾಗಿದೆ ಮತ್ತು ನಕಲು ವೇಗದ ಮಾನದಂಡವಲ್ಲ. ಉಪಯುಕ್ತ ವೇಗವು ನಿರ್ದಿಷ್ಟವಾಗಿ ಪ್ರೋಟೋಕಾಲ್, ಬಾಹ್ಯ ಮತ್ತು ಬಸ್ ಅನ್ನು ಹಂಚಿಕೊಳ್ಳುವ ಇತರ ಸಾಧನಗಳ ಮೇಲೆ ಅವಲಂಬಿತವಾಗಿರುತ್ತದೆ. ಲಭ್ಯವಿರುವ ಬ್ಯಾಂಡ್‌ವಿಡ್ತ್ ಅನ್ನು ಲೆಕ್ಕಾಚಾರ ಮಾಡಲು ಬಹು ಸಾಧನಗಳಿಂದ ವೇಗವನ್ನು ಸೇರಿಸುವುದಿಲ್ಲ.

ನಿಷ್ಕ್ರಿಯ USB ಕೇಬಲ್ ಸಾಮಾನ್ಯವಾಗಿ ಎಣಿಸಬಹುದಾದ ಸಾಧನವಲ್ಲ. ಈ ಆವೃತ್ತಿಯು ಅದರ ಇ-ಮಾರ್ಕರ್ ಅಥವಾ USB ಪವರ್ ಡೆಲಿವರಿ ಪವರ್ ಅಥವಾ ಅದರ ಕನೆಕ್ಟರ್ ಪ್ರಕಾರವನ್ನು ಓದುವುದಿಲ್ಲ. ಆದ್ದರಿಂದ ಇದು ತನ್ನ ಗರಿಷ್ಠ ವೇಗವನ್ನು ಪ್ರಮಾಣೀಕರಿಸಲು ಹೇಳಿಕೊಳ್ಳುವುದಿಲ್ಲ. ರೋಗನಿರ್ಣಯವು ಗಮನಿಸಿದ ಲಿಂಕ್ ಅನ್ನು ಆಧರಿಸಿದೆ ಮತ್ತು ಲಭ್ಯವಿದ್ದರೆ, ವಿಂಡೋಸ್ ಸೂಚಕಗಳಲ್ಲಿ. ನಿಧಾನವಾದ ಲಿಂಕ್ ಅನ್ನು ಕೇಬಲ್, ಪೋರ್ಟ್, ಹಬ್ ಅಥವಾ ಸಾಧನದಿಂದ ಸೀಮಿತಗೊಳಿಸಬಹುದು. USB ಡಿಸ್ಕ್ರಿಪ್ಟರ್ ಆವೃತ್ತಿ ಸಂಖ್ಯೆಯನ್ನು ಗರಿಷ್ಠ ವೇಗವಾಗಿ ಎಂದಿಗೂ ಬಳಸಲಾಗುವುದಿಲ್ಲ.

SuperSpeedPlus ವರ್ಗವು ಇಲ್ಲಿ 10 ಮತ್ತು 20 Gb/s ಮೋಡ್‌ಗಳ ನಡುವೆ ವ್ಯತ್ಯಾಸವನ್ನು ತೋರಿಸುವುದಿಲ್ಲ. USB4/Thunderbolt ಮತ್ತು ಅವುಗಳ ಸುರಂಗಗಳನ್ನು ಪರೀಕ್ಷಿಸಲಾಗಿಲ್ಲ. ಲಗತ್ತಿಸಲಾದ ಸಾಧನವಿಲ್ಲದ ಪೋರ್ಟ್‌ಗಳನ್ನು ದಾಸ್ತಾನು ಮಾಡಲಾಗಿಲ್ಲ. ಡೇಟಾ ಇಲ್ಲದೆ ಚಾರ್ಜಿಂಗ್ ಕೇಬಲ್ ಗೋಚರ ಸಾಧನವನ್ನು ರಚಿಸುವುದಿಲ್ಲ. USB ಟ್ರೀಯಲ್ಲಿ ಆಂತರಿಕ ಸಾಧನಗಳು (ಬ್ಲೂಟೂತ್, ಅಂತರ್ನಿರ್ಮಿತ ಕ್ಯಾಮೆರಾ, ಇತ್ಯಾದಿ) ಕಾಣಿಸಿಕೊಳ್ಳಬಹುದು.

ಪ್ರವೇಶಿಸಲಾಗದ ಮಾಹಿತಿಯನ್ನು ಲಭ್ಯವಿಲ್ಲ ಎಂದು ಪ್ರದರ್ಶಿಸಲಾಗುತ್ತದೆ. ತಯಾರಕರು ಮತ್ತು ಇಂಟರ್ಫೇಸ್‌ಗಳು ಯಾವಾಗಲೂ ವಿಂಡೋಸ್‌ನಿಂದ ಬಹಿರಂಗಗೊಳ್ಳುವುದಿಲ್ಲ. ಸ್ಕ್ಯಾನ್‌ಗಳ ನಡುವೆ ಸಂಪೂರ್ಣವಾಗಿ ಸಂಭವಿಸುವ ಘಟನೆಗಳು ಗಮನಕ್ಕೆ ಬಾರದೆ ಹೋಗಬಹುದು. ಲಾಗ್ ಮೆಮೊರಿಯಲ್ಲಿದೆ ಮತ್ತು ಮೊದಲ ಯಶಸ್ವಿ ದಾಸ್ತಾನು ನಂತರ ಪ್ರಾರಂಭವಾಗುತ್ತದೆ.

ಬಸ್ ಗುರುತಿಸುವಿಕೆಗಳು ಮತ್ತು ಪೋರ್ಟ್ ಮಾರ್ಗಗಳು ಸಿಸ್ಟಮ್ ಟೋಪೋಲಜಿಯನ್ನು ವಿವರಿಸುತ್ತದೆ. ಒಂದು ಭೌತಿಕ ಕನೆಕ್ಟರ್ USB 2 ಮತ್ತು SuperSpeed ಗಾಗಿ ಎರಡು ಪ್ರತ್ಯೇಕ ಮಾರ್ಗಗಳನ್ನು ಹೊಂದಬಹುದು.

## ಆರ್ಕಿಟೆಕ್ಚರ್ ಮತ್ತು ಮೌಲ್ಯೀಕರಣ

`scanner.rs` ದಾಸ್ತಾನು ನಿರ್ವಹಿಸುತ್ತದೆ; `windows_probe.rs` ಹಬ್‌ಗಳಿಂದ ಸ್ಥಳೀಯ ಓದುವ ವಿನಂತಿಗಳನ್ನು ಎನ್‌ಕ್ಯಾಪ್ಸುಲೇಟ್ ಮಾಡುತ್ತದೆ; `model.rs` ಡೇಟಾ ಮತ್ತು ಡಯಾಗ್ನೋಸ್ಟಿಕ್ಸ್ ಅನ್ನು ಒಳಗೊಂಡಿದೆ. `app.rs` ಹಿನ್ನೆಲೆ ಕಾರ್ಯಗಳನ್ನು ಮತ್ತು ಆಯ್ಕೆಯನ್ನು ನಿಭಾಯಿಸುತ್ತದೆ; `views.rs`, `inspector.rs`, `connection.rs` ಮತ್ತು `theme.rs` egui/eframe ನೊಂದಿಗೆ ಇಂಟರ್ಫೇಸ್ ಅನ್ನು ಸೆಳೆಯುತ್ತವೆ. ಇಂಟರ್ಫೇಸ್ ಸ್ಕ್ಯಾನ್ ಸಮಯದಲ್ಲಿ ಸಂವಾದಾತ್ಮಕವಾಗಿರುತ್ತದೆ ಮತ್ತು ಮುಂದಿನ ಸ್ಕ್ಯಾನ್ ವಿಫಲವಾದಲ್ಲಿ ಕೊನೆಯ ಯಶಸ್ವಿ ಓದುವಿಕೆಯನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ.

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

ಲೈಬ್ರರಿಗಳು ಕ್ರಾಸ್ ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ ಮತ್ತು ವಿಂಡೋಸ್ ಕೋಡ್ ಷರತ್ತುಬದ್ಧವಾಗಿದೆ. ಈ ಮೊದಲ ವಿತರಣೆಯಲ್ಲಿ MacOS/Linux ಆವೃತ್ತಿಗಳನ್ನು ಮೌಲ್ಯೀಕರಿಸಲಾಗಿಲ್ಲ.

## ಗೌಪ್ಯತೆ

ಟೆಲಿಮೆಟ್ರಿ ಅಥವಾ ನೆಟ್‌ವರ್ಕ್ ಸೇವೆಗಳಿಲ್ಲದೆ ಇನ್ವೆಂಟರಿ ಸ್ಥಳೀಯವಾಗಿ, ಓದಲು ಮಾತ್ರ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ. ಮಾರ್ಗದರ್ಶಿ ಲಿಂಕ್‌ಗಳು ಕ್ಲಿಕ್‌ನಲ್ಲಿ ಮಾತ್ರ ತೆರೆದುಕೊಳ್ಳುತ್ತವೆ. JSON ವರದಿಗಳು ಸರಣಿ ಸಂಖ್ಯೆಗಳು ಮತ್ತು ಸಿಸ್ಟಮ್ ಐಡೆಂಟಿಫೈಯರ್‌ಗಳನ್ನು ಒಳಗೊಂಡಿರಬಹುದು: ಅವುಗಳನ್ನು ಹಂಚಿಕೊಳ್ಳುವುದು ನಿಮಗೆ ಬಿಟ್ಟದ್ದು.

## ಭಾಷೆಗಳು - ಆವೃತ್ತಿ 0.2.0

ಅಪ್ಲಿಕೇಶನ್ **50 ಇಂಟರ್ಫೇಸ್ ಭಾಷೆಗಳನ್ನು ಒಳಗೊಂಡಿದೆ**. ಸ್ವಿಚರ್ ತೆರೆಯಲು ಮೇಲಿನ ಬಲಭಾಗದಲ್ಲಿರುವ ಭಾಷಾ ಕೋಡ್ (`FR`, `EN`, ಇತ್ಯಾದಿ) ಕ್ಲಿಕ್ ಮಾಡಿ. ನೀವು ಭಾಷೆಯನ್ನು ಅದರ ಸ್ಥಳೀಯ ಹೆಸರು, ಅದರ ಇಂಗ್ಲಿಷ್ ಹೆಸರು ಅಥವಾ ಅದರ ಕೋಡ್ ಮೂಲಕ ಹುಡುಕಬಹುದು. ಬದಲಾವಣೆಯು ತಕ್ಷಣವೇ ಮತ್ತು ಆಯ್ಕೆಯನ್ನು ವಿಂಡೋಸ್ ಅಡಿಯಲ್ಲಿ `%APPDATA%/SanUsbViewer/preferences.json` ನಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾಗಿದೆ. ಆದ್ಯತೆಯಿಲ್ಲದೆ, ಸಿಸ್ಟಮ್ ಭಾಷೆಯನ್ನು ಬಳಸಲಾಗುತ್ತದೆ; ಬೆಂಬಲವಿಲ್ಲದ ಭಾಷೆ ಇಂಗ್ಲಿಷ್‌ಗೆ ಹಿಂತಿರುಗುತ್ತದೆ.

ಆಯ್ಕೆಯು ಒಟ್ಟಾರೆಯಾಗಿ ಹೆಚ್ಚು ಮಾತನಾಡುವ ಭಾಷೆಗಳಿಗೆ (ಮಾತೃಭಾಷೆ ಮತ್ತು ಎರಡನೇ ಭಾಷೆ) ಒಲವು ನೀಡುತ್ತದೆ, ಪ್ರಾದೇಶಿಕ ರೂಪಾಂತರಗಳನ್ನು ಒಟ್ಟುಗೂಡಿಸುತ್ತದೆ. ಇದು ಸಂಖ್ಯಾತ್ಮಕ ವರ್ಗೀಕರಣವಲ್ಲ: ಉಪಭಾಷೆಗಳ ಗುಂಪನ್ನು ಅವಲಂಬಿಸಿ ಫಲಿತಾಂಶಗಳು ಬದಲಾಗುತ್ತವೆ. ಆಯ್ಕೆ ಮಾಡಲಾದ ರೂಪಾಂತರಗಳಲ್ಲಿ ಸರಳೀಕೃತ ಚೈನೀಸ್, ಸ್ಟ್ಯಾಂಡರ್ಡ್ ಅರೇಬಿಕ್ ಮತ್ತು ಫುಲಾನಿ ಮತ್ತು ಉಜ್ಬೆಕ್‌ನ ಲ್ಯಾಟಿನ್ ಲಿಪಿಗಳು ಸೇರಿವೆ; ಪಂಜಾಬಿ ಗುರುಮುಖಿಯನ್ನು ಬಳಸುತ್ತದೆ.

ಇಂಗ್ಲಿಷ್, ಚೈನೀಸ್, ಹಿಂದಿ, ಸ್ಪ್ಯಾನಿಷ್, ಫ್ರೆಂಚ್, ಅರೇಬಿಕ್, ಬೆಂಗಾಲಿ, ಪೋರ್ಚುಗೀಸ್, ರಷ್ಯನ್, ಉರ್ದು, ಇಂಡೋನೇಷಿಯನ್, ಜರ್ಮನ್, ಜಪಾನೀಸ್, ಮರಾಠಿ, ವಿಯೆಟ್ನಾಮೀಸ್, ತೆಲುಗು, ಹೌಸಾ, ಟರ್ಕಿಶ್, ಪಂಜಾಬಿ, ಸ್ವಹಿಲಿ, ಫಿಲಿಪಿನೋ, ತಮಿಳು, ಪರ್ಷಿಯನ್, ಕೊರಿಯನ್, ಅಂಹರಿಕ್, ಥಾಯ್, ಜಾವಾನೀಸ್, ಇಟಾಲಿಯನ್, ಗುಜರಾತಿ, ಕನ್ನಡ, ಭೋಜ್‌ಪುರಿ, ಬರ್ಮೀಸ್, ಪೋಲಿಷ್, ಓ ಯೊರುಬಾ, ಮಲಯಾಳಂ, ಓ ಯೊರುಬಾ, ಎಲ್. ಉಕ್ರೇನಿಯನ್, ಸಿಂಧಿ, ಉಜ್ಬೆಕ್, ಪಾಷ್ಟೋ, ಸುಂದನೀಸ್, ಮಲಯ, ಇಗ್ಬೊ, ನೇಪಾಳಿ, ಅಜೆರಿ, ಮೈಥಿಲಿ ಮತ್ತು ಸೊಮಾಲಿ.

ನಕಲಿಸಿದ ಮೆನುಗಳು, ಡಯಾಗ್ನೋಸ್ಟಿಕ್ಸ್, ಸಹಾಯ ಪಠ್ಯಗಳು, ಚಟುವಟಿಕೆ ಸಂದೇಶಗಳು ಮತ್ತು ವಿವರಗಳನ್ನು ಸ್ಥಳೀಕರಿಸಲಾಗಿದೆ. ಹಾರ್ಡ್‌ವೇರ್ ಮತ್ತು ಸಿಸ್ಟಮ್ ಒದಗಿಸಿದ ಹೆಸರುಗಳು ಮತ್ತು ಗುರುತಿಸುವಿಕೆಗಳನ್ನು ಉಳಿಸಿಕೊಳ್ಳಲಾಗಿದೆ. JSON ರಫ್ತು ಡಿಸ್ಪ್ಲೇ ಭಾಷೆಯ ಹೊರತಾಗಿಯೂ ಅದರ ಸ್ಕೀಮಾ ಮತ್ತು ದಾಸ್ತಾನು ಡೇಟಾವನ್ನು ಇರಿಸುತ್ತದೆ. ಬೈಟ್‌ಗಳೊಂದಿಗೆ ಗೊಂದಲವನ್ನು ತಪ್ಪಿಸಲು ತಾಂತ್ರಿಕ ಘಟಕಗಳು **bit/s** (Mbit/s ಮತ್ತು Gbit/s) ನಲ್ಲಿ ಉಳಿಯುತ್ತವೆ.

ಫ್ರೆಂಚ್ ಮತ್ತು ಇಂಗ್ಲಿಷ್ ಕ್ಯಾಟಲಾಗ್‌ಗಳು ಉಲ್ಲೇಖವಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತವೆ. ಇತರ ಭಾಷೆಗಳು **ಸ್ವಯಂಚಾಲಿತ ಅನುವಾದಗಳು**, ಇವುಗಳಿಗೆ ಭಾಷಾ ತಿದ್ದುಪಡಿಗಳ ಅಗತ್ಯವಿರಬಹುದು. `locales/*.json` ಫೈಲ್‌ಗಳನ್ನು ಸಂಕಲನದಲ್ಲಿ ಸೇರಿಸಲಾಗಿದೆ ಮತ್ತು ಸರಿಪಡಿಸಬಹುದು ಮತ್ತು ನಂತರ ಮರುಸಂಕಲಿಸಬಹುದು. ಅಪ್ಲಿಕೇಶನ್‌ನಿಂದ ಯಾವುದೇ ನೆಟ್‌ವರ್ಕ್ ಅನುವಾದವನ್ನು ಕೈಗೊಳ್ಳಲಾಗುವುದಿಲ್ಲ: SIL ಓಪನ್ ಫಾಂಟ್ ಪರವಾನಗಿ ಅಡಿಯಲ್ಲಿ 50 ಭಾಷೆಗಳು ಮತ್ತು ನೋಟೊ ಫಾಂಟ್‌ಗಳನ್ನು ಎಂಬೆಡ್ ಮಾಡಲಾಗಿದೆ. ಅರೇಬಿಕ್ ಪಠ್ಯವು ದ್ವಿಮುಖ ಯುನಿಕೋಡ್ ವಿಭಾಗಗಳನ್ನು ಮತ್ತು ಫಾರ್ಮ್ಯಾಟ್ ಮಾಡುವ ಮೊದಲು ಲೆಕ್ಕಹಾಕಿದ ಹೊಸ ಸಾಲುಗಳನ್ನು ಬಳಸುತ್ತದೆ.
