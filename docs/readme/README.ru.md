# San USB Viewer

**Текущая версия: `0.2.0`** — лицензия MIT.

![San USB Viewer](../../assets/screenshots/SanUsbViewer.jpg)

Собственный USB Explorer, написанный на **Rust**, с темным интерфейсом, визуальной топологией и читаемой диагностикой. Первая версия предназначена для Windows 10/11.

## Происхождение проекта

Видео в начале проекта: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus).

Проект вдохновлен использованием **WhatCable** в Apple и **USB Device Tree Viewer** в Windows: понимание периферийных устройств, концентраторов и скорости их USB-соединений. Это независимая реализация.

## Функции

- Фактическое обнаружение USB-устройств и контроллеров через `nusb`.
- Древовидная структура по маршрутам шин и портов с глубиной концентратора.
- Поиск по имени, серийному номеру или VID:PID; Фильтры и концентраторы USB 3+.
- Согласованная скорость соединения: 1,5/12/480 Мбит/с, 5 Гбит/с,
или категория SuperSpeedPlus (10 Гбит/с и более).
- Схема путешествия: компьютер, промежуточные концентраторы, канал и устройство.
- Под Windows дополнительный опрос хаба по IOCTL для выяснения
SuperSpeed Возможности заявленного устройства. Устройство, совместимое с SuperSpeed, подключенное через USB 2.0, производит диагностику ограничения пути.   Концентраторы USB 2, сопутствующие концентраторам USB 3, рассматриваются отдельно, чтобы избежать приписания их ветви со скоростью 480 Мбит/с к неисправности кабеля.
- Идентификаторы VID/PID, дескриптор USB, версия, драйвер, последовательный порт и интерфейсы,
когда система раскрывает эту информацию.
- Автоматическое обновление каждые три секунды или вручную по F5.

- Экспортируйте полный оператор в формате JSON (Ctrl+E) и скопируйте выбранные данные.
- Встроенное руководство и подробный демонстрационный режим, никогда не используемые в качестве резервной копии.

## Бросать

С помощью Rust **1.95+**, набора инструментов MSVC и инструментов Visual Studio C++ для Windows. В примерах используется RTK для фильтрации вывода команд; без RTK просто удалите префикс `rtk`. Скрипт распространения принимает оба случая.

```powershell
rtk cargo run --release
```

Автономный двоичный файл создается в `target/release/san-usb-viewer.exe`. Скрипт `build.ps1` также создает дистрибутив в `dist/SanUsbViewer/`. Для инвентаризации не требуется модификация драйверов или установка WinUSB: приложению не требуются интерфейсы устройств.

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

Папка назначения для захвата должна существовать. Релизная версия представляет собой приложение Windows без консоли; предпочитайте `cargo run` в разработке для инвентаризации командной строки.

## Интерпретируйте результаты

**Согласованная скорость** — это скорость соединения, а не эталон скорости копирования. Полезная скорость зависит, в частности, от протокола, периферийного устройства и других устройств, совместно использующих шину. Скорости нескольких устройств не суммируются для расчета доступной пропускной способности.

Пассивный USB-кабель, как правило, не является перечислимым устройством. Эта версия не считывает ни свой электронный маркер, ни мощность USB Power Delivery, ни тип разъема. Поэтому он не претендует на сертификацию максимальной скорости. Диагностика основывается на наблюдаемой ссылке и, если таковые имеются, на показателях Windows. Медленное соединение может быть ограничено кабелем, портом, концентратором или устройством. Номер версии дескриптора USB никогда не используется в качестве максимальной скорости.

Категория SuperSpeedPlus здесь не различает режимы 10 и 20 Гбит/с. USB4/Thunderbolt и их туннели не проверяются. Порты, к которым не подключено устройство, не учитываются. Зарядный кабель без данных не создает видимого устройства. В дереве USB могут появиться внутренние устройства (Bluetooth, встроенная камера и т. д.).

Недоступная информация отображается как недоступная. Производитель и интерфейсы не всегда отображаются в Windows. События, происходящие между сканированиями, могут остаться незамеченными. Журнал находится в памяти и начинается после первой успешной инвентаризации.

Идентификаторы шин и пути портов описывают топологию системы. Физический разъем может иметь два отдельных пути для USB 2 и SuperSpeed.

## Архитектура и проверка

`scanner.rs` выполняет инвентаризацию; `windows_probe.rs` инкапсулирует собственные запросы чтения от концентраторов; `model.rs` содержит данные и диагностику. `app.rs` обрабатывает фоновые задачи и выбор; `views.rs`, `inspector.rs`, `connection.rs` и `theme.rs` рисуют интерфейс с помощью egui/eframe. Интерфейс остается интерактивным во время сканирования и сохраняет последнее успешное чтение, если следующее сканирование не удалось.

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

Библиотеки являются кроссплатформенными, а код Windows является условным. Версии macOS/Linux не проверяются в этой первой поставке.

## Конфиденциальность

Инвентаризация работает локально, только для чтения, без телеметрии или сетевых служб. Ссылки руководства открываются только по клику. Отчеты JSON могут содержать серийные номера и системные идентификаторы: делиться ими зависит от вас.

## Языки — версия 0.2.0

Приложение включает **50 языков интерфейса**. Нажмите на код языка (`FR`, `EN` и т. д.) в правом верхнем углу, чтобы открыть переключатель. Вы можете искать язык по его родному названию, английскому названию или коду. Изменение происходит немедленно, и выбор сохраняется в `%APPDATA%/SanUsbViewer/preferences.json` под Windows. Без предпочтения используется системный язык; Неподдерживаемый язык возвращается к английскому.

Выбор отдает предпочтение наиболее распространенным языкам в целом (родному и второму языку), группируя региональные варианты. Это не числовая классификация: результаты различаются в зависимости от группировки диалектов. Выбранные варианты включают упрощенный китайский, стандартный арабский язык и латиницу фулани и узбекского языка; Пенджаби использует Гурмукхи.

Английский, китайский, хинди, испанский, французский, арабский, бенгальский, португальский, русский, урду, индонезийский, немецкий, японский, маратхи, вьетнамский, телугу, хауса, турецкий, панджаби, суахили, филиппинский, тамильский, персидский, корейский, амхарский, тайский, яванский, итальянский, гуджарати, каннада, бходжпури, бирманский, польский, йоруба, лингала, оромо, фулани, Малаялам, одиа, украинский, синдхи, узбекский, пушту, суданский, малайский, игбо, непальский, азербайджанский, майтхили и сомалийский.

Скопированные меню, диагностика, справочные тексты, сообщения об активности и подробные сведения локализованы. Имена и идентификаторы, предоставленные оборудованием и системой, сохраняются. Экспорт JSON сохраняет схему и данные инвентаризации независимо от языка отображения. Технические единицы измерения остаются в **бит/с** (Мбит/с и Гбит/с), чтобы избежать путаницы с байтами.

Справочными материалами служат каталоги на французском и английском языках. Другие языки являются **автоматическими переводами**, поэтому могут потребоваться лингвистические исправления. Файлы `locales/*.json` включены в компиляцию и могут быть исправлены, а затем перекомпилированы. Приложение не выполняет сетевой перевод: встроены 50 языков и шрифты Noto в соответствии с лицензией SIL Open Font License. В арабском тексте используются двунаправленные сегменты Юникода и символы новой строки, рассчитанные перед форматированием.

```powershell
# Forcer une langue pour ce lancement, sans remplacer le choix enregistré
rtk cargo run -- --lang ja

# Vérifier les catalogues, les paramètres et les unités de vitesse
rtk python tools/validate_locales.py

# Capture du guide en arabe
rtk cargo run -- --demo --lang ar --page guide --screenshot artifacts/guide-ar.png
```

`SAN_USB_VIEWER_CONFIG` может ссылаться на другой файл настроек для тестирования или переносной установки. Там сохраняется только код языка.
