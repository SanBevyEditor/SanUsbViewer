**ரஸ்ட்** இல் எழுதப்பட்ட நேட்டிவ் யூ.எஸ்.பி எக்ஸ்ப்ளோரர், இருண்ட இடைமுகம், காட்சி இடவியல் மற்றும் படிக்கக்கூடிய கண்டறிதல். விண்டோஸ் 10/11 க்கான முதல் பதிப்பு.

## திட்டத்தின் தோற்றம்

திட்டத்தின் தோற்றத்தில் வீடியோ: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus).

ஆப்பிளில் **WhatCable** மற்றும் Windows இல் **USB Device Tree Viewer** ஆகியவற்றின் பயன்பாடுகளால் இந்த திட்டம் ஈர்க்கப்பட்டுள்ளது: சாதனங்கள், மையங்கள் மற்றும் அவற்றின் USB இணைப்புகளின் வேகத்தைப் புரிந்துகொள்வது. இது ஒரு சுதந்திரமான செயல்படுத்தல்.

## அம்சங்கள்

- `nusb` வழியாக USB சாதனங்கள் மற்றும் கட்டுப்படுத்திகளின் உண்மையான கண்டறிதல்.
- பஸ் மற்றும் துறைமுக பாதை வழியாக மர அமைப்பு, மைய ஆழத்துடன்.
- பெயர், வரிசை எண் அல்லது VID:PID மூலம் தேடவும்; USB 3+ வடிப்பான்கள் மற்றும் மையங்கள்.
- பேச்சுவார்த்தைக்குட்பட்ட இணைப்பு வேகம்: 1.5 / 12 / 480 Mb/s, 5 Gb/s,
அல்லது வகை SuperSpeedPlus (10 Gb/s அல்லது அதற்கு மேல்).
- பயண வரைபடம்: கணினி, இடைநிலை மையங்கள், இணைப்பு மற்றும் சாதனம்.
- விண்டோஸின் கீழ், ஐ.ஓ.சி.டி.எல் மூலம் ஹப்பைக் கண்டறிய கூடுதல் விசாரணை
சாதனத்தால் அறிவிக்கப்பட்ட SuperSpeed திறன்கள். USB 2.0 வழியாக இணைக்கப்பட்ட SuperSpeed இணக்கமான சாதனம் பாதை வரம்பு கண்டறியும் முறையை உருவாக்குகிறது.   USB 3 ஹப்களின் USB 2 ஹப்ஸ் தோழர்கள் தங்கள் 480 Mb/s கிளையை கேபிள் தவறுக்குக் காரணம் கூறுவதைத் தவிர்க்க தனித்தனியாகக் கருதப்படுகிறார்கள்.
- VID/PID அடையாளங்காட்டிகள், USB டிஸ்கிரிப்டர், மீள்பார்வை, இயக்கி, தொடர் மற்றும் இடைமுகங்கள்,
கணினி இந்த தகவலை வெளிப்படுத்தும் போது.
- ஒவ்வொரு மூன்று வினாடிகளுக்கும் தானியங்கி புதுப்பித்தல் அல்லது F5 உடன் கையேடு.
- கடந்த 200 கவனிக்கப்பட்ட மாற்றங்களின் அமர்வு பதிவு.
- JSON (Ctrl+E) இல் முழுமையான அறிக்கையை ஏற்றுமதி செய்து, தேர்ந்தெடுத்த விவரங்களை நகலெடுக்கவும்.
- ஒருங்கிணைந்த வழிகாட்டி மற்றும் வெளிப்படையான செயல்விளக்க முறை, ஒருபோதும் காப்புப்பிரதியாகப் பயன்படுத்தப்படவில்லை
கண்டறிதல் தோல்வி ஏற்பட்டால் அமைதியாக இருங்கள்.

## எறியுங்கள்

ரஸ்ட் **1.95+** உடன், MSVC கருவித்தொகுப்பு மற்றும் விண்டோஸில் விஷுவல் ஸ்டுடியோ C++ கருவிகள். கட்டளைகளின் வெளியீட்டை வடிகட்ட, எடுத்துக்காட்டுகள் RTK ஐப் பயன்படுத்துகின்றன; RTK இல்லாமல், `rtk` முன்னொட்டை அகற்றவும். விநியோக ஸ்கிரிப்ட் இரண்டு நிகழ்வுகளையும் ஏற்றுக்கொள்கிறது.

```powershell
rtk cargo run --release
```

தனித்த பைனரி `target/release/san-usb-viewer.exe` இல் தயாரிக்கப்படுகிறது. `build.ps1` ஸ்கிரிப்ட் `dist/SanUsbViewer/` இல் விநியோகத்தையும் உருவாக்குகிறது. சரக்குகளுக்கு இயக்கி மாற்றம் அல்லது WinUSB இன் நிறுவல் தேவையில்லை: பயன்பாட்டிற்கு சாதன இடைமுகங்கள் தேவையில்லை.

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

பிடிப்பிற்கான இலக்கு கோப்புறை இருக்க வேண்டும். வெளியீட்டு பதிப்பு கன்சோல் இல்லாத விண்டோஸ் பயன்பாடு ஆகும்; கட்டளை வரி சரக்குக்கான வளர்ச்சியில் `cargo run` ஐ விரும்புகிறது.

## முடிவுகளை விளக்கவும்

**பேச்சுவார்த்தை வேகம்** என்பது இணைப்பின் வேகம், நகல் வேகத்தின் அளவுகோல் அல்ல. பயனுள்ள வேகம் குறிப்பாக நெறிமுறை, புற மற்றும் பஸ்ஸைப் பகிர்ந்து கொள்ளும் பிற சாதனங்களைப் பொறுத்தது. கிடைக்கக்கூடிய அலைவரிசையைக் கணக்கிட, பல சாதனங்களின் வேகம் சேர்க்கப்படாது.

ஒரு செயலற்ற USB கேபிள் பொதுவாக கணக்கிட முடியாத சாதனம் அல்ல. இந்தப் பதிப்பு அதன் மின்-மார்க்கரையோ, USB பவர் டெலிவரி பவரையோ, அதன் இணைப்பான் வகையையோ படிக்கவில்லை. எனவே அதன் அதிகபட்ச வேகத்தை சான்றளிக்க உரிமை கோரவில்லை. கண்டறிதல் கவனிக்கப்பட்ட இணைப்பை அடிப்படையாகக் கொண்டது மற்றும் கிடைத்தால், விண்டோஸ் குறிகாட்டிகளில். மெதுவான இணைப்பு கேபிள், போர்ட், ஹப் அல்லது சாதனத்தால் வரையறுக்கப்படலாம். USB டிஸ்கிரிப்டர் பதிப்பு எண் அதிகபட்ச வேகமாக பயன்படுத்தப்படாது.

SuperSpeedPlus வகையானது இங்கு 10 மற்றும் 20 Gb/s முறைகளை வேறுபடுத்தவில்லை. USB4/தண்டர்போல்ட் மற்றும் அவற்றின் சுரங்கங்கள் ஆய்வு செய்யப்படவில்லை. சாதனம் இணைக்கப்படாத துறைமுகங்கள் இருப்பு வைக்கப்படவில்லை. தரவு இல்லாத சார்ஜிங் கேபிள் காணக்கூடிய சாதனத்தை உருவாக்காது. உள் சாதனங்கள் (புளூடூத், உள்ளமைக்கப்பட்ட கேமரா போன்றவை) USB ட்ரீயில் தோன்றலாம்.

அணுக முடியாத தகவல்கள் கிடைக்கவில்லை என காட்டப்படும். உற்பத்தியாளர் மற்றும் இடைமுகங்கள் எப்போதும் விண்டோஸால் வெளிப்படுவதில்லை. ஸ்கேன்களுக்கு இடையில் நடக்கும் நிகழ்வுகள் கவனிக்கப்படாமல் போகலாம். பதிவு நினைவகத்தில் உள்ளது மற்றும் முதல் வெற்றிகரமான சரக்குக்குப் பிறகு தொடங்குகிறது.

பஸ் அடையாளங்காட்டிகள் மற்றும் போர்ட் பாதைகள் கணினி இடவியலை விவரிக்கின்றன. ஒரு இயற்பியல் இணைப்பான் USB 2 மற்றும் SuperSpeed க்கு இரண்டு தனித்தனி பாதைகளைக் கொண்டிருக்கலாம்.

## கட்டிடக்கலை மற்றும் சரிபார்ப்பு

`scanner.rs` சரக்குகளை செய்கிறது; `windows_probe.rs` மையங்களில் இருந்து சொந்த வாசிப்பு கோரிக்கைகளை இணைக்கிறது; `model.rs` தரவு மற்றும் கண்டறிதல்களைக் கொண்டுள்ளது. `app.rs` பின்னணி பணிகள் மற்றும் தேர்வை கையாளுகிறது; `views.rs`, `inspector.rs`, `connection.rs` மற்றும் `theme.rs` ஆகியவை egui/eframe உடன் இடைமுகத்தை வரையவும். ஸ்கேன் செய்யும் போது இடைமுகம் ஊடாடுகிறது மற்றும் அடுத்த ஸ்கேன் தோல்வியுற்றால் கடைசி வெற்றிகரமான வாசிப்பைத் தக்க வைத்துக் கொள்ளும்.

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

நூலகங்கள் குறுக்கு-தளம் மற்றும் விண்டோஸ் குறியீடு நிபந்தனைக்குட்பட்டது. இந்த முதல் டெலிவரியில் macOS/Linux பதிப்புகள் சரிபார்க்கப்படவில்லை.

## இரகசியத்தன்மை

டெலிமெட்ரி அல்லது நெட்வொர்க் சேவைகள் இல்லாமல் சரக்கு உள்நாட்டில், படிக்க மட்டும் வேலை செய்கிறது. வழிகாட்டி இணைப்புகள் கிளிக் செய்தால் மட்டுமே திறக்கும். JSON அறிக்கைகளில் வரிசை எண்கள் மற்றும் கணினி அடையாளங்காட்டிகள் இருக்கலாம்: அவற்றைப் பகிர்வது உங்களுடையது.

பொது களஞ்சியத்தில் தொகுக்க தேவையான ஆதாரங்கள், மொழிபெயர்ப்புகள் மற்றும் இலவச எழுத்துருக்கள் மட்டுமே உள்ளன. USB அளவீடுகள், கண்டறியும் பிடிப்புகள், ஏற்றுமதிகள், உள்ளூர் விருப்பத்தேர்வுகள், தற்காலிக சேமிப்புகள் மற்றும் மேம்பாட்டு பைனரிகள் `.gitignore` ஆல் விலக்கப்பட்டுள்ளன. சிக்கலைப் புகாரளிக்க, `--demo` பயன்முறையைப் பயன்படுத்தவும் அல்லது வரிசை எண்கள் மற்றும் கணினி ஐடிகளைப் பகிர்வதற்கு முன் உங்கள் அறிக்கைகளிலிருந்து அகற்றவும்.

பயன்பாட்டில் **50 இடைமுக மொழிகள்** அடங்கும். மாற்றியைத் திறக்க, மேல் வலதுபுறத்தில் உள்ள மொழிக் குறியீட்டைக் (`FR`, `EN`, முதலியன) கிளிக் செய்யவும். நீங்கள் ஒரு மொழியை அதன் சொந்த பெயர், அதன் ஆங்கில பெயர் அல்லது அதன் குறியீடு மூலம் தேடலாம். மாற்றம் உடனடியானது மற்றும் தேர்வு விண்டோஸின் கீழ் `%APPDATA%/SanUsbViewer/preferences.json` இல் சேமிக்கப்படும். விருப்பம் இல்லாமல், கணினி மொழி பயன்படுத்தப்படுகிறது; ஆதரிக்கப்படாத மொழி ஆங்கிலத்திற்குத் திரும்பும்.

இந்தத் தேர்வு மொத்தத்தில் அதிகம் பேசப்படும் மொழிகளுக்கு (தாய்மொழி மற்றும் இரண்டாம் மொழி), பிராந்திய மாறுபாடுகளை ஒன்றிணைக்கிறது. இது ஒரு எண் வகைப்பாடு அல்ல: பேச்சுவழக்குகளின் குழுவைப் பொறுத்து முடிவுகள் மாறுபடும். தேர்ந்தெடுக்கப்பட்ட மாறுபாடுகளில் எளிமைப்படுத்தப்பட்ட சீனம், ஸ்டாண்டர்ட் அரபு மற்றும் ஃபுலானி மற்றும் உஸ்பெக்கின் லத்தீன் ஸ்கிரிப்டுகள் அடங்கும்; பஞ்சாபி குர்முகியைப் பயன்படுத்துகிறது.

ஆங்கிலம், சீனம், இந்தி, ஸ்பானிஷ், பிரஞ்சு, அரபு, பெங்காலி, போர்த்துகீசியம், ரஷியன், உருது, இந்தோனேசிய, ஜெர்மன், ஜப்பானிய, மராத்தி, வியட்நாம், தெலுங்கு, ஹௌசா, துருக்கிய, பஞ்சாபி, சுவாஹிலி, பிலிப்பினோ, தமிழ், பாரசீக, கொரியன், அம்ஹாரிக், தாய், ஜாவானீஸ், இத்தாலியன், குஜராத்தி, கன்னடம், போஜ்புரி, பர்மிய, எல், யோருபா, போலிஷ், யோருபா, மலையாளம், யோருபா உக்ரேனிய, சிந்தி, உஸ்பெக், பாஷ்டோ, சுண்டனீஸ், மலாய், இக்போ, நேபாளி, அசெரி, மைதிலி மற்றும் சோமாலி.

நகலெடுக்கப்பட்ட மெனுக்கள், கண்டறிதல்கள், உதவி உரைகள், செயல்பாட்டுச் செய்திகள் மற்றும் விவரங்கள் உள்ளூர்மயமாக்கப்பட்டுள்ளன. வன்பொருள் மற்றும் அமைப்பால் வழங்கப்பட்ட பெயர்கள் மற்றும் அடையாளங்காட்டிகள் தக்கவைக்கப்படுகின்றன. காட்சி மொழியைப் பொருட்படுத்தாமல், JSON ஏற்றுமதி அதன் ஸ்கீமா மற்றும் இருப்புத் தரவை வைத்திருக்கிறது. பைட்டுகளுடன் குழப்பத்தைத் தவிர்க்க, தொழில்நுட்ப அலகுகள் **பிட்/வி** (Mbit/s மற்றும் Gbit/s) இல் இருக்கும்.

பிரஞ்சு மற்றும் ஆங்கில பட்டியல்கள் ஒரு குறிப்புகளாக செயல்படுகின்றன. பிற மொழிகள் **தானியங்கி மொழிபெயர்ப்பு**, இதற்கு மொழியியல் திருத்தங்கள் தேவைப்படலாம். `locales/*.json` கோப்புகள் தொகுப்பில் சேர்க்கப்பட்டுள்ளன, அவற்றை சரிசெய்து மீண்டும் தொகுக்கலாம். பயன்பாட்டினால் நெட்வொர்க் மொழிபெயர்ப்பு எதுவும் மேற்கொள்ளப்படவில்லை: SIL திறந்த எழுத்துரு உரிமத்தின் கீழ் 50 மொழிகள் மற்றும் நோட்டோ எழுத்துருக்கள் உட்பொதிக்கப்பட்டுள்ளன. அரபு உரை இருதரப்பு யூனிகோட் பிரிவுகளையும் வடிவமைப்பதற்கு முன் கணக்கிடப்பட்ட புதிய வரிகளையும் பயன்படுத்துகிறது.
