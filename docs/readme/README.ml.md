# San USB Viewer

**മലയാളം** · [English](README.en.md) · [Français](../../README.md) · [50 languages](../README.md)

> യന്ത്ര വിവർത്തനങ്ങൾ; തിരുത്തലുകൾ സ്വാഗതം ചെയ്യുന്നു.

**നിലവിലെ പതിപ്പ്: `0.2.0`** — MIT ലൈസൻസ്.

![San USB Viewer](../../assets/screenshots/SanUsbViewer.jpg)

ഇരുണ്ട ഇൻ്റർഫേസ്, വിഷ്വൽ ടോപ്പോളജി, റീഡബിൾ ഡയഗ്നോസ്റ്റിക്സ് എന്നിവയ്ക്കൊപ്പം **റസ്റ്റ്**-ൽ എഴുതിയ നേറ്റീവ് യുഎസ്ബി എക്സ്പ്ലോറർ. വിൻഡോസ് 10/11-ന് ഉദ്ദേശിച്ചുള്ള ആദ്യ പതിപ്പ്.

## പദ്ധതിയുടെ ഉത്ഭവം

പ്രോജക്റ്റിൻ്റെ ഉത്ഭവത്തിൽ വീഡിയോ: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus).

ആപ്പിളിൽ **WhatCable**, Windows-ൽ **USB Device Tree Viewer** എന്നിവയുടെ ഉപയോഗങ്ങളിൽ നിന്ന് പ്രോജക്റ്റ് പ്രചോദനം ഉൾക്കൊണ്ടതാണ്: പെരിഫറലുകൾ, ഹബുകൾ, അവയുടെ USB കണക്ഷനുകളുടെ വേഗത എന്നിവ മനസ്സിലാക്കൽ. ഇത് ഒരു സ്വതന്ത്ര നിർവഹണമാണ്.

## ഫീച്ചറുകൾ

- `nusb` വഴി USB ഉപകരണങ്ങളുടെയും കൺട്രോളറുകളുടെയും യഥാർത്ഥ കണ്ടെത്തൽ.
- ബസ്സിലൂടെയും തുറമുഖ പാതയിലൂടെയും മരത്തിൻ്റെ ഘടന, ഹബ് ഡെപ്ത്.
- പേര്, സീരിയൽ നമ്പർ അല്ലെങ്കിൽ VID:PID പ്രകാരം തിരയുക; USB 3+ ഫിൽട്ടറുകളും ഹബുകളും.
- ചർച്ചചെയ്ത ലിങ്ക് വേഗത: 1.5 / 12 / 480 Mb/s, 5 Gb/s,
അല്ലെങ്കിൽ വിഭാഗം SuperSpeedPlus (10 Gb/s അല്ലെങ്കിൽ അതിൽ കൂടുതൽ).
- യാത്രാ ഡയഗ്രം: കമ്പ്യൂട്ടർ, ഇൻ്റർമീഡിയറ്റ് ഹബുകൾ, ലിങ്ക്, ഉപകരണം.
- വിൻഡോസിന് കീഴിൽ, ഐഒസിടിഎൽ ഹബ്ബിൻ്റെ അധിക ചോദ്യം ചെയ്യൽ കണ്ടെത്തുന്നതിന്
ഉപകരണം പ്രഖ്യാപിച്ച SuperSpeed കഴിവുകൾ. USB 2.0 വഴി ബന്ധിപ്പിച്ചിരിക്കുന്ന SuperSpeed അനുയോജ്യമായ ഉപകരണം ഒരു പാത്ത് ലിമിറ്റേഷൻ ഡയഗ്നോസ്റ്റിക് നിർമ്മിക്കുന്നു.   USB 3 ഹബുകളുടെ USB 2 ഹബ് കൂട്ടാളികൾ അവരുടെ 480 Mb/s ബ്രാഞ്ച് കേബിൾ തകരാറിന് കാരണമാകുന്നത് ഒഴിവാക്കാൻ പ്രത്യേകം പരിഗണിക്കുന്നു.
- VID/PID ഐഡൻ്റിഫയറുകൾ, USB ഡിസ്ക്രിപ്റ്റർ, റിവിഷൻ, ഡ്രൈവർ, സീരിയൽ, ഇൻ്റർഫേസുകൾ,
സിസ്റ്റം ഈ വിവരങ്ങൾ വെളിപ്പെടുത്തുമ്പോൾ.
- ഓരോ മൂന്ന് സെക്കൻഡിലും സ്വയമേവ അപ്ഡേറ്റ് ചെയ്യുക, അല്ലെങ്കിൽ F5 ഉപയോഗിച്ച് മാനുവൽ.
- കഴിഞ്ഞ 200 നിരീക്ഷിച്ച മാറ്റങ്ങളുടെ സെഷൻ ലോഗ്.
- JSON (Ctrl+E)-ൽ പൂർണ്ണമായ പ്രസ്താവന എക്‌സ്‌പോർട്ടുചെയ്‌ത് തിരഞ്ഞെടുത്ത വിശദാംശങ്ങൾ പകർത്തുക.
- സംയോജിത ഗൈഡും വ്യക്തമായ ഡെമോൺസ്‌ട്രേഷൻ മോഡും, ഒരിക്കലും ഒരു ബാക്കപ്പായി ഉപയോഗിച്ചിട്ടില്ല
കണ്ടെത്തൽ പരാജയപ്പെടുമ്പോൾ നിശബ്ദത.

## എറിയുക

Rust **1.95+** ഉപയോഗിച്ച്, MSVC ടൂൾചെയിൻ, Windows-ലെ വിഷ്വൽ സ്റ്റുഡിയോ C++ ടൂളുകൾ. കമാൻഡുകളുടെ ഔട്ട്പുട്ട് ഫിൽട്ടർ ചെയ്യുന്നതിന് ഉദാഹരണങ്ങൾ RTK ഉപയോഗിക്കുന്നു; RTK ഇല്ലാതെ, `rtk` പ്രിഫിക്സ് നീക്കം ചെയ്യുക. വിതരണ സ്ക്രിപ്റ്റ് രണ്ട് കേസുകളും അംഗീകരിക്കുന്നു.

```powershell
rtk cargo run --release
```

`target/release/san-usb-viewer.exe`-ലാണ് ഒറ്റപ്പെട്ട ബൈനറി നിർമ്മിക്കുന്നത്. `build.ps1` സ്ക്രിപ്റ്റ് `dist/SanUsbViewer/`-ൽ ഒരു വിതരണവും സൃഷ്ടിക്കുന്നു. ഇൻവെൻ്ററിക്കായി WinUSB-ൻ്റെ ഡ്രൈവർ പരിഷ്ക്കരണമോ ഇൻസ്റ്റാളേഷനോ ആവശ്യമില്ല: അപ്ലിക്കേഷന് ഉപകരണ ഇൻ്റർഫേസുകൾ ആവശ്യമില്ല.

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

ഒരു ക്യാപ്‌ചർ ചെയ്യാനുള്ള ഡെസ്റ്റിനേഷൻ ഫോൾഡർ നിലവിലുണ്ടാകണം. റിലീസ് പതിപ്പ് കൺസോൾ കുറവുള്ള വിൻഡോസ് ആപ്ലിക്കേഷനാണ്; കമാൻഡ് ലൈൻ ഇൻവെൻ്ററിക്കായി വികസനത്തിൽ `cargo run` തിരഞ്ഞെടുക്കുക.

## ഫലങ്ങൾ വ്യാഖ്യാനിക്കുക

** ചർച്ച ചെയ്‌ത വേഗത** കണക്ഷനുടേതാണ്, പകർപ്പ് വേഗതയുടെ മാനദണ്ഡമല്ല. ഉപയോഗപ്രദമായ വേഗത പ്രോട്ടോക്കോൾ, പെരിഫറൽ, ബസ് പങ്കിടുന്ന മറ്റ് ഉപകരണങ്ങൾ എന്നിവയെ ആശ്രയിച്ചിരിക്കുന്നു. ലഭ്യമായ ബാൻഡ്‌വിഡ്ത്ത് കണക്കാക്കാൻ ഒന്നിലധികം ഉപകരണങ്ങളിൽ നിന്നുള്ള വേഗത കൂട്ടുന്നില്ല.

ഒരു നിഷ്ക്രിയ യുഎസ്ബി കേബിൾ സാധാരണയായി എണ്ണാവുന്ന ഉപകരണമല്ല. ഈ പതിപ്പ് അതിൻ്റെ ഇ-മാർക്കറോ USB പവർ ഡെലിവറി പവറോ അതിൻ്റെ കണക്റ്റർ തരമോ വായിക്കുന്നില്ല. അതിനാൽ അതിൻ്റെ പരമാവധി വേഗത സാക്ഷ്യപ്പെടുത്താൻ ഇത് അവകാശപ്പെടുന്നില്ല. നിരീക്ഷിച്ച ലിങ്ക് അടിസ്ഥാനമാക്കിയുള്ളതാണ് രോഗനിർണയം, ലഭ്യമാണെങ്കിൽ, വിൻഡോസ് സൂചകങ്ങളിൽ. ഒരു സ്ലോ ലിങ്ക് കേബിൾ, പോർട്ട്, ഹബ് അല്ലെങ്കിൽ ഉപകരണം വഴി പരിമിതപ്പെടുത്തിയേക്കാം. USB ഡിസ്ക്രിപ്റ്റർ പതിപ്പ് നമ്പർ ഒരിക്കലും പരമാവധി വേഗതയായി ഉപയോഗിക്കില്ല.

SuperSpeedPlus വിഭാഗം ഇവിടെ 10, 20 Gb/s മോഡുകൾ തമ്മിൽ വേർതിരിച്ചറിയുന്നില്ല. USB4/തണ്ടർബോൾട്ടും അവയുടെ തുരങ്കങ്ങളും പരിശോധിച്ചിട്ടില്ല. ഉപകരണം ഘടിപ്പിച്ചിട്ടില്ലാത്ത പോർട്ടുകൾ ഇൻവെൻ്ററി അല്ല. ഡാറ്റയില്ലാത്ത ഒരു ചാർജിംഗ് കേബിൾ ദൃശ്യമായ ഒരു ഉപകരണം സൃഷ്ടിക്കുന്നില്ല. USB ട്രീയിൽ ആന്തരിക ഉപകരണങ്ങൾ (ബ്ലൂടൂത്ത്, ബിൽറ്റ്-ഇൻ ക്യാമറ മുതലായവ) ദൃശ്യമാകാം.

ആക്‌സസ് ചെയ്യാൻ കഴിയാത്ത വിവരങ്ങൾ ലഭ്യമല്ലാത്തതായി പ്രദർശിപ്പിക്കും. നിർമ്മാതാക്കളും ഇൻ്റർഫേസുകളും എല്ലായ്പ്പോഴും വിൻഡോസ് വെളിപ്പെടുത്തുന്നില്ല. പൂർണ്ണമായും സ്കാനുകൾക്കിടയിൽ സംഭവിക്കുന്ന ഇവൻ്റുകൾ ശ്രദ്ധിക്കപ്പെടാതെ പോയേക്കാം. ലോഗ് മെമ്മറിയിലാണ്, ആദ്യത്തെ വിജയകരമായ ഇൻവെൻ്ററിക്ക് ശേഷം ആരംഭിക്കുന്നു.

ബസ് ഐഡൻ്റിഫയറുകളും പോർട്ട് പാതകളും സിസ്റ്റം ടോപ്പോളജിയെ വിവരിക്കുന്നു. ഒരു ഫിസിക്കൽ കണക്ടറിന് USB 2, SuperSpeed എന്നിവയ്‌ക്കായി രണ്ട് വ്യത്യസ്ത പാതകൾ ഉണ്ടായിരിക്കും.

## വാസ്തുവിദ്യയും മൂല്യനിർണ്ണയവും

`scanner.rs` ഇൻവെൻ്ററി നടത്തുന്നു; `windows_probe.rs` കേന്ദ്രങ്ങളിൽ നിന്നുള്ള നേറ്റീവ് റീഡ് അഭ്യർത്ഥനകൾ ഉൾക്കൊള്ളുന്നു; `model.rs` ഡാറ്റയും ഡയഗ്നോസ്റ്റിക്സും അടങ്ങിയിരിക്കുന്നു. `app.rs` പശ്ചാത്തല ജോലികളും തിരഞ്ഞെടുപ്പും കൈകാര്യം ചെയ്യുന്നു; `views.rs`, `inspector.rs`, `connection.rs`, `theme.rs` എന്നിവ egui/eframe ഉപയോഗിച്ച് ഇൻ്റർഫേസ് വരയ്ക്കുന്നു. ഒരു സ്കാൻ സമയത്ത് ഇൻ്റർഫേസ് ഇൻ്ററാക്ടീവ് ആയി തുടരുകയും അടുത്ത സ്കാൻ പരാജയപ്പെടുകയാണെങ്കിൽ അവസാനത്തെ വിജയകരമായ വായന നിലനിർത്തുകയും ചെയ്യും.

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

ലൈബ്രറികൾ ക്രോസ്-പ്ലാറ്റ്ഫോമാണ്, വിൻഡോസ് കോഡ് സോപാധികമാണ്. ഈ ആദ്യ ഡെലിവറിയിൽ MacOS/Linux പതിപ്പുകൾ സാധുതയുള്ളതല്ല.

## രഹസ്യാത്മകത

ടെലിമെട്രിയോ നെറ്റ്‌വർക്ക് സേവനങ്ങളോ ഇല്ലാതെ ഇൻവെൻ്ററി പ്രാദേശികമായി, വായന-മാത്രം പ്രവർത്തിക്കുന്നു. ഗൈഡ് ലിങ്കുകൾ ക്ലിക്ക് ചെയ്യുമ്പോൾ മാത്രമേ തുറക്കൂ. JSON റിപ്പോർട്ടുകളിൽ സീരിയൽ നമ്പറുകളും സിസ്റ്റം ഐഡൻ്റിഫയറുകളും അടങ്ങിയിരിക്കാം: അവ പങ്കിടുന്നത് നിങ്ങളുടേതാണ്.

പബ്ലിക് റിപ്പോസിറ്ററിയിൽ സമാഹാരത്തിന് ആവശ്യമായ ഉറവിടങ്ങളും വിവർത്തനങ്ങളും സൗജന്യ ഫോണ്ടുകളും മാത്രമേ അടങ്ങിയിട്ടുള്ളൂ. USB റീഡിംഗുകൾ, ഡയഗ്നോസ്റ്റിക് ക്യാപ്‌ചറുകൾ, കയറ്റുമതികൾ, പ്രാദേശിക മുൻഗണനകൾ, കാഷെകൾ, വികസന ബൈനറികൾ എന്നിവ `.gitignore` ഒഴിവാക്കിയിരിക്കുന്നു. ഒരു പ്രശ്നം റിപ്പോർട്ടുചെയ്യുന്നതിന്, `--demo` മോഡ് ഉപയോഗിക്കുക അല്ലെങ്കിൽ നിങ്ങളുടെ റിപ്പോർട്ടുകളിൽ നിന്ന് സീരിയൽ നമ്പറുകളും സിസ്റ്റം ഐഡികളും പങ്കിടുന്നതിന് മുമ്പ് അവ നീക്കം ചെയ്യുക.

## ഭാഷകൾ - പതിപ്പ് 0.2.0

അപ്ലിക്കേഷനിൽ **50 ഇൻ്റർഫേസ് ഭാഷകൾ** ഉൾപ്പെടുന്നു. സ്വിച്ചർ തുറക്കാൻ മുകളിൽ വലതുവശത്തുള്ള ഭാഷാ കോഡ് (`FR`, `EN`, മുതലായവ) ക്ലിക്ക് ചെയ്യുക. നിങ്ങൾക്ക് ഒരു ഭാഷയുടെ മാതൃനാമം, ഇംഗ്ലീഷ് പേര് അല്ലെങ്കിൽ കോഡ് എന്നിവ ഉപയോഗിച്ച് തിരയാൻ കഴിയും. മാറ്റം ഉടനടി സംഭവിക്കുന്നു, ചോയ്സ് വിൻഡോസിന് കീഴിൽ `%APPDATA%/SanUsbViewer/preferences.json`-ൽ സംഭരിച്ചിരിക്കുന്നു. മുൻഗണന കൂടാതെ, സിസ്റ്റം ഭാഷ ഉപയോഗിക്കുന്നു; പിന്തുണയ്‌ക്കാത്ത ഭാഷ ഇംഗ്ലീഷിലേക്ക് മടങ്ങുന്നു.

ഈ തിരഞ്ഞെടുപ്പ് മൊത്തത്തിൽ ഏറ്റവും കൂടുതൽ സംസാരിക്കുന്ന ഭാഷകളെ (മാതൃഭാഷയും രണ്ടാം ഭാഷയും) പ്രാദേശിക വകഭേദങ്ങളെ ഒന്നിച്ചു ചേർക്കുന്നു. ഇതൊരു സംഖ്യാപരമായ വർഗ്ഗീകരണമല്ല: ഉപഭാഷകളുടെ ഗ്രൂപ്പിംഗിനെ ആശ്രയിച്ച് ഫലങ്ങൾ വ്യത്യാസപ്പെടുന്നു. തിരഞ്ഞെടുത്ത വകഭേദങ്ങളിൽ ലളിതമാക്കിയ ചൈനീസ്, സ്റ്റാൻഡേർഡ് അറബിക്, ഫുലാനി, ഉസ്ബെക്ക് എന്നിവയുടെ ലാറ്റിൻ ലിപികൾ ഉൾപ്പെടുന്നു; പഞ്ചാബി ഗുരുമുഖിയാണ് ഉപയോഗിക്കുന്നത്.

ഇംഗ്ലീഷ്, ചൈനീസ്, ഹിന്ദി, സ്പാനിഷ്, ഫ്രഞ്ച്, അറബിക്, ബംഗാളി, പോർച്ചുഗീസ്, റഷ്യൻ, ഉറുദു, ഇന്തോനേഷ്യൻ, ജർമ്മൻ, ജാപ്പനീസ്, മറാത്തി, വിയറ്റ്നാമീസ്, തെലുങ്ക്, ഹൗസ, ടർക്കിഷ്, പഞ്ചാബി, സ്വാഹിലി, ഫിലിപ്പിനോ, തമിഴ്, പേർഷ്യൻ, കൊറിയൻ, അംഹാരിക്, തായ്, ജാവനീസ്, ഇറ്റാലിയൻ, ഗുജറാത്തി, കന്നഡ, ഭോജ്പുരി, ബർമീസ്, പോളിഷ്, ഒറൂബ, മലയാളം, ഒറൂബ, പോളിംഗ്, ഒറൂബ, മലയാളം ഉക്രേനിയൻ, സിന്ധി, ഉസ്ബെക്ക്, പാഷ്തോ, സുന്ദനീസ്, മലയ്, ഇഗ്ബോ, നേപ്പാളി, അസെരി, മൈഥിലി, സോമാലി.

പകർത്തിയ മെനുകൾ, ഡയഗ്‌നോസ്റ്റിക്‌സ്, ഹെൽപ്പ് ടെക്‌സ്‌റ്റുകൾ, ആക്‌റ്റിവിറ്റി സന്ദേശങ്ങൾ, വിശദാംശങ്ങൾ എന്നിവ പ്രാദേശികവൽക്കരിച്ചിരിക്കുന്നു. ഹാർഡ്‌വെയറും സിസ്റ്റവും നൽകുന്ന പേരുകളും ഐഡൻ്റിഫയറുകളും നിലനിർത്തുന്നു. ഡിസ്പ്ലേ ഭാഷ പരിഗണിക്കാതെ തന്നെ JSON എക്‌സ്‌പോർട്ട് അതിൻ്റെ സ്കീമയും ഇൻവെൻ്ററി ഡാറ്റയും സൂക്ഷിക്കുന്നു. ബൈറ്റുകളുമായുള്ള ആശയക്കുഴപ്പം ഒഴിവാക്കാൻ സാങ്കേതിക യൂണിറ്റുകൾ **bit/s** (Mbit/s, Gbit/s) ആയി തുടരും.

ഫ്രഞ്ച്, ഇംഗ്ലീഷ് കാറ്റലോഗുകൾ ഒരു റഫറൻസായി വർത്തിക്കുന്നു. മറ്റ് ഭാഷകൾ ** സ്വയമേവയുള്ള വിവർത്തനങ്ങളാണ്**, ഇതിന് ഭാഷാപരമായ തിരുത്തലുകൾ ആവശ്യമായി വന്നേക്കാം. `locales/*.json` ഫയലുകൾ സമാഹാരത്തിൽ ഉൾപ്പെടുത്തിയിട്ടുണ്ട്, അവ ശരിയാക്കാനും വീണ്ടും കംപൈൽ ചെയ്യാനും കഴിയും. ആപ്ലിക്കേഷൻ ഒരു നെറ്റ്‌വർക്ക് വിവർത്തനവും നടത്തുന്നില്ല: SIL ഓപ്പൺ ഫോണ്ട് ലൈസൻസിന് കീഴിൽ 50 ഭാഷകളും നോട്ടോ ഫോണ്ടുകളും ഉൾച്ചേർത്തിരിക്കുന്നു. അറബി ടെക്‌സ്‌റ്റ് ദ്വിദിശ യൂണികോഡ് സെഗ്‌മെൻ്റുകളും ഫോർമാറ്റ് ചെയ്യുന്നതിന് മുമ്പ് കണക്കാക്കിയ ന്യൂലൈനുകളും ഉപയോഗിക്കുന്നു.

```powershell
# Forcer une langue pour ce lancement, sans remplacer le choix enregistré
rtk cargo run -- --lang ja

# Vérifier les catalogues, les paramètres et les unités de vitesse
rtk python tools/validate_locales.py

# Capture du guide en arabe
rtk cargo run -- --demo --lang ar --page guide --screenshot artifacts/guide-ar.png
```

`SAN_USB_VIEWER_CONFIG` മറ്റൊരു മുൻഗണന ഫയൽ പരിശോധനയ്‌ക്കോ പോർട്ടബിൾ ഇൻസ്റ്റാളേഷനോ പരാമർശിച്ചേക്കാം. ഭാഷാ കോഡ് മാത്രമേ അവിടെ സേവ് ചെയ്തിട്ടുള്ളൂ.
