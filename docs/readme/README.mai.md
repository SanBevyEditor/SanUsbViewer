## फेंकू

रस्ट **1.95+** के साथ, विंडोज पर एमएसवीसी टूलचेन आरू विजुअल स्टूडियो सी++ टूल. उदाहरण कमांड कें आउटपुट कें फ़िल्टर करय कें लेल आरटीके कें उपयोग करय छै; बिना आरटीके के, बस `rtk` उपसर्ग हटाउ. वितरण लिपि दुनू मामला स्वीकार करैत अछि।

```powershell
rtk cargo run --release
```

स्टैंडअलोन बाइनरी `target/release/san-usb-viewer.exe` मे उत्पादित छै. `build.ps1` स्क्रिप्ट `dist/SanUsbViewer/` मे एकटा वितरण सेहो बनाबैत अछि. इन्वेंट्री कें लेल कोनों ड्राइवर संशोधन या WinUSB कें इंस्टॉलेशन आवश्यक नहि छै: एप्लीकेशन कें लेल डिवाइस इंटरफेस कें आवश्यकता नहि छै.

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique

```

कैप्चर कें लेल गंतव्य फोल्डर मौजूद होबाक चाही. रिलीज संस्करण एकटा कंसोल-रहित विंडोज एप्लीकेशन अछि; कमांड लाइन इन्वेंट्री क लेल विकास मे `cargo run` पसंद करैत अछि.

## परिणामक व्याख्या करू

**बातचीत गति** कनेक्शन के अछि, आ कॉपी गति के बेंचमार्क नहि. उपयोगी गति विशेष रूप सं प्रोटोकॉल, परिधीय आ बस कें साझा करय वाला अन्य उपकरणक पर निर्भर करय छै. उपलब्ध बैंडविड्थ कें गणना करय कें लेल कईटा डिवाइस सं गति जोड़ल नहि जायत छै.

निष्क्रिय यूएसबी केबल आमतौर पर कोनों गणना योग्य उपकरण नहि होयत छै. ई संस्करण अपन ई-मार्कर नहि पढ़ैत अछि, आ ने यूएसबी पावर डिलीवरी पावर, आ ने एकर कनेक्टर टाइप. एहि लेल ओ अपन अधिकतम गति कए प्रमाणित करबाक दावा नहि करैत अछि । निदान देखल गेल लिंक आ यदि उपलब्ध होय त विंडोज संकेतक पर आधारित छै. एकटा धीमा लिंक केबल, पोर्ट, हब या डिवाइस कें द्वारा सीमित भ सकय छै. यूएसबी डिस्क्रिप्टर संस्करण नंबर कें उपयोग कहियो अधिकतम गति कें रूप मे नहि कैल जायत छै.

SuperSpeedPlus श्रेणी एतय 10 आ 20 Gb/s मोड मे अंतर नहि करैत अछि । USB4/Thunderbolt आ ओकर सुरंगक निरीक्षण नहि होइत अछि । बिना कोनों डिवाइस संलग्न पोर्ट कें इन्वेंट्री नहि कैल जायत छै. बिना डाटा कें चार्जिंग केबल कोनों दृश्यमान उपकरण नहि बनायत छै. यूएसबी ट्री मे आंतरिक उपकरण (ब्लूटूथ, बिल्ट-इन कैमरा, आदि) आबि सकैत अछि.

दुर्गम जानकारी अनुपलब्ध के रूप मे प्रदर्शित कएल जाइत अछि. निर्माता आ इंटरफेस हमेशा विंडोज कें द्वारा उजागर नहि होयत छै. स्कैन कें बीच पूरा तरह सं घटित घटनाक कें कोनों ध्यान नहि देल जा सकएय छै. लॉग मेमोरी मे छै आ पहिल सफल इन्वेंट्री कें बाद शुरू होयत छै.

बस पहचानकर्ता आ पोर्ट पथ सिस्टम टोपोलॉजी कें वर्णन करयत छै. एकटा भौतिक कनेक्टर मे यूएसबी 2 आ... SuperSpeed .

## वास्तुकला एवं सत्यापन

`scanner.rs` इन्वेंट्री करैत अछि; `windows_probe.rs` हब सं देशी पढ़य कें अनुरोध कें कैप्सूल करयत छै; `model.rs` मे डाटा आ डायग्नोस्टिक्स शामिल छै. `app.rs` पृष्ठभूमि कार्य आ चयन संभालैत अछि; `views.rs`, `inspector.rs`, `connection.rs` आरू `theme.rs` egui/eframe के साथ इंटरफेस आकर्षित करय छै. इंटरफेस स्कैन कें दौरान इंटरैक्टिव रहयत छै आ अगर अगिला स्कैन विफल भ जायत छै त अंतिम सफल रीड कें बरकरार रखयत छै.

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

लाइब्रेरी क्रॉस-प्लेटफॉर्म छै आ विंडोज कोड सशर्त छै. macOS/Linux संस्करणक कें अइ पहिल वितरण मे मान्य नहि कैल गेल छै.
