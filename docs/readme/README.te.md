![San USB Viewer](../../assets/screenshots/SanUsbViewer.jpg)

డార్క్ ఇంటర్‌ఫేస్, విజువల్ టోపోలాజీ మరియు రీడబుల్ డయాగ్నస్టిక్‌లతో **రస్ట్**లో వ్రాయబడిన స్థానిక USB ఎక్స్‌ప్లోరర్. మొదటి వెర్షన్ Windows 10/11 కోసం ఉద్దేశించబడింది.

## ప్రాజెక్ట్ యొక్క మూలం

ప్రాజెక్ట్ మూలం వద్ద వీడియో: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus).

ప్రాజెక్ట్ Appleలో **WhatCable** మరియు Windowsలో **USB Device Tree Viewer** ఉపయోగాల నుండి ప్రేరణ పొందింది: పెరిఫెరల్స్, హబ్‌లు మరియు వాటి USB కనెక్షన్‌ల వేగాన్ని అర్థం చేసుకోవడం. ఇది స్వతంత్ర అమలు.

## ఫీచర్లు

- `nusb` ద్వారా USB పరికరాలు మరియు కంట్రోలర్‌ల వాస్తవ గుర్తింపు.
- బస్సు మరియు పోర్ట్ మార్గం ద్వారా చెట్టు నిర్మాణం, హబ్ లోతుతో.
- పేరు, క్రమ సంఖ్య లేదా VID:PID ద్వారా శోధించండి; USB 3+ ఫిల్టర్‌లు మరియు హబ్‌లు.
- చర్చల లింక్ వేగం: 1.5 / 12 / 480 Mb/s, 5 Gb/s,
లేదా వర్గం SuperSpeedPlus (10 Gb/s లేదా అంతకంటే ఎక్కువ).
- జర్నీ రేఖాచిత్రం: కంప్యూటర్, ఇంటర్మీడియట్ హబ్‌లు, లింక్ మరియు పరికరం.
- విండోస్ కింద, IOCTL ద్వారా హబ్‌ని అదనపు విచారణను కనుగొనడం
SuperSpeed సామర్థ్యాలు పరికరం ద్వారా ప్రకటించబడ్డాయి. USB 2.0 ద్వారా కనెక్ట్ చేయబడిన SuperSpeed అనుకూల పరికరం పాత్ లిమిటేషన్ డయాగ్నస్టిక్‌ను ఉత్పత్తి చేస్తుంది.   USB 3 హబ్‌ల యొక్క USB 2 హబ్‌ల సహచరులు వారి 480 Mb/s బ్రాంచ్‌ను కేబుల్ తప్పుకు ఆపాదించడాన్ని నివారించడానికి విడిగా పరిగణించబడతాయి.
- VID/PID ఐడెంటిఫైయర్‌లు, USB డిస్క్రిప్టర్, రివిజన్, డ్రైవర్, సీరియల్ మరియు ఇంటర్‌ఫేస్‌లు,
సిస్టమ్ ఈ సమాచారాన్ని బహిర్గతం చేసినప్పుడు.
- ప్రతి మూడు సెకన్లకు ఆటోమేటిక్ అప్‌డేట్ లేదా F5తో మాన్యువల్.
- గత 200 గమనించిన మార్పుల సెషన్ లాగ్.
- JSON (Ctrl+E)లో పూర్తి స్టేట్‌మెంట్‌ను ఎగుమతి చేయండి మరియు ఎంచుకున్న వివరాలను కాపీ చేయండి.
- ఇంటిగ్రేటెడ్ గైడ్ మరియు స్పష్టమైన ప్రదర్శన మోడ్, ఎప్పుడూ బ్యాకప్‌గా ఉపయోగించబడదు
గుర్తింపు వైఫల్యం విషయంలో నిశ్శబ్దం.

## త్రో

రస్ట్ **1.95+**తో, Windowsలో MSVC టూల్‌చెయిన్ మరియు విజువల్ స్టూడియో C++ టూల్స్. ఆదేశాల అవుట్‌పుట్‌ను ఫిల్టర్ చేయడానికి ఉదాహరణలు RTKని ఉపయోగిస్తాయి; RTK లేకుండా, `rtk` ఉపసర్గను తీసివేయండి. పంపిణీ స్క్రిప్ట్ రెండు కేసులను అంగీకరిస్తుంది.

```powershell
rtk cargo run --release
```

స్వతంత్ర బైనరీ `target/release/san-usb-viewer.exe`లో ఉత్పత్తి చేయబడింది. `build.ps1` స్క్రిప్ట్ `dist/SanUsbViewer/`లో పంపిణీని కూడా సృష్టిస్తుంది. జాబితా కోసం WinUSB యొక్క డ్రైవర్ సవరణ లేదా ఇన్‌స్టాలేషన్ అవసరం లేదు: అనువర్తనానికి పరికర ఇంటర్‌ఫేస్‌లు అవసరం లేదు.

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

క్యాప్చర్ కోసం డెస్టినేషన్ ఫోల్డర్ తప్పనిసరిగా ఉండాలి. విడుదల సంస్కరణ కన్సోల్-తక్కువ విండోస్ అప్లికేషన్; కమాండ్ లైన్ ఇన్వెంటరీ కోసం అభివృద్ధిలో `cargo run`ని ఇష్టపడండి.

## ఫలితాలను అర్థం చేసుకోండి

** చర్చల వేగం** అనేది కనెక్షన్‌కి సంబంధించినది మరియు కాపీ వేగం యొక్క బెంచ్‌మార్క్ కాదు. ఉపయోగకరమైన వేగం ప్రత్యేకంగా ప్రోటోకాల్, పెరిఫెరల్ మరియు బస్సును పంచుకునే ఇతర పరికరాలపై ఆధారపడి ఉంటుంది. అందుబాటులో ఉన్న బ్యాండ్‌విడ్త్‌ను లెక్కించడానికి బహుళ పరికరాల నుండి వేగం జోడించబడదు.

నిష్క్రియ USB కేబుల్ సాధారణంగా లెక్కించదగిన పరికరం కాదు. ఈ సంస్కరణ దాని ఇ-మార్కర్ లేదా USB పవర్ డెలివరీ పవర్ లేదా దాని కనెక్టర్ రకాన్ని చదవదు. కనుక ఇది దాని గరిష్ట వేగాన్ని ధృవీకరించడానికి దావా వేయదు. రోగ నిర్ధారణ గమనించిన లింక్‌పై ఆధారపడి ఉంటుంది మరియు అందుబాటులో ఉంటే, విండోస్ సూచికలపై ఆధారపడి ఉంటుంది. స్లో లింక్ కేబుల్, పోర్ట్, హబ్ లేదా పరికరం ద్వారా పరిమితం చేయబడవచ్చు. USB డిస్క్రిప్టర్ వెర్షన్ నంబర్ గరిష్ట వేగంగా ఎప్పుడూ ఉపయోగించబడదు.

SuperSpeedPlus వర్గం ఇక్కడ 10 మరియు 20 Gb/s మోడ్‌ల మధ్య తేడాను గుర్తించదు. USB4/థండర్‌బోల్ట్ మరియు వాటి సొరంగాలు తనిఖీ చేయబడవు. పరికరం జోడించబడని పోర్ట్‌లు ఇన్వెంటరీ చేయబడవు. డేటా లేకుండా ఛార్జింగ్ కేబుల్ కనిపించే పరికరాన్ని సృష్టించదు. USB ట్రీలో అంతర్గత పరికరాలు (బ్లూటూత్, అంతర్నిర్మిత కెమెరా మొదలైనవి) కనిపించవచ్చు.

అందుబాటులో లేని సమాచారం ప్రదర్శించబడుతుంది. తయారీదారు మరియు ఇంటర్‌ఫేస్‌లు ఎల్లప్పుడూ Windows ద్వారా బహిర్గతం చేయబడవు. స్కాన్‌ల మధ్య పూర్తిగా జరిగే సంఘటనలు గుర్తించబడకపోవచ్చు. లాగ్ మెమరీలో ఉంది మరియు మొదటి విజయవంతమైన జాబితా తర్వాత ప్రారంభమవుతుంది.

బస్ ఐడెంటిఫైయర్‌లు మరియు పోర్ట్ పాత్‌లు సిస్టమ్ టోపోలాజీని వివరిస్తాయి. భౌతిక కనెక్టర్ USB 2 మరియు SuperSpeed కోసం రెండు వేర్వేరు మార్గాలను కలిగి ఉంటుంది.

## ఆర్కిటెక్చర్ మరియు ధ్రువీకరణ

`scanner.rs` జాబితాను నిర్వహిస్తుంది; `windows_probe.rs` హబ్‌ల నుండి స్థానిక రీడ్ అభ్యర్థనలను ఎన్‌క్యాప్సులేట్ చేస్తుంది; `model.rs` డేటా మరియు డయాగ్నస్టిక్‌లను కలిగి ఉంది. `app.rs` నేపథ్య పనులు మరియు ఎంపికను నిర్వహిస్తుంది; `views.rs`, `inspector.rs`, `connection.rs` మరియు `theme.rs` ఇంటర్‌ఫేస్‌ను egui/eframeతో గీయండి. స్కాన్ సమయంలో ఇంటర్‌ఫేస్ ఇంటరాక్టివ్‌గా ఉంటుంది మరియు తదుపరి స్కాన్ విఫలమైతే చివరి విజయవంతమైన రీడ్‌ను అలాగే ఉంచుతుంది.

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

లైబ్రరీలు క్రాస్-ప్లాట్‌ఫారమ్ మరియు Windows కోడ్ షరతులతో కూడుకున్నవి. ఈ మొదటి డెలివరీలో MacOS/Linux సంస్కరణలు ధృవీకరించబడలేదు.

## గోప్యత

ఇన్వెంటరీ టెలిమెట్రీ లేదా నెట్‌వర్క్ సేవలు లేకుండా స్థానికంగా, చదవడానికి మాత్రమే పనిచేస్తుంది. గైడ్ లింక్‌లు క్లిక్ చేసిన తర్వాత మాత్రమే తెరవబడతాయి. JSON నివేదికలు క్రమ సంఖ్యలు మరియు సిస్టమ్ ఐడెంటిఫైయర్‌లను కలిగి ఉండవచ్చు: వాటిని భాగస్వామ్యం చేయడం మీ ఇష్టం.

అప్లికేషన్‌లో **50 ఇంటర్‌ఫేస్ భాషలు** ఉన్నాయి. స్విచ్చర్‌ను తెరవడానికి ఎగువ కుడి వైపున ఉన్న భాషా కోడ్ (`FR`, `EN`, మొదలైనవి) క్లిక్ చేయండి. మీరు ఒక భాష కోసం దాని స్థానిక పేరు, దాని ఆంగ్ల పేరు లేదా దాని కోడ్ ద్వారా శోధించవచ్చు. మార్పు తక్షణమే మరియు ఎంపిక Windows కింద `%APPDATA%/SanUsbViewer/preferences.json`లో నిల్వ చేయబడుతుంది. ప్రాధాన్యత లేకుండా, సిస్టమ్ భాష ఉపయోగించబడుతుంది; మద్దతు లేని భాష ఇంగ్లీషులోకి తిరిగి వస్తుంది.

ఎంపిక మొత్తంగా అత్యధికంగా మాట్లాడే భాషలకు అనుకూలంగా ఉంటుంది (మాతృభాష మరియు రెండవ భాష), ప్రాంతీయ రూపాంతరాలను సమూహపరచడం. ఇది సంఖ్యా వర్గీకరణ కాదు: మాండలికాల సమూహాన్ని బట్టి ఫలితాలు మారుతూ ఉంటాయి. ఎంచుకున్న వేరియంట్‌లలో సరళీకృత చైనీస్, స్టాండర్డ్ అరబిక్ మరియు ఫులానీ మరియు ఉజ్బెక్ యొక్క లాటిన్ స్క్రిప్ట్‌లు ఉన్నాయి; పంజాబీ గురుముఖిని ఉపయోగిస్తుంది.
