မှောင်မိုက်သော မျက်နှာပြင်၊ အမြင်ဆိုင်ရာ ပေါ်လစီနှင့် ဖတ်နိုင်သော ရောဂါရှာဖွေမှုများပါရှိသော **Rust** ဖြင့် ရေးသားထားသော မူရင်း USB Explorer Windows 10/11 အတွက် ရည်ရွယ်သည့် ပထမဗားရှင်း။

## ပရောဂျက်၏ဇာစ်မြစ်

ပရောဂျက်၏ မူလအစမှ ဗီဒီယို- [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus)။

အဆိုပါပရောဂျက်ကို Apple တွင် **WhatCable** နှင့် Windows ပေါ်ရှိ **USB Device Tree Viewer** တို့ကို အသုံးပြုခြင်းဖြင့် မှုတ်သွင်းထားသည်- အရံအတားများ၊ အချက်အချာကျမှုများနှင့် ၎င်းတို့၏ USB ချိတ်ဆက်မှုများ၏ အမြန်နှုန်းများကို နားလည်ခြင်း။ ဒါက လွတ်လပ်တဲ့ အကောင်အထည်ဖော်မှုပါ။

## အင်္ဂါရပ်များ

- `nusb` မှတစ်ဆင့် USB စက်ပစ္စည်းများနှင့် ထိန်းချုပ်ကိရိယာများကို အမှန်တကယ်သိရှိနိုင်ခြင်း။
- ဘတ်စ်ကားနှင့် ဆိပ်ကမ်းလမ်းကြောင်းအလိုက် သစ်ပင်ဖွဲ့စည်းပုံ၊ အချက်အချာကျသော အနက်ရှိသည်။
- အမည်၊ အမှတ်စဉ်နံပါတ် သို့မဟုတ် VID:PID; USB 3+ စစ်ထုတ်မှုများနှင့် အချက်အချာကျသည်။
- ညှိနှိုင်းထားသောလင့်ခ်အမြန်နှုန်း- 1.5/12/480 Mb/s၊ 5 Gb/s၊
သို့မဟုတ် SuperSpeedPlus (10 Gb/s သို့မဟုတ် ထို့ထက်ပို၍) အမျိုးအစား။
- ခရီးစဉ်ပုံကြမ်း- ကွန်ပျူတာ၊ အလယ်အလတ်အချက်အချာ၊ လင့်ခ်နှင့် စက်။
- Windows အောက်တွင် IOCTL မှ အချက်အချာကို ထပ်မံစစ်ဆေးမေးမြန်းခြင်း။
SuperSpeed စွမ်းရည်များကို စက်က ကြေညာခဲ့သည်။ USB 2.0 မှတစ်ဆင့် ချိတ်ဆက်ထားသော SuperSpeed တွဲဖက်အသုံးပြုနိုင်သည့် စက်ပစ္စည်းသည် လမ်းကြောင်းကန့်သတ်ချက်ရှာဖွေမှုကို ထုတ်လုပ်ပေးသည်။   USB 3 hubs ၏ 480 Mb/s အကိုင်းအခက်ကို ကေဘယ်ချို့ယွင်းမှုဟု သတ်မှတ်ခြင်းမှ ရှောင်ရှားနိုင်ရန် USB 2 hubs များကို သီးခြားစီ ဆက်ဆံပါသည်။
- VID/PID ခွဲခြားသတ်မှတ်မှုများ၊ USB ဖော်ပြချက်၊ ပြန်လည်ပြင်ဆင်မှု၊ ယာဉ်မောင်း၊ အမှတ်စဉ်နှင့် အင်တာဖေ့စ်များ၊
စနစ်က ဒီအချက်အလက်တွေကို ထုတ်ပြတဲ့အခါ။
- သုံးစက္ကန့်တိုင်း အလိုအလျောက် အပ်ဒိတ်လုပ်ပါ သို့မဟုတ် F5 ဖြင့် manual။
- နောက်ဆုံးတွေ့ရှိထားသောပြောင်းလဲမှု ၂၀၀ ၏ စက်ရှင်မှတ်တမ်း။
- အပြည့်အစုံကို JSON (Ctrl+E) တွင် ထုတ်ယူပြီး ရွေးချယ်ထားသော အသေးစိတ်အချက်အလက်များကို ကူးယူပါ။
- ပေါင်းစည်းထားသော လမ်းညွှန်နှင့် တိကျပြတ်သားသော သရုပ်ပြမုဒ်ကို အရန်အဖြစ် ဘယ်တော့မှ အသုံးမပြုပါ။
ထောက်လှမ်းမှု မအောင်မြင်ပါက အသံတိတ်။

## အရှင်သာရိပုတ္တရာ

Rust **1.95+** ဖြင့် Windows ရှိ MSVC toolchain နှင့် Visual Studio C++ ကိရိယာများ။ ဥပမာများသည် command များ၏ output ကိုစစ်ထုတ်ရန် RTK ကိုအသုံးပြုသည်။ RTK မပါဘဲ၊ `rtk` ရှေ့ဆက်ကို ဖယ်ရှားလိုက်ပါ။ ဖြန့်ချီရေးဇာတ်ညွှန်းသည် အမှုနှစ်ခုလုံးကို လက်ခံသည်။

```powershell
rtk cargo run --release
```

standalone binary ကို `target/release/san-usb-viewer.exe` တွင် ထုတ်လုပ်သည်။ `build.ps1` script သည် `dist/` တွင်လည်း ဖြန့်ဖြူးမှုကို ဖန်တီးပေးပါသည်။ စာရင်းအတွက် WinUSB ၏ ယာဉ်မောင်း ပြုပြင်မွမ်းမံခြင်း သို့မဟုတ် တပ်ဆင်ခြင်း မလိုအပ်ပါ- အပလီကေးရှင်းသည် စက်ပစ္စည်းကြားခံများ မလိုအပ်ပါ။

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

ရိုက်ကူးမှုတစ်ခုအတွက် ဦးတည်ရာဖိုင်တွဲသည် ရှိရပါမည်။ ထုတ်ဝေသည့်ဗားရှင်းသည် ကွန်ဆိုးလ်နည်းသော Windows အပလီကေးရှင်းတစ်ခုဖြစ်သည်။ command line inventory အတွက် ဖွံ့ဖြိုးတိုးတက်မှုတွင် `cargo run` ကို ပိုနှစ်သက်သည်။

## ရလဒ်များကို ဘာသာပြန်ပါ။

**ညှိနှိုင်းထားသော မြန်နှုန်း** သည် ကော်ပီအမြန်နှုန်း၏ စံသတ်မှတ်ချက်မဟုတ်ပေ။ အသုံးဝင်သော အမြန်နှုန်းများသည် အထူးသဖြင့် ပရိုတိုကော၊ အရံနှင့် ဘတ်စ်ကားကို မျှဝေသည့် အခြားစက်ပစ္စည်းများအပေါ်တွင် မူတည်သည်။ ရနိုင်သော bandwidth ကိုတွက်ချက်ရန် စက်အများအပြားမှ အမြန်နှုန်းများကို ပေါင်းထည့်မည်မဟုတ်ပါ။

Passive USB ကြိုးသည် ယေဘူယျအားဖြင့် ရေတွက်နိုင်သော စက်မဟုတ်ပါ။ ဤဗားရှင်းသည် ၎င်း၏ အီး-အမှတ်အသား၊ USB ပါဝါ ပေးပို့မှု ပါဝါ၊ ၎င်း၏ ချိတ်ဆက်ကိရိယာ အမျိုးအစားကို မဖတ်ပါ။ ထို့ကြောင့် ၎င်းသည် ၎င်း၏အမြင့်ဆုံးမြန်နှုန်းကို အသိအမှတ်ပြုရန် တောင်းဆိုခြင်းမရှိပေ။ ရောဂါရှာဖွေတွေ့ရှိမှုသည် စောင့်ကြည့်လေ့လာထားသောလင့်ခ်ပေါ်တွင် အခြေခံပြီး ရရှိပါက၊ Windows အညွှန်းများပေါ်တွင် အခြေခံထားသည်။ နှေးကွေးသောလင့်ခ်ကို ကေဘယ်လ်၊ အပေါက်၊ အချက်အချာ၊ သို့မဟုတ် စက်ဖြင့် ကန့်သတ်ထားနိုင်သည်။ USB ဖော်ပြမှုဗားရှင်းနံပါတ်ကို အမြင့်ဆုံးမြန်နှုန်းအဖြစ် ဘယ်တော့မှ အသုံးမပြုပါ။

SuperSpeedPlus အမျိုးအစားသည် ဤနေရာတွင် 10 နှင့် 20 Gb/s မုဒ်များကို ခွဲခြားမထားပေ။ USB4/Thunderbolt နှင့် ၎င်းတို့၏ ဥမင်များကို စစ်ဆေးမထားပါ။ ချိတ်ဆက်ကိရိယာမပါဘဲ ဆိပ်ကမ်းများကို စာရင်းမသွင်းပါ။ ဒေတာမပါဘဲ အားသွင်းကြိုးသည် မြင်နိုင်သော ကိရိယာကို မဖန်တီးပါ။ အတွင်းပိုင်း ကိရိယာများ (ဘလူးတုသ်၊ တပ်ဆင်ထားသော ကင်မရာ စသည်) ကို USB သစ်ပင်တွင် ပေါ်လာနိုင်သည်။

လက်လှမ်းမမီသော အချက်အလက်ကို မရရှိနိုင်ဟု ဖော်ပြသည်။ ထုတ်လုပ်သူနှင့် အင်တာဖေ့စ်များကို Windows က အမြဲမဖော်ပြပါ။ စကင်န်ဖတ်မှုများကြားတွင် လုံးလုံးလျားလျားဖြစ်ပေါ်သည့် အဖြစ်အပျက်များကို သတိမပြုမိနိုင်ပါ။ မှတ်တမ်းသည် မှတ်ဉာဏ်တွင်ရှိပြီး ပထမဆုံးအောင်မြင်သောစာရင်းပြီးနောက် စတင်သည်။

Bus identifiers နှင့် port paths များသည် system topology ကိုဖော်ပြသည်။ ရုပ်ပိုင်းဆိုင်ရာချိတ်ဆက်ကိရိယာတစ်ခုတွင် USB 2 နှင့် SuperSpeed အတွက် သီးခြားလမ်းကြောင်းနှစ်ခုရှိနိုင်သည်။

## ဗိသုကာနှင့်အတည်ပြုချက်

`scanner.rs` သည် စာရင်းဇယားကို လုပ်ဆောင်သည်။ `windows_probe.rs` သည် hubs များမှ မူရင်းဖတ်ရန် တောင်းဆိုမှုများကို ဖုံးအုပ်ထားသည်။ `model.rs` တွင် ဒေတာနှင့် ရောဂါရှာဖွေမှုများ ပါရှိသည်။ `app.rs` သည် နောက်ခံအလုပ်များနှင့် ရွေးချယ်မှုကို ကိုင်တွယ်သည်။ `views.rs`၊ `inspector.rs`၊ `connection.rs` နှင့် `theme.rs` သည် အင်တာဖေ့စ်ကို egui/eframe ဖြင့် ဆွဲပါ။ စကင်န်တစ်ခုအတွင်း အင်တာဖေ့စ်သည် အပြန်အလှန်တုံ့ပြန်မှုရှိနေဆဲဖြစ်ပြီး နောက်တစ်ကြိမ်စကင်န်မအောင်မြင်ပါက နောက်ဆုံးဖတ်ခြင်းအား ဆက်လက်ထိန်းသိမ်းထားသည်။

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

စာကြည့်တိုက်များသည် cross-platform ဖြစ်ပြီး Windows ကုဒ်သည် အခြေအနေအရဖြစ်သည်။ macOS/Linux ဗားရှင်းများကို ဤပထမဆုံးပေးပို့မှုတွင် တရားဝင်မတွေ့ရှိရပါ။

## လျှို့ဝှက်ချက်

စာရင်းအင်းသည် တယ်လီမီတာ သို့မဟုတ် ကွန်ရက်ဝန်ဆောင်မှုများမပါဘဲ စက်တွင်း၊ ဖတ်ရှုရန်သာ လုပ်ဆောင်သည်။ လမ်းညွှန်လင့်ခ်များသည် ကလစ်ဖြင့်သာဖွင့်သည်။ JSON အစီရင်ခံစာများတွင် နံပါတ်စဉ်များနှင့် စနစ်ခွဲခြားသတ်မှတ်မှုများ ပါဝင်နိုင်သည်- ၎င်းတို့ကို မျှဝေခြင်းသည် သင့်အတွက်ဖြစ်သည်။
