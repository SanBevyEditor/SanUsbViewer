# San USB Viewer

**ગુજરાતી** · [English](README.en.md) · [Français](../../README.md) · [50 languages](../README.md)

> મશીન અનુવાદ; સુધારાઓ આવકાર્ય છે.

**વર્તમાન સંસ્કરણ: `0.2.0`** — MIT લાઇસન્સ.

![San USB Viewer](../../assets/screenshots/SanUsbViewer.jpg)

**રસ્ટ** માં લખાયેલ મૂળ યુએસબી એક્સપ્લોરર, ડાર્ક ઈન્ટરફેસ, વિઝ્યુઅલ ટોપોલોજી અને વાંચી શકાય તેવા ડાયગ્નોસ્ટિક્સ સાથે. વિન્ડોઝ 10/11 માટે બનાવાયેલ પ્રથમ સંસ્કરણ.

## પ્રોજેક્ટની ઉત્પત્તિ

પ્રોજેક્ટના મૂળમાં વિડિઓ: [https://www.youtube.com/watch?v=xk6GxQEmkus](https://www.youtube.com/watch?v=xk6GxQEmkus).

આ પ્રોજેક્ટ એપલ પર **WhatCable** અને Windows પર **USB Device Tree Viewer** ના ઉપયોગોથી પ્રેરિત છે: પેરિફેરલ્સ, હબ અને તેમના USB કનેક્શનની ઝડપને સમજવા. આ એક સ્વતંત્ર અમલીકરણ છે.

## લક્ષણો

- `nusb` દ્વારા USB ઉપકરણો અને નિયંત્રકોની વાસ્તવિક શોધ.
- હબની ઊંડાઈ સાથે બસ અને પોર્ટ પાથ દ્વારા વૃક્ષનું માળખું.
- નામ, સીરીયલ નંબર અથવા VID:PID દ્વારા શોધો; USB 3+ ફિલ્ટર્સ અને હબ.
- નેગોશિયેટેડ લિંક સ્પીડ: 1.5 / 12 / 480 Mb/s, 5 Gb/s,
અથવા શ્રેણી SuperSpeedPlus (10 Gb/s અથવા વધુ).
- જર્ની ડાયાગ્રામ: કમ્પ્યુટર, મધ્યવર્તી હબ, લિંક અને ઉપકરણ.
- વિન્ડોઝ હેઠળ, IOCTL દ્વારા હબની વધારાની પૂછપરછ તે જાણવા માટે
ઉપકરણ દ્વારા જાહેર કરાયેલ SuperSpeed ક્ષમતાઓ. USB 2.0 દ્વારા જોડાયેલ SuperSpeed સુસંગત ઉપકરણ પાથ મર્યાદા ડાયગ્નોસ્ટિક ઉત્પન્ન કરે છે.   યુએસબી 3 હબના યુએસબી 2 હબ સાથીદારોને તેમની 480 Mb/s બ્રાન્ચને કેબલ ફોલ્ટ માટે જવાબદાર ઠેરવવાનું ટાળવા માટે અલગથી ગણવામાં આવે છે.
- VID/PID ઓળખકર્તા, USB વર્ણનકર્તા, પુનરાવર્તન, ડ્રાઈવર, સીરીયલ અને ઈન્ટરફેસ,
જ્યારે સિસ્ટમ આ માહિતીને ઉજાગર કરે છે.
- દર ત્રણ સેકન્ડે સ્વચાલિત અપડેટ અથવા F5 સાથે મેન્યુઅલ.
- છેલ્લા 200 અવલોકન કરેલ ફેરફારોનો સત્ર લોગ.
- JSON (Ctrl+E) માં સંપૂર્ણ નિવેદન નિકાસ કરો અને પસંદ કરેલી વિગતોની નકલ કરો.
- એકીકૃત માર્ગદર્શિકા અને સ્પષ્ટ પ્રદર્શન મોડ, બેકઅપ તરીકે ક્યારેય ઉપયોગમાં લેવાતું નથી
તપાસ નિષ્ફળતાના કિસ્સામાં શાંત.

## ફેંકવું

રસ્ટ **1.95+** સાથે, Windows પર MSVC ટૂલચેન અને વિઝ્યુઅલ સ્ટુડિયો C++ ટૂલ્સ. આદેશોના આઉટપુટને ફિલ્ટર કરવા માટે ઉદાહરણો RTK નો ઉપયોગ કરે છે; RTK વિના, ફક્ત `rtk` ઉપસર્ગ દૂર કરો. વિતરણ સ્ક્રિપ્ટ બંને કેસો સ્વીકારે છે.

```powershell
rtk cargo run --release
```

એકલ બાઈનરી `target/release/san-usb-viewer.exe` માં ઉત્પન્ન થાય છે. `build.ps1` સ્ક્રિપ્ટ પણ `dist/SanUsbViewer/` માં વિતરણ બનાવે છે. ઈન્વેન્ટરી માટે કોઈ ડ્રાઈવર ફેરફાર અથવા WinUSB ના ઇન્સ્ટોલેશન જરૂરી નથી: એપ્લિકેશનને ઉપકરણ ઈન્ટરફેસની જરૂર નથી.

```powershell
# Démonstration avec données fictives, identifiées dans l’interface et l’export
rtk cargo run -- --demo

# Inventaire JSON sur la sortie standard (utiliser le binaire de développement)
rtk cargo run -- --scan

# Capture du rendu réel de l’application, puis fermeture automatique
rtk cargo run -- --screenshot artifacts/live.png
```

કેપ્ચર માટે ગંતવ્ય ફોલ્ડર અસ્તિત્વમાં હોવું જોઈએ. રિલીઝ વર્ઝન એ કન્સોલ-લેસ વિન્ડોઝ એપ્લિકેશન છે; કમાન્ડ લાઇન ઇન્વેન્ટરી માટે વિકાસમાં `cargo run` પસંદ કરો.

## પરિણામોનું અર્થઘટન કરો

**વાટાઘાટ કરેલ ઝડપ** એ કનેક્શનની છે, અને કોપી ઝડપનો માપદંડ નથી. ઉપયોગી ઝડપ ખાસ કરીને પ્રોટોકોલ, પેરિફેરલ અને બસ શેર કરતા અન્ય ઉપકરણો પર આધારિત છે. ઉપલબ્ધ બેન્ડવિડ્થની ગણતરી કરવા માટે બહુવિધ ઉપકરણોની ઝડપ ઉમેરાતી નથી.

નિષ્ક્રિય USB કેબલ સામાન્ય રીતે ગણી શકાય તેવું ઉપકરણ નથી. આ સંસ્કરણ તેના ઇ-માર્કરને વાંચતું નથી, ન તો USB પાવર ડિલિવરી પાવર, ન તેના કનેક્ટર પ્રકાર. તેથી તે તેની મહત્તમ ઝડપને પ્રમાણિત કરવાનો દાવો કરતું નથી. નિદાન અવલોકન કરેલ લિંક પર આધારિત છે અને, જો ઉપલબ્ધ હોય તો, Windows સૂચકાંકો પર. ધીમી લિંક કેબલ, પોર્ટ, હબ અથવા ઉપકરણ દ્વારા મર્યાદિત હોઈ શકે છે. USB વર્ણનકર્તા સંસ્કરણ નંબરનો ઉપયોગ મહત્તમ ઝડપ તરીકે ક્યારેય થતો નથી.

SuperSpeedPlus કેટેગરી અહીં 10 અને 20 Gb/s મોડ્સ વચ્ચે તફાવત કરતી નથી. USB4/થંડરબોલ્ટ અને તેમની ટનલની તપાસ કરવામાં આવી નથી. જોડાયેલ ઉપકરણ વગરના પોર્ટની શોધ કરવામાં આવતી નથી. ડેટા વિના ચાર્જિંગ કેબલ દૃશ્યમાન ઉપકરણ બનાવતું નથી. આંતરિક ઉપકરણો (બ્લુટુથ, બિલ્ટ-ઇન કેમેરા, વગેરે) યુએસબી ટ્રીમાં દેખાઈ શકે છે.

અપ્રાપ્ય માહિતી અનુપલબ્ધ તરીકે પ્રદર્શિત થાય છે. વિન્ડોઝ દ્વારા ઉત્પાદક અને ઇન્ટરફેસ હંમેશા ખુલ્લા નથી હોતા. ઘટનાઓ કે જે સંપૂર્ણપણે સ્કેન વચ્ચે બનતી હોય તે કદાચ ધ્યાન ન જાય. લોગ મેમરીમાં છે અને પ્રથમ સફળ ઇન્વેન્ટરી પછી શરૂ થાય છે.

બસ આઇડેન્ટીફાયર અને પોર્ટ પાથ સિસ્ટમ ટોપોલોજીનું વર્ણન કરે છે. ભૌતિક કનેક્ટરમાં USB 2 અને SuperSpeed માટે બે અલગ પાથ હોઈ શકે છે.

## આર્કિટેક્ચર અને માન્યતા

`scanner.rs` ઇન્વેન્ટરી કરે છે; `windows_probe.rs` હબમાંથી મૂળ વાંચવાની વિનંતીઓને સમાવે છે; `model.rs` ડેટા અને ડાયગ્નોસ્ટિક્સ ધરાવે છે. `app.rs` પૃષ્ઠભૂમિ કાર્યો અને પસંદગીને સંભાળે છે; `views.rs`, `inspector.rs`, `connection.rs` અને `theme.rs` egui/eframe સાથે ઇન્ટરફેસ દોરે છે. સ્કેન દરમિયાન ઇન્ટરફેસ ઇન્ટરેક્ટિવ રહે છે અને જો આગળનું સ્કેન નિષ્ફળ જાય તો છેલ્લું સફળ વાંચન જાળવી રાખે છે.

```powershell
rtk cargo fmt --check
rtk cargo clippy --all-targets -- -D warnings
rtk cargo test --workspace
```

પુસ્તકાલયો ક્રોસ-પ્લેટફોર્મ છે અને Windows કોડ શરતી છે. આ પ્રથમ વિતરણમાં macOS/Linux સંસ્કરણો માન્ય નથી.

## ગોપનીયતા

ઇન્વેન્ટરી સ્થાનિક રીતે, ફક્ત વાંચવા માટે, ટેલિમેટ્રી અથવા નેટવર્ક સેવાઓ વિના કાર્ય કરે છે. માર્ગદર્શિકા લિંક ફક્ત ક્લિક પર ખુલે છે. JSON રિપોર્ટ્સમાં સીરીયલ નંબર્સ અને સિસ્ટમ આઇડેન્ટિફાયર હોઈ શકે છે: તેમને શેર કરવાનું તમારા પર છે.

## ભાષાઓ - સંસ્કરણ 0.2.0

એપ્લિકેશનમાં **50 ઇન્ટરફેસ ભાષાઓ** શામેલ છે. સ્વિચર ખોલવા માટે ઉપર જમણી બાજુએ ભાષા કોડ (`FR`, `EN`, વગેરે) પર ક્લિક કરો. તમે કોઈ ભાષાને તેના મૂળ નામ, તેના અંગ્રેજી નામ અથવા તેના કોડ દ્વારા શોધી શકો છો. ફેરફાર તાત્કાલિક છે અને પસંદગી Windows હેઠળ `%APPDATA%/SanUsbViewer/preferences.json` માં સંગ્રહિત છે. પસંદગી વિના, સિસ્ટમ ભાષાનો ઉપયોગ થાય છે; અસમર્થિત ભાષા અંગ્રેજીમાં પાછી આવે છે.

પસંદગી પ્રાદેશિક ચલોને એકસાથે જૂથબદ્ધ કરીને, કુલ (માતૃભાષા અને બીજી ભાષા) માં સૌથી વધુ બોલાતી ભાષાઓની તરફેણ કરે છે. આ સંખ્યાત્મક વર્ગીકરણ નથી: બોલીઓના જૂથના આધારે પરિણામો બદલાય છે. પસંદ કરેલ પ્રકારોમાં સરળીકૃત ચાઈનીઝ, સ્ટાન્ડર્ડ અરબી અને ફુલાની અને ઉઝબેકની લેટિન સ્ક્રિપ્ટોનો સમાવેશ થાય છે; પંજાબી ગુરુમુખીનો ઉપયોગ કરે છે.

અંગ્રેજી, ચાઇનીઝ, હિન્દી, સ્પેનિશ, ફ્રેંચ, અરબી, બંગાળી, પોર્ટુગીઝ, રશિયન, ઉર્દુ, ઇન્ડોનેશિયન, જર્મન, જાપાનીઝ, મરાઠી, વિયેતનામીસ, તેલુગુ, હૌસા, તુર્કી, પંજાબી, સ્વાહિલી, ફિલિપિનો, તમિલ, ફારસી, કોરિયન, એમ્હારિક, થાઈ, જાવાનીઝ, ઇટાલિયન, ગુજરાતી, કન્નડ, ભોજપુરી, ભોજપુર, ભોજપુર, ભોજપુર, ગુજરાતી ફુલાની, મલયાલમ, ઓડિયા, યુક્રેનિયન, સિંધી, ઉઝબેક, પશ્તો, સુન્ડનીઝ, મલય, ઇગ્બો, નેપાળી, અઝેરી, મૈથિલી અને સોમાલી.

કૉપિ કરેલ મેનુઓ, ડાયગ્નોસ્ટિક્સ, સહાય પાઠો, પ્રવૃત્તિ સંદેશાઓ અને વિગતો સ્થાનિક છે. હાર્ડવેર અને સિસ્ટમ દ્વારા પૂરા પાડવામાં આવેલ નામો અને ઓળખકર્તાઓ જાળવી રાખવામાં આવે છે. JSON એક્સપોર્ટ તેની સ્કીમા અને ઇન્વેન્ટરી ડેટા રાખે છે, ડિસ્પ્લે ભાષાને ધ્યાનમાં લીધા વગર. બાઇટ્સ સાથે મૂંઝવણ ટાળવા માટે તકનીકી એકમો **bit/s** (Mbit/s અને Gbit/s) માં રહે છે.

ફ્રેન્ચ અને અંગ્રેજી કેટલોગ સંદર્ભ તરીકે સેવા આપે છે. અન્ય ભાષાઓ **ઓટોમેટિક અનુવાદો** છે, જેમાં ભાષાકીય સુધારાની જરૂર પડી શકે છે. `locales/*.json` ફાઇલો સંકલનમાં શામેલ છે અને તેને સુધારી શકાય છે અને પછી ફરીથી કમ્પાઇલ કરી શકાય છે. એપ્લિકેશન દ્વારા કોઈ નેટવર્ક અનુવાદ કરવામાં આવતો નથી: SIL ઓપન ફોન્ટ લાયસન્સ હેઠળ 50 ભાષાઓ અને નોટો ફોન્ટ્સ એમ્બેડ કરેલા છે. અરેબિક ટેક્સ્ટ દ્વિદિશ યુનિકોડ સેગમેન્ટ્સ અને ફોર્મેટિંગ પહેલાં ગણતરી કરાયેલ નવી રેખાઓનો ઉપયોગ કરે છે.

```powershell
# Forcer une langue pour ce lancement, sans remplacer le choix enregistré

# Vérifier les catalogues, les paramètres et les unités de vitesse
rtk python tools/validate_locales.py

```

`SAN_USB_VIEWER_CONFIG` પરીક્ષણ અથવા પોર્ટેબલ ઇન્સ્ટોલેશન માટે અન્ય પસંદગીની ફાઇલનો સંદર્ભ લઈ શકે છે. માત્ર ભાષા કોડ ત્યાં સાચવવામાં આવે છે.
